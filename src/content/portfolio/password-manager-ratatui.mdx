## Description
This **Password Manager CLI** is a terminal-based password management tool built using **Rust** with the **Ratatui** library for an interactive user interface. It allows users to securely store and manage their account credentials.

## Features

- 🔑 **Securely store passwords**
- 🖥️ **TUI-based interactive interface** using `ratatui`
- 📄 **Save & load credentials** from a text file
- ⬆️⬇️ **Navigation** using arrow keys
- 📝 **Add new accounts & passwords**
- 🔍 **View stored passwords**
- ❌ **Exit easily with 'q' key**

## Technologies Used

- 🦀 **Rust** - Safe and fast systems programming language
- 📦 **Crossterm** - Terminal handling library
- 🎨 **Ratatui** - TUI framework for interactive CLI applications

## Technical Decisions & Trade-offs

**A TUI vault vs a GUI or web password manager**
Running in the terminal means the tool works over SSH, needs no GUI toolkit, and stays fully keyboard-driven with arrow-key navigation. The cost is fit with daily habits: no OS keychain integration, no browser autofill, and an interface that assumes a comfortable command line.

**Text-file storage vs encryption at rest**
Credentials are saved to and loaded from a text file on disk, which keeps the code small and the data easy to inspect or copy. The honest limit: a text file has no encryption at rest and no master-password gate, so anyone who can read that file has every credential in it. This is a demonstration of a TUI workflow, not a hardened vault like KeePassXC or pass.

**Rust for security-adjacent tooling**
Memory safety removes whole classes of bugs, such as buffer overflows and use-after-free, that are especially damaging in software handling secrets. The trade is pace: the borrow checker and compile times are heavy machinery for a small learning project.

**Viewing passwords on screen**
Displaying stored passwords is convenient, and that convenience has a real cost: anything rendered in a terminal can be shoulder-surfed and may linger in scrollback or the emulator's buffer. A production tool would add an explicit reveal toggle and clipboard clearing; this one leans toward visibility and simplicity.

## Installation & Usage
### Clone the Repository
```bash
git clone https://github.com/MamangRust/example-password-manager-ratatui.git
cd example-password-manager-ratatui
```

### Build and Run
```bash
cargo run
```
