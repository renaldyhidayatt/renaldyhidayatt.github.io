## 🚀 Fitur Utama

### 1️⃣ Mode Cover letter
- **Cover Letter Mode** → Memberikan kritik tajam dan sarkastik terhadap surat lamaran kerja.
- **Setiap roasting dilengkapi dengan saran perbaikan yang membangun.**

### 2️⃣ Teknologi AI dengan DeepSeek & Ollama
- Menggunakan **DeepSeek (deepseek-r1:1.5b)** untuk menghasilkan kritik yang tajam & cerdas.
- Dapat diperluas dengan model lain melalui **Ollama** untuk analisis lebih mendalam.

### 3️⃣ Dukungan Berbagai Format File
✅ **.txt** – File teks sederhana.
✅ **.docx** – File Microsoft Word.
✅ **Mudah diunggah langsung melalui UI Streamlit.**

### 4️⃣ Roasting dalam Bahasa Indonesia
- Hasil roasting **sepenuhnya dalam Bahasa Indonesia**.
- Menggunakan bahasa yang **tajam tetapi tetap relevan dan membangun**.

### 5️⃣ Antarmuka Pengguna yang Simpel & Intuitif
- **Dibangun dengan Streamlit** untuk pengalaman pengguna yang ringan & responsif.
- **Desain interaktif** → Pilih mode, unggah file, dan terima roasting secara instan!

### 6️⃣ Kritik Tajam tapi Bermanfaat
- **Roasting AI dibuat dengan metafora kreatif dan sarkasme cerdas.**
- Kritik disertai dengan **solusi konkret** untuk meningkatkan kualitas tulisan.

## Technical Decisions & Trade-offs

**A local 1.5B model via Ollama**
Running `deepseek-r1:1.5b` locally means zero API cost, no rate limits, and cover letters full of personal detail never leaving the machine. The cost is capability: a 1.5B model reasons and writes well below hosted large models, and output quality depends on the hardware it runs on. For a sarcasm-generation tool, local and free is the right trade against remote and better.

**Tone control lives in the prompt**
The sharp-but-constructive sarcasm is instructed behavior, not fine-tuned, which makes the persona cheap to iterate on. The risk is drift: a small model sometimes lands flat and sometimes overshoots into plain rudeness. Requiring every roast to come with concrete improvement suggestions is a prompt-level guardrail, and it mostly — not always — holds.

**Streamlit as the fastest usable interface**
Streamlit turns the idea into an upload-and-submit application with minimal code, which is the right call for a single-purpose tool. The trade-off is that it stays demo-grade: limited layout control and no deployment story beyond running it locally.

**Only .txt and .docx**
Supporting plain text and Word documents covers where cover letters actually live while keeping parsing scope small. The cost is a document-parsing dependency and the format edge cases that .docx brings, and no PDF support, which is the obvious next request for a tool like this.

## 📌 Cara Menggunakan
1. **Pilih mode** → Cover Letter atau Artikel.
2. **Upload file** → Format `.txt` atau `.docx`.
3. **Klik Submit** → AI akan langsung menganalisis dan memberikan roasting.
4. **Terima hasil roasting** → Baca kritik dan perbaiki tulisan kamu!
