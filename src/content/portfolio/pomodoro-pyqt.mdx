# 🚀 Pomodoro Task QT

**Pomodoro Task QT** is a Pomodoro Timer application with task management features designed to enhance productivity.

## ✨ Key Features

✅ **Tasks List & Pomodoro Timer** - Organize tasks and use the Pomodoro technique for focused work.

📊 **Monthly Visualization** - Analyze monthly productivity in graphical form.

📆 **Weekly Visualization** - View weekly statistics to understand work patterns.

## Technical Decisions & Trade-offs

**Counting ticks vs reading the clock**
In a GUI timer the countdown advances on framework timer events, and those events slip when the event loop is busy. Whether the app sums ticks or reads the system clock is the difference between a timer that drifts under load and one that stays honest; reading the clock costs a little extra bookkeeping and is what a 25-minute block ultimately depends on.

**PyQt for an always-open desktop companion**
A Pomodoro tool wants to sit in the background while you work elsewhere, and a native Qt window with notifications through Plyer fits that better than a terminal tab or a browser page. The price is packaging: Qt binaries are heavy, and the tool only works while the process stays alive, so closing the window ends the session.

**Pandas and matplotlib for personal statistics**
Weekly and monthly charts come from mature libraries rather than hand-rolled aggregation and plotting, which is fast to build and dependable to render. The trade is proportion: both are industrial-scale dependencies for a single user's task log, and their import time and memory are paid at every launch of a tool you open many times a day.

**Notifications without per-platform code**
Plyer supplies platform-independent notifications from Python, sparing the project separate APIs for each operating system. The cost of that abstraction is shallow integration: notifications are basic, and their behavior varies by desktop environment in ways the library does not fully smooth over.
