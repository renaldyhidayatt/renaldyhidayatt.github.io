# Mathematics for Artificial Intelligence

Mathematics is the language that underlies Artificial Intelligence (AI) and Machine Learning (ML). In this article, we will explain the fundamental mathematical concepts used in AI, including Linear Algebra, Calculus, and Statistics, and provide examples of their use.

## Linear Algebra

In mathematics, Linear Algebra is an important branch that is widely used across various disciplines, including Artificial Intelligence. Let's explore Linear Algebra concepts at different levels of difficulty.

### 1-Dimensional Linear Algebra

In one dimension, linear algebra operations usually involve scalar values represented as real numbers. Here are some mathematical representations:

#### Scalar Addition:

$$
\text{Scalar1} + \text{Scalar2} = 3 + 5 = 8
$$

#### Scalar Multiplication:

$$
\text{Scalar} \times \text{Scalar1} = 2 \times 3 = 6
$$

**Python Example:**

```python
import numpy as np

scalar1 = 3
scalar2 = 5

result_addition = scalar1 + scalar2
print("Scalar 1 + Scalar 2 = ", result_addition)

scalar = 2
result_multiplication = scalar * scalar1
print("Scalar * Scalar 1 = ", result_multiplication)
```

## 2-Dimensional Linear Algebra

In two dimensions, we work with vectors represented as number pairs \((x, y)\). Here are some mathematical representations:

#### Vector Addition:

$$
\text{Vector1} + \text{Vector2} = (2, 3) + (4, 5) = (6, 8)
$$

#### Scalar Multiplication:

$$
\text{Scalar} \times \text{Vector1} = 2 \times (2, 3) = (4, 6)
$$

#### Dot Product:

$$
\text{Dot Product} \, \text{Vector1} \cdot \text{Vector2} = (2, 3) \cdot (4, 5) = 2 \times 4 + 3 \times 5 = 23
$$

**Contoh Python:**

```python
import numpy as np

vector1 = np.array([2, 3])
vector2 = np.array([4, 5])

# Vector Addition
result_addition = vector1 + vector2
print("Vector 1 + Vector 2 =", result_addition)

# Scalar Multiplication
scalar = 2
result_multiplication = scalar * vector1
print("Scalar * Vector 1 =", result_multiplication)

# Dot Product
dot_product = np.dot(vector1, vector2)
print("Dot Product of Vector1 and Vector2 =", dot_product)
```

## 3-Dimensional Linear Algebra

In three dimensions, vectors are represented as triplets \((x, y, z)\). Here are some mathematical representations:

### Penjumlahan Vektor

$$
\text{Vector1} + \text{Vector2} = (2, 3, 1) + (4, 5, 2) = (2 + 4, 3 + 5, 1 + 2) = (6, 8, 3)
$$

### Perkalian Skalar

$$
\text{Scalar} \times \text{Vector1} = 2 \times (2, 3, 1) = (2 \times 2, 2 \times 3, 2 \times 1) = (4, 6, 2)
$$

### Cross Product

$$
\text{Cross Product of Vector1 and Vector2} = (2, 3, 1) \times (4, 5, 2) = \left( (3 \times 2 - 5 \times 1), (2 \times 4 - 1 \times 2), (4 \times 5 - 3 \times 2) \right) = (1, 6, 14)
$$


## Calculus
Calculus is the branch of mathematics that studies change and the rate of change. In this material, we will explain three fundamental concepts of Calculus: Derivatives, Indefinite Integrals, and Definite Integrals, and also show how to use Python to compute them.

### Concept 1: Derivatives
Definition: A derivative measures the rate of change of a function with respect to changes in the independent variable. The derivative of a function $f(x)$ is denoted as $f'(x)$ or $\frac{df}{dx}$.
Python Usage Example:
To compute the derivative of a function, we can use the SymPy library in Python. Let's use the function $f(x) = 2x^2 + 3x + 1$ as an example.


```python
# Importing the SymPy library
import sympy as sp

# Creating the variable symbol
x = sp.symbols('x')

# Defining the function
f = 2*x**2 + 3*x + 1

# Computing the first derivative
f_prime = sp.diff(f, x)

# Printing the result
print("The first derivative of f(x) is:", f_prime)
```

### Concept 2: Indefinite Integrals
An indefinite integral is one of the important concepts in calculus. This integral is the inverse operation of a derivative. The indefinite integral of a function $f(x)$ is denoted as $\int f(x) , dx$ and produces another function that, if differentiated, yields $f(x)$ again.
Indefinite Integral Concept Example:
Suppose we have the function $f(x) = 3x^2 + 2x + 4$. To compute the indefinite integral of $f(x)$, we can write it as follows:
$$
\int (3x^2 + 2x + 4) , dx
$$
Then, we can compute this indefinite integral using Python and the SymPy library:

```python
# Importing the SymPy library
import sympy as sp

# Creating the variable symbol
x = sp.symbols('x')

# Defining the function
f = 3*x**2 + 2*x + 4

# Computing the indefinite integral
integral = sp.integrate(f, x)

# Printing the result
print("The indefinite integral of f(x) is:", integral)

```


### Concept 3: Definite Integrals
A definite integral is one of the important concepts in calculus used to compute the area under a function's curve between two specific bounds. The definite integral of a function $f(x)$ over the interval $[a, b]$ is denoted as $\int_{a}^{b} f(x) , dx$ and produces a numerical value representing the area of the region under the curve $f(x)$ between $x = a$ and $x = b$.
Definite Integral Concept Example:
Suppose we want to compute the definite integral of the function $g(x) = 2x$ over the interval $[1, 5]:
$$
\int_{1}^{5} 2x , dx
$$
Using Python and the SymPy library, we can compute this definite integral:

```python
# Importing the SymPy library
import sympy as sp

# Creating the variable symbol
x = sp.symbols('x')

# Defining the integration bounds
a = 1
b = 5

# Defining the function
g = 2*x

# Computing the definite integral
definite_integral = sp.integrate(g, (x, a, b))

# Printing the result
print("The definite integral of g(x) from {} to {} is:".format(a, b), definite_integral)
```

## Conclusion

In the realm of Artificial Intelligence (AI), Linear Algebra and Calculus play pivotal roles in shaping the algorithms and models that drive intelligent systems.

1. **Linear Algebra** is fundamental for handling data in multiple dimensions. Concepts such as vector addition, scalar multiplication, and matrix operations enable efficient data representation and manipulation. These mathematical tools allow AI practitioners to process vast datasets, perform transformations, and execute complex computations necessary for training machine learning models. The understanding of linear transformations and eigenvalues is particularly crucial in optimization tasks, which are central to improving model performance.

2. **Calculus** provides essential techniques for understanding change and optimization. The derivative serves as a measure of how a function evolves, which is critical for optimizing learning algorithms. Gradient descent, a fundamental optimization technique used in training neural networks, relies heavily on concepts from calculus to minimize loss functions effectively. Furthermore, integrals help in calculating areas under curves, which can be useful in probabilistic models and decision-making processes.

Together, Linear Algebra and Calculus form the backbone of the mathematical framework that underpins AI. Mastery of these subjects equips AI professionals with the tools necessary to develop more sophisticated and efficient algorithms, ultimately advancing the capabilities and applications of artificial intelligence.
