## Mental model Spring Boot

| Konsep | Ringkasan |
| :--- | :--- |
| Auto-configuration | Boot **membuat bean** yang kemungkinan kamu butuhkan, **hanya kalau** tidak ada bean milikmu → kamu selalu bisa override |
| Starter | dependency set + auto-configuration + default konfigurasi |
| Convention over configuration | Nama bean & property yang diharapkan sudah diasumsikan |
| `@ComponentScan` | memindai paket milikmu, bukan `java.*` |
| Sifat bean | **singleton** default; prototype/scoped kalau perlu |
| `@Bean` di `@Configuration` | **proxy** → bisa saling memanggil, aman |
| `@Bean` di `@Component` | **bukan proxy** → inter-bean reference tidak_di chinasional |
| Type-based injection | tipe bean jadi kuncinya → **1 tipe = 1 bean** (atau `@Primary`/`@Qualifier`) |
| `@Transactional` | bekerja lewat **proxy** → self-invocation tidak di-transaksikan |
| Condition | `@ConditionalOn*` dipakai saat **auto-configuration**, `@Conditional` untuk app |

## Auto-configuration

```java
// auto-configuration class (dalam paket o.s.a.autoconfigure.*)
@AutoConfiguration
@ConditionalOnClass(RedisTemplate.class)              // hanya kalau class ada di classpath
@ConditionalOnMissingBean(RedisTemplate.class)         // hanya kalau user belum bikin sendiri
@ConditionalOnProperty(name = "app.cache.enabled", havingValue = "true")
@AutoConfigureAfter(DataSourceAutoConfiguration.class) // urutan auto-config
public class CacheAutoConfiguration {

    @Bean
    @ConditionalOnMissingBean
    RedisTemplate<String, Object> redisTemplate(RedisConnectionFactory factory) {
        return new RedisTemplate<>(factory);
    }
}
```

```text
# src/main/resources/META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports
com.sanedge.order.config.CacheAutoConfiguration
```

| Anotasi | Arti |
| :--- | :--- |
| `@AutoConfiguration` | penanda auto-configuration (bukan `@Configuration` biasa) |
| `@ConditionalOnClass` | hanya aktif kalau class ada → **proteksi `NoClassDefFoundError`** |
| `@ConditionalOnMissingBean` | hanya aktif kalau bean belum ada → **titik override user** |
| `@ConditionalOnProperty` | based on property |
| `@ConditionalOnBooleanProperty` | (3.5) versi boolean dari `@ConditionalOnProperty` |
| `@ConditionalOnBean` | hanya kalau bean tertentu ada |
| `@AutoConfigureBefore/After` | urutan |

> **Jebakan:** `@ConditionalOnMissingBean` **hanya boleh dipakai di auto-configuration**,
> bukan di `@Configuration` milikmu — urutan evaluasi bean tidak terjamin, hasilnya bisa
> berubah sesuai urutan scan. Ini alasan Spring Boot memisahkan `@AutoConfiguration`.

## Dependency injection

```java
@Service
public class OrderService {

    private final OrderRepository repository;      // WAJIB constructor injection
    private final UserClient userClient;
    private final Clock clock;                    // bean Clock — mudah di-test (mock waktu)

    public OrderService(OrderRepository repository, UserClient userClient, Clock clock) {
        this.repository = repository;
        this.userClient = userClient;
        this.clock = clock;
    }
}
```

```java
// beberapa bean bertipe sama → @Qualifier
@Service
public class NotificationService {
    private final Sender emailSender;
    private final Sender smsSender;

    public NotificationService(@Qualifier("emailSender") Sender emailSender,
                               @Qualifier("smsSender") Sender smsSender) { ... }
}

// @Primary = default kalau tidak ada qualifier
@Service
@Primary
public class DefaultSender implements Sender { ... }

// @Order = urutan saat mengoleksi bean
@Component
@Order(1)
class FirstValidator implements Validator { ... }

// optional dependency
@Service
public class ReportService {
    private final ObjectProvider<EmailSender> emailSender;   // lazy, bisa tidak ada

    public void send() {
        EmailSender s = emailSender.getIfAvailable();
        if (s != null) s.send();
    }
}
```

| Cara | Kapan |
| :--- | :--- |
| Constructor injection | **default** — dependency wajib, mudah di-test |
| Setter injection | dependency opsional yang bisa berubah |
| Field injection (`@Autowired`) | **jangan** — field `null` tanpa container, sulit di-test |
| `@Qualifier` | lebih dari satu bean bertipe sama |
| `@Primary` | tentukan default |
| `ObjectProvider<T>` | dependency opsional / lazy |

> **Jebakan:** satu tipe bean = satu instance. Kalau butuh dua `Sender` berbeda tanpa
> `@Qualifier`, aplikasi **tidak akan start** (`NoUniqueBeanDefinitionException`).

```java
// filter (setiap request) — didaftarkan di @Configuration
@Component
public class CorrelationIdFilter extends OncePerRequestFilter {
    @Override
    protected void doFilterInternal(HttpServletRequest req, HttpServletResponse res, FilterChain chain) {
        String id = req.getHeader("X-Request-Id");
        if (id == null) id = UUID.randomUUID().toString();
        MDC.put("requestId", id);
        res.setHeader("X-Request-Id", id);
        try { chain.doFilter(req, res); } finally { MDC.remove("requestId"); }
    }
}

// (3.5) registrasi filter via anotasi
@Configuration(proxyBeanMethods = false)
class WebConfig {
    @Bean
    @FilterRegistration(name = "myFilter", urlPatterns = "/api/*", order = 0)
    MyFilter myFilter() { return new MyFilter(); }
}
```

```java
@RestControllerAdvice
public class GlobalExceptionHandler {

    @ExceptionHandler(MethodArgumentNotValidException.class)
    ProblemDetail validation(MethodArgumentNotValidException ex) {
        ProblemDetail pd = ProblemDetail.forStatus(HttpStatus.BAD_REQUEST);
        pd.setTitle("Validation failed");
        pd.setProperty("errors", ex.getBindingResult().getFieldErrors().stream()
                .map(f -> f.getField() + ": " + f.getDefaultMessage()).toList());
        return pd;
    }

    @ExceptionHandler(OrderNotFoundException.class)
    ProblemDetail notFound(OrderNotFoundException ex) {
        return ProblemDetail.forStatusAndDetail(HttpStatus.NOT_FOUND, ex.getMessage());
    }
}
```

```java
// validator kustom
@Component
public class MerchantCodeValidator implements ConstraintValidator<ValidMerchantCode, String> {
```

| Annotasi | Validasi |
| :--- | :--- |
| `@NotNull` `@NotBlank` `@NotEmpty` | keberadaan |
| `@Min` `@Max` `@Positive` `@PositiveOrZero` | angka |
| `@Size` `@Email` `@Pattern` `@URL` | format |
| `@Past` `@Future` `@PastOrPresent` | waktu |
| `@AssertTrue` | ekspresi kustom |
| `@Valid` | validasi nested object |

## Spring Data JPA

```java
public interface OrderRepository extends JpaRepository<Order, Long>, JpaSpecificationExecutor<Order> {

    // derived query — nama method = query
    List<Order> findByMerchantIdAndStatus(Long merchantId, OrderStatus status);
    Optional<Order> findFirstByOrderNo(String orderNo);
    boolean existsByIdempotencyKey(String key);
    long countByStatusAndCreatedAtAfter(OrderStatus status, Instant after);

    // @Query + JOIN FETCH — hindari N+1
    @Query("select o from Order o join fetch o.items where o.id = :id")
    Optional<Order> findByIdWithItems(@Param("id") Long id);

    // native query
    @Query(value = "SELECT * FROM orders WHERE merchant_id = :m AND created_at > :since", nativeQuery = true)
    List<Order> findNative(@Param("m") Long merchantId, @Param("since") Instant since);

    // @Modifying + transaksi
    @Modifying(clearAutomatically = true, flushAutomatically = true)
    @Query("update Order o set o.status = :s where o.id = :id")
    int updateStatus(@Param("id") Long id, @Param("s") OrderStatus s);

    // projection — ambil subset kolom
    @Query("select new com.sanedge.order.dto.OrderSummary(o.id, o.totalPrice) from Order o where o.merchantId = :m")
    List<OrderSummary> summaryByMerchant(@Param("m") Long merchantId);

    // entity graph
    @EntityGraph(attributePaths = {"items"})
    List<Order> findByMerchantId(Long merchantId);

    // pagination & sorting
    Page<Order> findByStatus(OrderStatus status, Pageable pageable);
}
```

```java
// Specification — query dinamis
@Service
@RequiredArgsConstructor
public class OrderSearchService {
    private final OrderRepository repository;

    public Page<Order> search(OrderFilter filter, Pageable pageable) {
        Specification<Order> spec = Specification.where((root, q, cb) ->
                cb.equal(root.get("status"), filter.status()))
            .and((root, q, cb) -> cb.greaterThanOrEqualTo(root.get("createdAt"), filter.from()));
        return repository.findAll(spec, pageable);
    }
}
```

```java
// auditing
@EntityListeners(AuditingEntityListener.class)
@Entity
public abstract class BaseModel {
    @CreatedDate  @Column(updatable = false) private Instant createdAt;
    @LastModifiedDate              private Instant updatedAt;
    @CreatedBy                    private String createdBy;
    @LastModifiedBy               private String updatedBy;
    @Version                      private Long version;   // optimistic locking
}

@Configuration
@EnableJpaAuditing(auditorAwareRef = "auditorProvider")
class JpaConfig {
    @Bean AuditorAware<String> auditorProvider() {
        return () -> SecurityContextHolder.getContext().getAuthentication().getName();
    }
}
```

| Konsep | Catatan |
| :--- | :--- |
| Derived query | method name = query; `And`/`Or`, `Between`, `Top3`, `IgnoreCase` |
| `@Query` JPQL | portable, `join fetch` untuk relasi |
| `@Query` native | SQL mentah, butuh nama kolom/tabel persis |
| `@EntityGraph` | eager loading 1 query (alternatif `join fetch`) |
| Projection | `interface` atau `record` constructor — **tanpa load entity** |
| `Pageable` / `Sort` | pagination + sort, `PageRequest.of(p, s, Sort.by(...))` |
| `@Modifying` | bulk update/delete → **harus dalam transaksi** |
| `@Version` | optimistic locking → `OptimisticLockingFailureException` |
| `Specification` | query dinamis, komposable |
| `@EntityGraph` + pagination | hati-hati: bisa menarik terlalu banyak baris |

> **Jebakan:** `@Modifying` **tidak** jalan tanpa `@Transactional`. Dan bulk update **tidak**
> menyentuh `persistence context` → pakai `clearAutomatically = true`.

## Transaksi

```java
@Service
public class OrderService {

    @Transactional                                   // REQUIRED (default)
    public Order create(CreateOrderRequest req) { ... }

    @Transactional(readOnly = true)                  // query: skip flush + dirty check
    public List<Order> findAll() { ... }

    @Transactional(propagation = Propagation.REQUIRES_NEW)   // transaksi terpisah
    public void writeAudit(String message) { ... }

    @Transactional(isolation = Isolation.SERIALIZABLE)
    public void transfer(TransferRequest req) { ... }

    @Transactional(rollbackFor = BusinessException.class)    // checked exception → rollback
    public void risky() throws BusinessException { ... }

    @Transactional(timeout = 5, readOnly = true)
    public Order find(Long id) { ... }
}
```

| Propagation | Arti |
| :--- | :--- |
| `REQUIRED` | ikut transaksi existing, atau buat baru (default) |
| `REQUIRES_NEW` | selalu transaksi baru (transaksi lama di-suspend) |
| `NESTED` | savepoint di dalam transaksi |
| `SUPPORTS` | ikut kalau ada |
| `NOT_SUPPORTED` | non-transaksional |
| `MANDATORY` | wajib ada transaksi aktif |

| Atribut | Arti |
| :--- | :--- |
| `readOnly` | hint: tidak ada flush, boleh di-cache |
| `isolation` | `READ_COMMITTED` (default), `REPEATABLE_READ`, `SERIALIZABLE` |
| `rollbackFor` | exception yang **memicu** rollback (default: unchecked saja) |
| `noRollbackFor` | exception yang **tidak** memicu rollback |
| `timeout` | batas durasi transaksi |
| `label` | label untuk monitoring |

> **Jebakan:** `@Transactional` bekerja lewat **proxy** → panggilan `this.method()` di class
> yang sama **tidak** ditransaksikan. Fix: pindahkan ke bean lain, atau self-inject proxy.

## Migrasi skema (Flyway/Liquibase)

```text
src/main/resources/db/migration/
├── V20260815093000__create_orders_table.sql
├── V20260815093100__create_order_items_table.sql
├── V20260820094500__add_index_orders_status.sql
├── R__seed_reference_data.sql           # repeatable
└── U20260815093000__create_orders_table.sql   # undo (opsional)
```

```yaml
spring:
  flyway:
    enabled: true
    locations: classpath:db/migration
    baseline-on-migrate: true          # hanya saat mengadopsi DB existing
    baseline-version: 0
    validate-on-migrate: true
    out-of-order: false               # migrasi lama setelah baru → error (default)
```

| Aturan | Kenapa |
| :--- | :--- |
| `V<timestamp>__desc.sql` | nomor urut = urutan eksekusi; `V2` menabrak `V10` |
| `R__desc.sql` | repeatable (seed/view), jalan tiap checksum berubah |
| 1 DB = 1 zona history | beberapa modul satu DB → pisahkan `flyway_schema_history` |
| Jangan edit file yang sudah dipakai | checksum mismatch → **boot gagal** |
| `baseline-on-migrate` | hanya sekali, saat adopsi DB existing |
| Migrasi di service terpisah | jangan jalan di tiap replica aplikasi |

```bash
mvn -pl order-service flyway:info     # status migrasi
mvn -pl order-service flyway:migrate  # jalankan manual (dev)
```

```java
// JdbcTemplate
@Service
public class ReportDao {
    private final JdbcTemplate jdbc;
    private final NamedParameterJdbcTemplate named;

    public ReportDao(JdbcTemplate jdbc, NamedParameterJdbcTemplate named) {
        this.jdbc = jdbc; this.named = named;
    }

    public List<ReportRow> find(LocalDate from) {
        return named.query("""
                SELECT merchant_id, SUM(total) AS revenue
                FROM orders
                WHERE created_at >= :from AND status = 'PAID'
                GROUP BY merchant_id
                """, Map.of("from", from), (rs, i) -> new ReportRow(rs.getLong(1), rs.getBigDecimal(2)));
    }
}
```

```java
@Repository
public class OrderJooqRepository {
    private final DSLContext dsl;

    public List<OrderRecord> paidSince(Instant since) {
        return dsl.select(ORDERS)
                .where(ORDERS.STATUS.eq(PAID).and(ORDERS.CREATED_AT.greaterOrEqual(since)))
```

| Tool | Kapan |
| :--- | :--- |
| Spring Data JPA | domain kaya, query tak dinamis, butuh object graph |

> `spring-boot-starter-webflux` (Netty/reaktif) → aplikasi jalan tapi **stack-nya
> tidak deterministik**. Pilih satu.

## Caching

```java
@Service
public class ProductService {

    @Cacheable(cacheNames = "product", key = "#id")
    public Product findById(Long id) { ... }

    @CachePut(cacheNames = "product", key = "#product.id")
    public Product update(Product product) { ... }

    @CacheEvict(cacheNames = "product", key = "#id")
    public void delete(Long id) { ... }
```

## Jebakan (wajib dibaca)

| Jebakan | Gejalanya | Solusinya |
| :--- | :--- | :--- |
| `@Transactional` self-invocation | Transaksi tidak jalan | Pisah ke bean lain / self-inject proxy |
| `open-in-view: true` | `LazyInitializationException`, N+1 | Set `false` + `join fetch` |
| N+1 query | 1 + N query per list | `@EntityGraph`, `join fetch`, projection |
| `@Autowired` field | `null` di unit test | Constructor injection |
| 2 bean bertipe sama | `NoUniqueBeanDefinitionException` | `@Qualifier` / `@Primary` |
| `@MockBean` | Deprecated warning | `@MockitoBean` |
| `@ConditionalOnMissingBean` di `@Configuration` | Perilaku tidak deterministik | Hanya di auto-configuration |
| `.enabled=yes` | Fitur diam-diam mati (3.5: harus `true`/`false`) | Pakai `true`/`false` |
| `ddl-auto: update` | Schema berubah diam-diam | `validate` + Flyway |
| BigDecimal `equals` | `1.0` != `1.00` | `compareTo() == 0` |
| `EnumType.ORDINAL` | Reorder enum = data lama salah | `EnumType.STRING` |
| `@Async` di method private | Tidak jalan | Public + proxy |
| `@Async` tanpa nama executor | Pakai executor default (nama `taskExecutor` dihapus di 3.5) | `@Async("namaExecutor")` |
| `@Scheduled` di banyak replica | Job jalan N kali | ShedLock / 1 replica |
| `@Cacheable` tanpa TTL | Data basi selamanya | Set TTL di CacheManager |
| `RestTemplate` tanpa timeout | Request menggantung | Set timeout di request factory |
| Retry tanpa idempotency | Double charge | Idempotency key |
| `csrf().disable()` di aplikasi cookie | Keamanan rusak | Hanya untuk API stateless |
| Event publish di dalam transaksi | Consumer baca data belum commit | `AFTER_COMMIT` atau outbox |
| Mix MVC + WebFlux | Stack tidak deterministik | Pilih satu |
| `spring.threads.virtual.enabled` + `synchronized` | Carrier thread terblokir | `ReentrantLock` |
| Pool size naik bareng virtual thread | DB kewalahan | Batasi pool tetap |
| Image buildpack tanpa shell | `kubectl exec` gagal | Pakai run image dengan shell |
| `management.endpoint.env` di publik | Rahasia bocor | Batasi exposure + authorization |
