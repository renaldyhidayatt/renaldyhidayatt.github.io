## Spring Boot mental model

| Concept | Summary |
| :--- | :--- |
| Auto-configuration | Boot **creates the beans** you probably need, **only if** you don't have your own → you can always override |
| Starter | dependency set + auto-configuration + default configuration |
| Convention over configuration | Expected bean & property names are already assumed |
| `@ComponentScan` | scans your package, not `java.*` |
| Bean scope | **singleton** by default; prototype/scoped when needed |
| `@Bean` in `@Configuration` | **proxy** → can call each other, safe |
| `@Bean` in `@Component` | **not a proxy** → inter-bean references are not intercepted |
| Type-based injection | the bean type is the key → **1 type = 1 bean** (or `@Primary`/`@Qualifier`) |
| `@Transactional` | works through a **proxy** → self-invocation is not transactional |
| Condition | `@ConditionalOn*` is used in **auto-configuration**, `@Conditional` for apps |

> found (and there is no error — the app starts, but the service is `null`).

## Auto-configuration

```java
// auto-configuration class (inside the o.s.a.autoconfigure.* package)
@AutoConfiguration
@ConditionalOnClass(RedisTemplate.class)              // only if the class is on the classpath
@ConditionalOnMissingBean(RedisTemplate.class)         // only if the user hasn't created their own
@ConditionalOnProperty(name = "app.cache.enabled", havingValue = "true")
@AutoConfigureAfter(DataSourceAutoConfiguration.class) // auto-config ordering
public class CacheAutoConfiguration {

    @Bean
    @ConditionalOnMissingBean
    RedisTemplate<String, Object> redisTemplate(RedisConnectionFactory factory) {
        return new RedisTemplate<>(factory);
    }
}
```

```text
# src/main/resources/META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports
com.sanedge.order.config.CacheAutoConfiguration
```

| Annotation | Meaning |
| :--- | :--- |
| `@AutoConfiguration` | auto-configuration marker (not a regular `@Configuration`) |
| `@ConditionalOnClass` | only active if the class is present → **`NoClassDefFoundError` protection** |
| `@ConditionalOnMissingBean` | only active if the bean doesn't exist yet → **user override point** |
| `@ConditionalOnProperty` | based on property |
| `@ConditionalOnBooleanProperty` | (3.5) boolean version of `@ConditionalOnProperty` |
| `@ConditionalOnBean` | only if a specific bean exists |
| `@AutoConfigureBefore/After` | ordering |

> **Pitfall:** `@ConditionalOnMissingBean` **may only be used in auto-configuration**,
> not in your own `@Configuration` — bean evaluation order is not guaranteed and the result
> can change with scan order. This is why Spring Boot separates `@AutoConfiguration`.

## Dependency injection

```java
@Service
public class OrderService {

    private final OrderRepository repository;      // MUST be constructor injection
    private final UserClient userClient;
    private final Clock clock;                    // Clock bean — easy to test (mock time)

    public OrderService(OrderRepository repository, UserClient userClient, Clock clock) {
        this.repository = repository;
        this.userClient = userClient;
        this.clock = clock;
    }
}
```

```java
// multiple beans of the same type → @Qualifier
@Service
public class NotificationService {
    private final Sender emailSender;
    private final Sender smsSender;

    public NotificationService(@Qualifier("emailSender") Sender emailSender,
                               @Qualifier("smsSender") Sender smsSender) { ... }
}

// @Primary = the default when no qualifier is given
@Service
@Primary
public class DefaultSender implements Sender { ... }

// @Order = ordering when collecting beans
@Component
@Order(1)
class FirstValidator implements Validator { ... }

// optional dependency
@Service
public class ReportService {
    private final ObjectProvider<EmailSender> emailSender;   // lazy, may be absent

    public void send() {
        EmailSender s = emailSender.getIfAvailable();
        if (s != null) s.send();
    }
}
```

| Approach | When |
| :--- | :--- |
| Constructor injection | **default** — required dependency, easy to test |
| Setter injection | optional dependency that can change |
| Field injection (`@Autowired`) | **don't** — field is `null` without the container, hard to test |
| `@Qualifier` | more than one bean of the same type |
| `@Primary` | pick the default |
| `ObjectProvider<T>` | optional / lazy dependency |

> **Pitfall:** one bean type = one instance. If you need two different `Sender`s without a
> `@Qualifier`, the app **won't start** (`NoUniqueBeanDefinitionException`).

```java
// filter (every request) — registered in @Configuration
@Component
public class CorrelationIdFilter extends OncePerRequestFilter {
    @Override
    protected void doFilterInternal(HttpServletRequest req, HttpServletResponse res, FilterChain chain) {
        String id = req.getHeader("X-Request-Id");
        if (id == null) id = UUID.randomUUID().toString();
        MDC.put("requestId", id);
        res.setHeader("X-Request-Id", id);
        try { chain.doFilter(req, res); } finally { MDC.remove("requestId"); }
    }
}

// (3.5) register a filter via annotation
@Configuration(proxyBeanMethods = false)
class WebConfig {
    @Bean
    @FilterRegistration(name = "myFilter", urlPatterns = "/api/*", order = 0)
    MyFilter myFilter() { return new MyFilter(); }
}
```

| Concept | Difference |
| :--- | :--- |
| `@RestController` | `@Controller` + `@ResponseBody` (JSON automatically) |
| `@ResponseBody` |Serializes JSON, `@RequestBody` deserializes |
| `ResponseEntity` | controls status + headers + body |
| `ProblemDetail` | RFC 9457 error format (built into Spring 6) |
| `@ControllerAdvice` | global error handler (not per controller) |
| Servlet filter | runs **before** the DispatcherServlet |
| `HandlerInterceptor` | runs **after** the handler, pre/post |
| `@RestControllerAdvice` | advice + `@ResponseBody` combined |

```java
@RestControllerAdvice
public class GlobalExceptionHandler {

    @ExceptionHandler(MethodArgumentNotValidException.class)
    ProblemDetail validation(MethodArgumentNotValidException ex) {
        ProblemDetail pd = ProblemDetail.forStatus(HttpStatus.BAD_REQUEST);
        pd.setTitle("Validation failed");
        pd.setProperty("errors", ex.getBindingResult().getFieldErrors().stream()
                .map(f -> f.getField() + ": " + f.getDefaultMessage()).toList());
        return pd;
    }

    @ExceptionHandler(OrderNotFoundException.class)
    ProblemDetail notFound(OrderNotFoundException ex) {
        return ProblemDetail.forStatusAndDetail(HttpStatus.NOT_FOUND, ex.getMessage());
    }
}
```

## Bean validation

```java
public record CreateOrderRequest(
        @NotNull Long productId,
        @Min(1) @Max(100) int quantity,
        @NotBlank @Size(max = 200) String note,
        @Email String email,
        @Past Instant createdAt,
        @Pattern(regexp = "^[A-Z]{3}-\\d{4}$") String reference
) {}

// method validation (requires @Validated on the class)
@Service
@Validated
public class OrderService {
    public void transfer(@Valid TransferRequest req) { ... }
}

// groups: different validation per operation
public interface OnCreate {}
public interface OnUpdate {}

public record OrderRequest(
        @Null(groups = OnUpdate.class) Long id,   // null on create, required on update
        @NotNull(groups = OnCreate.class) Long productId
) {}

@PostMapping
public OrderResponse create(@Validated(OnCreate.class) @RequestBody OrderRequest req) { ... }
```

```java
// custom validator
@Component
public class MerchantCodeValidator implements ConstraintValidator<ValidMerchantCode, String> {
    @Override
    public boolean isValid(String value, ConstraintValidatorContext ctx) {
        return value == null || value.matches("^MERCH-\\d{4}$");
    }
}
```

| Annotation | Validates |
| :--- | :--- |
| `@NotNull` `@NotBlank` `@NotEmpty` | presence |
| `@Min` `@Max` `@Positive` `@PositiveOrZero` | numbers |
| `@Size` `@Email` `@Pattern` `@URL` | format |
| `@Past` `@Future` `@PastOrPresent` | time |
| `@AssertTrue` | custom expression |
| `@Valid` | nested object validation |

> **Pitfall:** **request body** validation runs automatically; **method** validation needs
> `@Validated` on the class. Without it, parameter constraints are silently ignored.

## Spring Data JPA

```java
public interface OrderRepository extends JpaRepository<Order, Long>, JpaSpecificationExecutor<Order> {

    // derived query — method name = query
    List<Order> findByMerchantIdAndStatus(Long merchantId, OrderStatus status);
    Optional<Order> findFirstByOrderNo(String orderNo);
    boolean existsByIdempotencyKey(String key);
    long countByStatusAndCreatedAtAfter(OrderStatus status, Instant after);

    // @Query + JOIN FETCH — avoid N+1
    @Query("select o from Order o join fetch o.items where o.id = :id")
    Optional<Order> findByIdWithItems(@Param("id") Long id);

    // native query
    @Query(value = "SELECT * FROM orders WHERE merchant_id = :m AND created_at > :since", nativeQuery = true)
    List<Order> findNative(@Param("m") Long merchantId, @Param("since") Instant since);

    // @Modifying + transaction
    @Modifying(clearAutomatically = true, flushAutomatically = true)
    @Query("update Order o set o.status = :s where o.id = :id")
    int updateStatus(@Param("id") Long id, @Param("s") OrderStatus s);

    // projection — fetch a subset of columns
    @Query("select new com.sanedge.order.dto.OrderSummary(o.id, o.totalPrice) from Order o where o.merchantId = :m")
    List<OrderSummary> summaryByMerchant(@Param("m") Long merchantId);

    // entity graph
    @EntityGraph(attributePaths = {"items"})
    List<Order> findByMerchantId(Long merchantId);

    // pagination & sorting
    Page<Order> findByStatus(OrderStatus status, Pageable pageable);
}
```

```java
// Specification — dynamic query
@Service
@RequiredArgsConstructor
public class OrderSearchService {
    private final OrderRepository repository;

    public Page<Order> search(OrderFilter filter, Pageable pageable) {
        Specification<Order> spec = Specification.where((root, q, cb) ->
                cb.equal(root.get("status"), filter.status()))
            .and((root, q, cb) -> cb.greaterThanOrEqualTo(root.get("createdAt"), filter.from()));
        return repository.findAll(spec, pageable);
    }
}
```

```java
// auditing
@EntityListeners(AuditingEntityListener.class)
@Entity
public abstract class BaseModel {
    @CreatedDate  @Column(updatable = false) private Instant createdAt;
    @LastModifiedDate              private Instant updatedAt;
    @CreatedBy                    private String createdBy;
    @LastModifiedBy               private String updatedBy;
    @Version                      private Long version;   // optimistic locking
}

@Configuration
@EnableJpaAuditing(auditorAwareRef = "auditorProvider")
class JpaConfig {
    @Bean AuditorAware<String> auditorProvider() {
        return () -> SecurityContextHolder.getContext().getAuthentication().getName();
    }
}
```

| Concept | Note |
| :--- | :--- |
| Derived query | method name = query; `And`/`Or`, `Between`, `Top3`, `IgnoreCase` |
| `@Query` JPQL | portable, `join fetch` for relations |
| `@Query` native | raw SQL, needs exact column/table names |
| `@EntityGraph` | eager loading in 1 query (alternative to `join fetch`) |
| Projection | `interface` or `record` constructor — **without loading the entity** |
| `Pageable` / `Sort` | pagination + sort, `PageRequest.of(p, s, Sort.by(...))` |
| `@Modifying` | bulk update/delete → **must be inside a transaction** |
| `@Version` | optimistic locking → `OptimisticLockingFailureException` |
| `Specification` | dynamic, composable query |
| `@EntityGraph` + pagination | careful: can pull too many rows |

> **Pitfall:** `@Modifying` does **not** work without `@Transactional`. And a bulk update does **not**
> touch the persistence context → use `clearAutomatically = true`.

## Transactions

```java
@Service
public class OrderService {

    @Transactional                                   // REQUIRED (default)
    public Order create(CreateOrderRequest req) { ... }

    @Transactional(readOnly = true)                  // query: skip flush + dirty check
    public List<Order> findAll() { ... }

    @Transactional(propagation = Propagation.REQUIRES_NEW)   // separate transaction
    public void writeAudit(String message) { ... }

    @Transactional(isolation = Isolation.SERIALIZABLE)
    public void transfer(TransferRequest req) { ... }

    @Transactional(rollbackFor = BusinessException.class)    // checked exception → rollback
    public void risky() throws BusinessException { ... }

    @Transactional(timeout = 5, readOnly = true)
    public Order find(Long id) { ... }
}
```

| Propagation | Meaning |
| :--- | :--- |
| `REQUIRED` | join the existing transaction, or create a new one (default) |
| `REQUIRES_NEW` | always a new transaction (the old one is suspended) |
| `NESTED` | savepoint inside the transaction |
| `SUPPORTS` | join if one exists |
| `NOT_SUPPORTED` | non-transactional |
| `MANDATORY` | an active transaction is required |

| Attribute | Meaning |
| :--- | :--- |
| `readOnly` | hint: no flush, may be cached |
| `isolation` | `READ_COMMITTED` (default), `REPEATABLE_READ`, `SERIALIZABLE` |
| `rollbackFor` | exceptions that **trigger** rollback (default: unchecked only) |
| `noRollbackFor` | exceptions that **do not** trigger rollback |
| `timeout` | transaction duration limit |
| `label` | label for monitoring |

> **Pitfall:** `@Transactional` works through a **proxy** → a `this.method()` call in the same
> class is **not** transactional. Fix: move it to another bean, or self-inject the proxy.

## Schema migration (Flyway/Liquibase)

```text
src/main/resources/db/migration/
├── V20260815093000__create_orders_table.sql
├── V20260815093100__create_order_items_table.sql
├── V20260820094500__add_index_orders_status.sql
├── R__seed_reference_data.sql           # repeatable
└── U20260815093000__create_orders_table.sql   # undo (optional)
```

```yaml
spring:
  flyway:
    enabled: true
    locations: classpath:db/migration
    baseline-on-migrate: true          # only when adopting an existing DB
    baseline-version: 0
    validate-on-migrate: true
    out-of-order: false               # old migration after a new one → error (default)
```

| Rule | Why |
| :--- | :--- |
| `V<timestamp>__desc.sql` | the number is the execution order; `V2` collides with `V10` |
| `R__desc.sql` | repeatable (seed/view), runs whenever the checksum changes |
| 1 DB = 1 history zone | multiple modules sharing one DB → separate the `flyway_schema_history` |
| Never edit a file that has already been used | checksum mismatch → **boot fails** |
| `baseline-on-migrate` | only once, when adopting an existing DB |
| Migrations in a separate service | don't run them in every app replica |

```bash
mvn -pl order-service flyway:info     # migration status
mvn -pl order-service flyway:migrate  # run manually (dev)
```

## SQL: JdbcTemplate, R2DBC, jOOQ

```java
// JdbcTemplate
@Service
public class ReportDao {
    private final JdbcTemplate jdbc;
    private final NamedParameterJdbcTemplate named;

    public ReportDao(JdbcTemplate jdbc, NamedParameterJdbcTemplate named) {
        this.jdbc = jdbc; this.named = named;
    }

    public List<ReportRow> find(LocalDate from) {
        return named.query("""
                SELECT merchant_id, SUM(total) AS revenue
                FROM orders
                WHERE created_at >= :from AND status = 'PAID'
                GROUP BY merchant_id
                """, Map.of("from", from), (rs, i) -> new ReportRow(rs.getLong(1), rs.getBigDecimal(2)));
    }
}
```

```java
// R2DBC (reactive) — don't mix with JPA in the same service
@Repository
public class OrderReactiveRepository extends ReactiveCrudRepository<Order, Long> {
    public Flux<Order> findByStatus(OrderStatus status) {
        return findAllByStatus(status);
    }
}
```

```java
// jOOQ — type-safe SQL generated from the DDL
@Repository
public class OrderJooqRepository {
    private final DSLContext dsl;

    public List<OrderRecord> paidSince(Instant since) {
        return dsl.select(ORDERS)
                .where(ORDERS.STATUS.eq(PAID).and(ORDERS.CREATED_AT.greaterOrEqual(since)))
                .fetch();
    }
}
```

| Tool | When |
| :--- | :--- |
| Spring Data JPA | rich domain, non-dynamic queries, needs an object graph |
| `JdbcTemplate` | hand-written SQL, the most transparent performance |
| jOOQ | complex SQL with type-safety from the DDL |
| R2DBC | reactive web; **do not mix** with JPA |

> **Pitfall:** mixing `spring-boot-starter-web` (Tomcat/MVC) and
> `spring-boot-starter-webflux` (Netty/reactive) → the app starts but the **stack is
> non-deterministic**. Pick one.

```yaml
spring:
  cache:
    type: redis            # simple | caffeine | redis | hazelcast | none
    redis:
      time-to-live: 5m
      cache-null-values: false
    caffeine:
      spec: maximumSize=1000,expireAfterWrite=300s
```

```java
// custom CacheManager + per-cache TTL
@Bean
CacheManager cacheManager(RedisConnectionFactory factory) {
    RedisCacheConfiguration config = RedisCacheConfiguration.defaultCacheConfig()
            .entryTtl(Duration.ofMinutes(5))
            .disableCachingNullValues()
            .serializeValuesWith(RedisSerializationContext.SerializationPair
                    .fromSerializer(new GenericJackson2JsonRedisSerializer()));
    return RedisCacheManager.builder(factory).cacheDefaults(config).build();
}
```

| Rule | Why |
| :--- | :--- |
| Explicit cache key | the default uses the param's `toString()` → unstable hashcode |
| Don't cache `null` | `cache-null-values: false` |
| TTL is mandatory | a cache without TTL = stale data forever |
| `@Cacheable` on the **service**, not the controller | the right layer & reusable |
| Evict the cache on the same path | write-through is not automatic |
| `@Cacheable` + `@Transactional` | ordering matters: cache outside the transaction |

```java
@Configuration
@EnableWebSecurity
@EnableMethodSecurity                       // for @PreAuthorize
public class SecurityConfig {

    @Bean
    SecurityFilterChain filterChain(HttpSecurity http, JwtDecoder decoder) throws Exception {
        return http
            .csrf(csrf -> csrf.disable())    // stateless API → CSRF is irrelevant
            .cors(Customizer.withDefaults())
            .sessionManagement(s -> s.sessionCreationPolicy(SessionCreationPolicy.STATELESS))
            .authorizeHttpRequests(auth -> auth
                .requestMatchers("/actuator/health/**", "/actuator/prometheus").permitAll()
                .requestMatchers(HttpMethod.POST, "/api/auth/**").permitAll()
                .requestMatchers("/api/admin/**").hasRole("ADMIN")
                .anyRequest().authenticated())
            .oauth2ResourceServer(oauth -> oauth.jwt(jwt -> jwt.decoder(decoder)))
            .addFilterBefore(jwtFilter, UsernamePasswordAuthenticationFilter.class)
            .build();
    }

    @Bean
    JwtDecoder jwtDecoder(@Value("${spring.security.oauth2.resourceserver.jwt.jwk-set-uri}") String uri) {
        return NimbusJwtDecoder.withJwkSetUri(uri).build();
    }

    @Bean
    PasswordEncoder passwordEncoder() {
        return new BCryptPasswordEncoder(12);
    }
}
```

| Concept | Meaning |
| :--- | :--- |
| `SecurityFilterChain` | bean; **one chain per request** |
| `authorizeHttpRequests` | declarative rule (replaces the deprecated `authorizeRequests`) |

```java
    @Async
    @EventListener
    public void onCreated(OrderCreated event) { ... }
```

| `@EventListener` | `@TransactionalEventListener` |
| :--- | :--- |

| Principle | Rule |
| :--- | :--- |

## Performance: virtual threads, pools, containers

```yaml
spring:

    virtual:
      enabled: true            # (3.2+) JDK 21+, I/O-bound work becomes cheap
  datasource:
    hikari:
      maximum-pool-size: 20
      minimum-idle: 5
      connection-timeout: 30000

      max: 200
      min-spare: 20

    accept-count: 100
    max-parameter-count: 10000
```

| Topic | Advice |
| :--- | :--- |
| Virtual threads | enable for I/O-bound work (web + blocking JDBC) |
| Connection pool | does **not** scale up with virtual threads — still limit the DB |
| `server.shutdown: graceful` | graceful shutdown + `terminationGracePeriodSeconds` |
| `spring.main.lazy-initialization` | fast startup, but errors show up on the first request |
| CDS / AOT | `spring-boot:run -Dspring-boot.run.jvmArguments="-XX:ArchiveClassesAtExit=app.jsa"` |
| Undertow vs Tomcat | Undertow is lighter on I/O; Tomcat is feature-complete |
| HTTP/2 | requires TLS + h2, check client support |
| Batch insert | `hibernate.order_inserts/updates` + `jdbc.batch_size` |

## Pitfalls (must read)

| Pitfall | Symptom | Fix |
| :--- | :--- | :--- |
| `@Transactional` self-invocation | Transaction doesn't apply | Move to another bean / self-inject the proxy |
| `open-in-view: true` | `LazyInitializationException`, N+1 | Set `false` + `join fetch` |
| N+1 query | 1 + N queries per list | `@EntityGraph`, `join fetch`, projection |
| `@Autowired` field | `null` in unit tests | Constructor injection |
| 2 beans of the same type | `NoUniqueBeanDefinitionException` | `@Qualifier` / `@Primary` |
| `@MockBean` | Deprecation warning | `@MockitoBean` |
| `@ConditionalOnMissingBean` in `@Configuration` | Non-deterministic behavior | Only in auto-configuration |
| `.enabled=yes` | Feature silently disabled (3.5: must be `true`/`false`) | Use `true`/`false` |
| `ddl-auto: update` | Schema changes silently | `validate` + Flyway |
| BigDecimal `equals` | `1.0` != `1.00` | `compareTo() == 0` |
| `EnumType.ORDINAL` | Reordering the enum corrupts old data | `EnumType.STRING` |
| `@Async` on a private method | Doesn't run | Public + proxy |
| `@Async` without an executor name | Uses the default executor (the `taskExecutor` name is removed in 3.5) | `@Async("executorName")` |
| `@Scheduled` on many replicas | Job runs N times | ShedLock / 1 replica |
| `@Cacheable` without TTL | Stale data forever | Set a TTL in the CacheManager |
| `RestTemplate` without a timeout | Requests hang | Set a timeout on the request factory |
| Retry without idempotency | Double charge | Idempotency key |
| `csrf().disable()` in a cookie-based app | Security is broken | Only for stateless APIs |
| Publishing events inside a transaction | Consumer reads uncommitted data | `AFTER_COMMIT` or outbox |
| Mixing MVC + WebFlux | Non-deterministic stack | Pick one |
| `spring.threads.virtual.enabled` + `synchronized` | Carrier thread blocked | `ReentrantLock` |
| Pool size raised along with virtual threads | DB overwhelmed | Keep the pool capped |
| Buildpack image without a shell | `kubectl exec` fails | Use a run image with a shell |
| `management.endpoint.env` exposed publicly | Secrets leak | Restrict exposure + authorization |
