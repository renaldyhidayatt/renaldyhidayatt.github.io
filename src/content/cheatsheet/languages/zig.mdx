## CLI & toolchain

```sh
zig init                 # scaffold project: build.zig + src/main.zig + build.zig.zon
zig run main.zig         # compile + run directly
zig test src/main.zig    # run all test blocks in the file
zig build -Doptimize=ReleaseFast
zig build test
zig fmt .                # official formatter (the only style — no debates)
zig build-exe m.zig -O ReleaseFast -fstrip
```

| Optimization mode | Meaning |
|---|---|
| `Debug` (default) | slowest, most safety checks + leak checker active |
| `ReleaseSafe` | fast, safety checks stay on (UB still caught) |
| `ReleaseFast` | fastest, safety checks disabled |
| `ReleaseSmall` | smallest binary size |

## 5-minute mental model

| Concept | Summary |
|---|---|
| `var` / `const` | `const` = immutable (the correct default). A variable that is never mutated but declared `var` = **compile error**. |
| Integer types | `u8 u16 u32 u64 u128 usize`, signed versions `i8..i128`, and `u0`/`i0` also exist. |
| Comptime | Everything that can be evaluated at compile time **is evaluated at compile time** — generics use `comptime T: type`, not templates. |
| No hidden control flow | No operator overloading, no exceptions. Allocation, errors, casts — all explicit. |
| Explicit allocators | Functions that need the heap take a `std.mem.Allocator` as a parameter. |
| `defer` / `errdefer` | `defer` runs when the scope exits (LIFO); `errdefer` only when exiting through an error return. |
| Optional | `?T` — null-safe, accessed via `.?` or `if (x) \|v\| ...`. |
| Error union | `E!T` — an error is a value, not an exception. |
| Slice | `[]T` = pointer + length. String = `[]const u8` (not its own type). |
| Sentinel | `[:0]const u8` = slice terminated by `\0` (for C FFI). |

## Entry point: `main` in 0.16

0.16 changed `main` — it can now receive a `std.process.Init` that already contains
**a ready-to-use allocator** and **an `Io` implementation** (picked automatically for the target):

```zig
const std = @import("std");

pub fn main(init: std.process.Init) !void {
    const io = init.io;   // I/O interface: file, net, sleep, mutex, ...
    const gpa = init.gpa; // general allocator (debug mode: leak checking active)
    _ = init.arena;       // arena for process-lifetime allocations
    _ = init.environ_map; // environment variables
    _ = init.minimal.args;
}
```

> The classic `main` `pub fn main() !void` and `pub fn main() !u8` are still valid.
> `Init.Minimal` (`init.minimal`) is a subset: only `environ` + `args`.

| `Init` field | Contents |
|---|---|
| `gpa` | general `std.mem.Allocator`, threadsafe, leak-checked in Debug |
| `arena` | process-lifetime `*std.heap.ArenaAllocator` — free all at once at the end |
| `io` | `std.Io` — context for all I/O operations in 0.16 |
| `environ_map` | `*std.process.Environ.Map` (see [Process](#process--environment)) |
| `minimal.args` | CLI arguments (see [Process](#process--environment)) |

## Print & `std.Io.Writer` / `std.Io.Reader`

### Quick: debug print (to stderr, unbuffered)

```zig
std.debug.print("value: {d}\n", .{42}); // no io needed, handy for debugging
```

### Idiomatic: buffered writer to stdout

Output is **buffer-based** — the buffer is yours, flush is explicit. This is the core 0.15/0.16 pattern:

```zig
pub fn main(init: std.process.Init) !void {
    const io = init.io;

    var stdout_buffer: [4096]u8 = undefined;                 // buffer on the stack
    var stdout_writer = std.Io.File.stdout().writer(io, &stdout_buffer);
    const out = &stdout_writer.interface;                    // *std.Io.Writer

    try out.print("hello {s}\n", .{"world"});
    try out.writeAll("without format\n");
    try out.writeByte('\n');
    try out.flush();                                         // REQUIRED before exit
}
```

> Forgetting `flush()` = lost output (still sitting in the buffer). Add `defer out.flush() catch {};`
> when there are many exit paths.

| `std.Io.Writer` | Function |
|---|---|
| `print(fmt, args)` | write with format specifiers |
| `writeAll(bytes)` | write all bytes |
| `write(bytes)` | write, may be partial (returns bytes written) |
| `writeByte(b)` | 1 byte |
| `flush()` | push the buffer to the destination |
| `unusedCapacitySlice()` | free buffer space as `[]u8` |
| `undo(n)` | rewind `n` bytes (e.g. drop the last separator) |
| `std.Io.Writer.fixed(buf)` | writer that writes to a fixed buffer |

| `std.Io.Reader` | Function |
|---|---|
| `takeByte()` | 1 byte |
| `takeDelimiter('\n')` | 1 line (without delimiter), `null` at EOF |
| `peek(n)` | look at `n` bytes without consuming |
| `discardAll(n)` | discard `n` bytes |
| `streamRemaining(writer)` | copy the rest of the stream to a writer (pump) |

### Reading & writing files

```zig
const io = init.io;
const cwd = std.Io.Dir.cwd();

// write
{
    const f = try cwd.createFile(io, "out.txt", .{ .truncate = true });
    defer f.close(io);                                   // close needs io in 0.16!
    var buf: [256]u8 = undefined;
    var fw = f.writer(io, &buf);
    try fw.interface.writeAll("hello file\n");
    try fw.interface.flush();
}

// read
{
    const f = try cwd.openFile(io, "out.txt", .{});
    defer f.close(io);
    var buf: [256]u8 = undefined;
    var fr = f.reader(io, &buf);
    if (try fr.interface.takeDelimiter('\n')) |line| {   // line borrows from buf
        std.debug.print("{s}\n", .{line});
    }
}
```

### Sleep, clock, duration

```zig
try io.sleep(.fromMilliseconds(100), .real); // std.Io.Duration.fromMilliseconds

// wall-clock timestamp
const ms = io.now(.real).toMilliseconds();
std.debug.print("unix ms: {d}\n", .{ms});
```

> The classic timer (`std.time.Timer`) is gone in 0.16 — use `io.now(.real)` before/after,
> or `io.now(.awake)`/`.monotonic` for interval measurements.

## String builder: `Writer.Allocating`

The idiomatic replacement for "append to an `ArrayList(u8)` while formatting" — a writer that
automatically reallocates on the heap:

```zig
var aw: std.Io.Writer.Allocating = .init(init.gpa);
defer aw.deinit();

try aw.writer.print("user={f} id={d}", .{ user, 7 });
const owned: []u8 = try aw.toOwnedSlice();   // take ownership of the memory
defer init.gpa.free(owned);
// also: aw.written() — borrowed slice, aw.writer directly
```

## Error handling

```zig
// error set
const ParseError = error{ Invalid, TooLong };

// error union: E!T
fn parse(s: []const u8) ParseError!u32 {
    if (s.len == 0) return error.Invalid;
    if (s.len > 10) return error.TooLong;
    return std.fmt.parseInt(u32, s, 10) catch |e| switch (e) {
        error.Overflow => return error.TooLong,   // convert errors between sets
        else => return error.Invalid,
    };
}

// consuming
const x = parse("42") catch 0;            // fallback value
const y = try parse("42");                // propagate to caller
const z = parse("42") catch |err| {       // catch + inspect
    std.debug.print("failed: {s}\n", .{@errorName(err)});
    return err;
};

// cleanup on success & error
var f = try cwd.openFile(io, "a.txt", .{});
defer f.close(io);                        // always runs
errdefer cleanup_partial();               // only if exiting with an error

// unwrap
const v: ?u32 = null;
const w = v orelse 0;                     // default
const t = v.?;                            // panics if null — for invariants only
if (v) |val| {} else {}                   // destructuring
if (v) |val| {}                           // optional + payload
for (items, 0..) |item, i| {}             // element + index
```

- `unreachable` = a compiler assert (panic in ReleaseSafe, UB in ReleaseFast).
- Error traces are automatic in Debug/ReleaseSafe — don't throw them away, they're Zig's best feature.

## Memory & allocator

All heap access goes through the `std.mem.Allocator` interface:

```zig
const mem: []u8 = try alloc.alloc(u8, 1024);   // allocate N elements
defer alloc.free(mem);

const copy: []u8 = try alloc.dupe(u8, "text"); // duplicate a slice/string
defer alloc.free(copy);

var buf: []u8 = try alloc.alloc(u8, 8);
buf = try alloc.realloc(buf, 64);              // resize
defer alloc.free(buf);

const p = try alloc.create(User);              // a single element
defer alloc.destroy(p);
```

| Allocator | When to use |
|---|---|
| `init.gpa` / `std.heap.DebugAllocator(.{})` | dev default — detects double-free, use-after-free, **leaks** |
| `std.heap.smp_allocator` | multithreaded production (the gpa choice in Release) |
| `std.heap.ArenaAllocator` | many small objects with a phase lifetime — **free all at once**, no per-item free |
| `std.heap.FixedBufferAllocator` | allocate from a static buffer — zero malloc, deterministic |
| `std.heap.page_allocator` | mmap syscall per alloc — simplest, slowest |
| `std.heap.c_allocator` | uses libc malloc (requires `link_libc`) |
| `std.testing.allocator` | in tests — fails the test on any leak |

### Arena pattern (most commonly used)

```zig
var arena = std.heap.ArenaAllocator.init(gpa);
defer arena.deinit();                     // releases ALL arena allocations here
const a = arena.allocator();

const s1 = try a.dupe(u8, "free");        // no need to free individually
const s2 = try std.fmt.allocPrint(a, "{d}", .{99});
```

> Rule of thumb: public functions accept any `Allocator`; internal code that needs
> scratch memory makes its own arena and `defer`s its deinit.

## Data containers

> **0.15+: `std.ArrayList` is *unmanaged*** — the allocator is passed per method, init uses
> `.empty`. The managed version still exists as `std.array_list.Managed(T)`.

### ArrayList

```zig
var list: std.ArrayList(u32) = .empty;
defer list.deinit(gpa);

try list.append(gpa, 1);
try list.appendSlice(gpa, &.{ 2, 3, 4 });
try list.insert(gpa, 0, 99);
const last = list.pop();                  // ?T
const removed = list.orderedRemove(0);    // shifts left
try list.ensureTotalCapacity(gpa, 1000);
_ = try list.toOwnedSlice(gpa);           // turn it into an owned []u32

std.debug.print("{any}\n", .{list.items}); // access via .items
```

### HashMap

```zig
// string keys → use StringHashMap; int/enum keys → AutoHashMap
var map = std.StringHashMap(u32).init(gpa);
defer map.deinit();

try map.put("one", 1);
try map.put("two", 2);
if (map.get("one")) |v| {}                // ?V
if (map.getPtr("one")) |ptr| {}           // ?*V — in-place mutation
const old = map.fetchPut("one", 10);      // put + return the old value
_ = map.remove("two");
const exists = map.contains("one");

var it = map.iterator();
while (it.next()) |e| {
    // e.key_ptr.*, e.value_ptr.* — order is NOT stable
}

// unmanaged (no stored allocator):
var um: std.HashMapUnmanaged(u32, u32) = .empty;
defer um.deinit(gpa);
try um.put(gpa, 1, 1);
```

### Other containers (quick look)

```zig
// ArrayHashMap — like HashMap but preserves insert order + fast iteration
var ahl = std.StringArrayHashMap(u32).init(gpa);
try ahl.put("a", 1);                      // ahl.keys(), ahl.values()

// MultiArrayList — automatic struct of arrays (cache-friendly for SoA)
var mal: std.MultiArrayList(User) = .empty;
try mal.append(gpa, .{ .name = "a", .age = 1 });

// PriorityQueue — 0.16: comparator returns std.math.Order, allocator per push
const PQ = std.PriorityQueue(u32, void, struct {
    fn lt(_: void, a: u32, b: u32) std.math.Order {
        return std.math.order(a, b);
    }
}.lt);
var pq = PQ.initContext({});
defer pq.deinit(gpa);
try pq.push(gpa, 3);
const min = pq.pop();                     // ?T — smallest element

// Deque — double-ended deque
var dq: std.Deque(u32) = .empty;
defer dq.deinit(gpa);
try dq.pushBack(gpa, 1);
const front = dq.popFront();              // ?T

// Linked list — intrusive: embed a Node in your struct, access the payload via @fieldParentPtr
const Item = struct { data: u32, node: std.DoublyLinkedList.Node = undefined };
var lst: std.DoublyLinkedList = .{};
var item = Item{ .data = 1 };
lst.append(&item.node);                   // prepend/insertAfter/remove/pop also exist
const payload: *Item = @fieldParentPtr("node", lst.first.?);

// BitStack (stack of bits) & DynamicBitSet
var bits = try std.DynamicBitSetUnmanaged.initEmpty(gpa, 128);
defer bits.deinit(gpa);
bits.set(3);                              // bits.isSet(3), bits.toggle(), ...

// EnumSet / EnumMap — array-backed, O(1) with no hashing
const S = std.EnumSet(Direction);
var s = S.initEmpty();
s.insert(.north);
const M = std.EnumMap(Direction, u8);
var m = M.init(.{ .north = 1, .south = 2 });

// StaticStringMap — literal lookup at comptime, O(len) with no allocation
const cmd = std.StaticStringMap(u8).initComptime(.{
    .{ "add", 'a' }, .{ "delete", 'd' },
});
const c = cmd.get("add").?;
```

## String & `std.mem`

A string in Zig = `[]const u8`. UTF-8 is treated as bytes — unicode utilities live in `std.unicode`.

```zig
const s = "hello world";
const m = std.mem;

m.eql(u8, "abc", "abc")            // true
m.startsWith(u8, s, "ha")          // true
m.endsWith(u8, s, "ld")            // true
m.indexOf(u8, s, "wor")            // ?usize
m.lastIndexOf(u8, s, "o")          // ?usize
m.count(u8, s, "o")                // usize — number of occurrences

// split & tokenize: both are iterators
var sp = m.splitScalar(u8, "a,b,,c", ',');
//   → "a" "b" "" "c"      (empty segments are kept)
var tk = m.tokenizeScalar(u8, " a , b ", ',');
//   → "a" "b"             (empty & whitespace are skipped)

m.trim(u8, "  x  ", " ")           // "x"
m.trimLeft(u8, "  x", " ")
m.replaceOwned(u8, gpa, "a-b", "-", "+")   // ![]u8 — owned by gpa

// join strings (needs an allocator)
const full = try m.concat(gpa, u8, &.{ "a", "b" });   // "ab"
const fmted = try std.fmt.allocPrint(gpa, "{s}-{d}", .{ "id", 7 });

// duplicate & null-terminate
const d = try gpa.dupe(u8, s);
const z = try gpa.dupeZ(u8, s);    // [:0]u8 for C APIs

// case-insensitive compare & friends: std.ascii
std.ascii.eqlIgnoreCase("Ab", "ab")   // true
std.ascii.upperString(&dst, src);     // std.ascii.isDigit, toUpper, ...
```

| `std.unicode` | Function |
|---|---|
| `utf8ValidateSlice(bytes)` | validate UTF-8 |
| `utf8CountCodepoints(s)` | count codepoints (not bytes!) |
| `utf8Encode(cp, out)` | encode `u21` → bytes |

## Format specifiers

Everything goes through `std.Io.Writer.print` / `std.debug.print` / `allocPrint`.

| Spec | Example output | Notes |
|---|---|---|
| `{s}` | `text` | string / slice of u8 |
| `{d}` | `42` | decimal int & float |
| `{x}` / `{X}` | `ff` / `FF` | hex lower/upper |
| `{b}` | `1010` | binary |
| `{o}` | `17` | octal |
| `{e}` / `{E}` | `1.23e4` | scientific |
| `{c}` | `a` | char ASCII |
| `{u}` | `é` | codepoint unicode |
| `{B}` | `1.536kB` | human-readable byte size |
| `{f}` | — | calls the type's `format(self, *Writer)` method |
| `{any}` | `{ 1, 2 }` | debug-dump anything |
| `{*}` | `main.User@...` | address + type |

```zig
std.debug.print("[{d:5}]", .{42});     // [   42]  — width 5
std.debug.print("[{s:>8}]", .{"zig"}); // [     zig] — right aligned
std.debug.print("[{d:.2}]", .{3.14159}); // [3.14] — precision

// custom format — invoked with {f}
const User = struct {
    name: []const u8,
    age: u8,
    pub fn format(u: User, w: *std.Io.Writer) std.Io.Writer.Error!void {
        try w.print("{s} ({d} years old)", .{ u.name, u.age });
    }
};
// std.debug.print("{f}", .{user});

// parsing the other way
const n = try std.fmt.parseInt(i32, "-42", 10);
const f = try std.fmt.parseFloat(f64, "3.14");
```

## Filesystem

> 0.16: `File` & `Dir` moved from `std.fs` to **`std.Io.File` / `std.Io.Dir`**.
> `std.fs` only keeps path utilities (`std.fs.path.*`).

```zig
const io = init.io;
const cwd = std.Io.Dir.cwd();

// open dir & file
var sub = try cwd.openDir(io, "src", .{}); defer sub.close(io);
const f = try cwd.openFile(io, "src/main.zig", .{});
defer f.close(io);
const st = try f.stat(io);              // .size, .kind, .mode

// create directories
try cwd.createDir(io, "new", .default_dir);        // .fromMode(0o755) = custom mode
try cwd.createDirPath(io, "a/b/c");                // mkdir -p

// delete & rename (note: io comes last)
try cwd.deleteFile(io, "old.txt");
try cwd.rename("a.txt", cwd, "b.txt", io);

// list a directory — requires .iterate = true, no allocator needed
var d = try cwd.openDir(io, "src", .{ .iterate = true });
defer d.close(io);
var it = d.iterate();
while (try it.next(io)) |entry| {
    // entry.name: []const u8, entry.kind: .file / .directory / .sym_link / ...
}

// recursive walk (needs an allocator; next() needs io)
var walker = try cwd.walk(gpa);
defer walker.deinit();
while (try walker.next(io)) |entry| {
    // entry.path, entry.basename, entry.kind
}

// stat a path directly
const info = try cwd.statFile(io, "src/main.zig", .{});

// path utilities
std.fs.path.join(gpa, &.{ "a", "b", "c.zig" });   // "a/b/c.zig" (OS-aware)
std.fs.path.basename("a/b/c.zig")                 // "c.zig"
std.fs.path.dirname("a/b/c.zig")                  // "a/b"
std.fs.path.extension("x.tar.gz")                 // ".gz"
std.fs.max_path_bytes                             // OS path limit
```

## Networking

All via `std.Io.net` (0.16). A `Stream` can be wrapped in buffered reader/writers just like a file.

```zig
const io = init.io;

// --- TCP client ---
const addr = try std.Io.net.IpAddress.parse("127.0.0.1", 8080);
//   or resolve DNS (needs io): try std.Io.net.IpAddress.resolve(io, "example.com", 443)
const stream = try addr.connect(io, .{});
defer stream.close(io);

var wbuf: [4096]u8 = undefined;
var w = stream.writer(io, &wbuf);
try w.interface.writeAll("ping\n");
try w.interface.flush();

// --- TCP server ---
var server = try addr.listen(io, .{ .reuse_address = true });
while (true) {
    const conn = try server.accept(io);   // std.Io.net.Stream
    defer conn.close(io);
    var rbuf: [4096]u8 = undefined;
    var r = conn.reader(io, &rbuf);
    if (try r.interface.takeDelimiter('\n')) |line| {
        // process the line...
    }
}

// unix socket
const ua: std.Io.net.UnixAddress = ...;   // listen/connect also available
```

### One-screen HTTP client

```zig
var client: std.http.Client = .{ .allocator = init.gpa, .io = io };
defer client.deinit();

var aw: std.Io.Writer.Allocating = .init(init.gpa);
defer aw.deinit();

const result = try client.fetch(.{
    .location = .{ .url = "https://example.com" },
    .response_writer = &aw.writer,        // body is written here
});
// result.status: .ok, etc. — body in aw.written()
```

## Concurrency

> 0.16: synchronization primitives moved to **`std.Io`** and their methods need `io`
> (because they can become cancellation points). `std.Thread` (classic OS threads) still exists.

```zig
// --- thread ---
const t = try std.Thread.spawn(.{}, worker, .{ arg1, arg2 });
t.join();
std.Thread.yield() catch {};

// --- mutex (std.Io.Mutex) ---
var mu: std.Io.Mutex = .init;
try mu.lock(io);                // cancelable
defer mu.unlock(io);
// mu.lockUncancelable(io)      // cannot be cancelled
// mu.tryLock()                 // bool — non-blocking

// --- condition variable ---
var cond: std.Io.Condition = .init;
// thread A (waiting):
try cond.wait(io, &mu);         // releases the mutex automatically while waiting
// thread B (notifying):
cond.signal(io);                // or cond.broadcast(io)

// --- semaphore ---
var sem: std.Io.Semaphore = .{};    // permits default 0
sem.post(io);
try sem.wait(io);

// --- atomic ---
var val = std.atomic.Value(u32).init(0);
_ = val.fetchAdd(1, .monotonic);
_ = val.swap(0, .seq_cst);
val.store(5, .release);
const v = val.load(.acquire);
// compare-exchange:
if (val.cmpxchgStrong(5, 10, .seq_cst, .seq_cst)) |old| {}

// low-level atomic builtins
const a = @atomicLoad(u32, &plain_var, .seq_cst);
@atomicStore(u32, &plain_var, 1, .release);
```

## Process & environment

```zig
// --- CLI arguments ---
var args = init.minimal.args.iterate();
while (args.next()) |arg| {         // arg: [:0]const u8
    std.debug.print("{s}\n", .{arg});
}
// or grab them all at once (needs an allocator):
const all = try init.minimal.args.toSlice(init.arena.allocator());

// --- environment variables ---
const home = init.environ_map.get("HOME");     // ?[]const u8
try init.environ_map.put("MODE", "dev");       // set an env var for this process

// --- run a child process, capture output ---
const res = try std.process.run(init.gpa, init.io, .{
    .argv = &.{ "echo", "hi" },
    .cwd = .inherit,
    // .environ_map = ..., .stdout_limit = ...
});
defer init.gpa.free(res.stdout);
defer init.gpa.free(res.stderr);
switch (res.term) {
    .Exited => |code| if (code != 0) return error.CommandFailed,
    else => return error.CommandFailed,
}

// --- spawn without waiting ---
```

## Testing

```zig
const std = @import("std");

test "any name" {
    const alloc = std.testing.allocator;      // a leak = the test FAILS automatically

    var arena = std.heap.ArenaAllocator.init(alloc);
    defer arena.deinit();

    var list: std.ArrayList(u8) = .empty;
    defer list.deinit(alloc);
    try list.appendSlice(alloc, "hello");

    try std.testing.expectEqual(@as(usize, 4), list.items.len);
    try std.testing.expectEqualStrings("hello", list.items);
    try std.testing.expectEqualSlices(u8, "hello", list.items);
    try std.testing.expect(std.mem.eql(u8, "hello", list.items));
    try std.testing.expectError(error.Overflow, std.fmt.parseInt(u8, "999", 10));
}

test "sequential allocation failures" {
    // stress test: force OOM at every allocation position
    try std.testing.checkAllAllocationFailures(std.testing.allocator, myFunc, .{});
}
```

```sh
zig test src/main.zig            # run
zig test src/main.zig -lc        # needs libc
zig build test                   # via the build system
```

- `std.debug.assert(ok)` — gone in ReleaseFast, panics in other modes.
- Error traces on return: do not `catch` in tests — let them propagate.

## Minimal build.zig

```zig
const std = @import("std");

pub fn build(b: *std.Build) void {
    const target = b.standardTargetOptions(.{});   // -Dtarget=...
    const optimize = b.standardOptimizeOption(.{});// -Doptimize=...

    const mod = b.createModule(.{
        .root_source_file = b.path("src/main.zig"),
        .target = target,
        .optimize = optimize,
    });

    const exe = b.addExecutable(.{ .name = "app", .root_module = mod });
    b.installArtifact(exe);

    const run = b.addRunArtifact(exe);
    b.step("run", "Run the app").dependOn(&run.step);

    const tests = b.addTest(.{ .root_module = mod });
    b.step("test", "Run tests").dependOn(&tests.step);
}
```

```sh
zig build -Doptimize=ReleaseFast
zig build -Dtarget=x86_64-linux-musl      # cross-compile: WITHOUT any other toolchain
zig build -Dtarget=aarch64-windows
```

## Migrating 0.15 → 0.16

| Before (≤0.14 / 0.15) | Now (0.16) |
|---|---|
| `std.fs.File` | `std.Io.File` |
| `std.io.getStdOut()` | `std.Io.File.stdout()` |
| `file.writer()` / `file.reader()` (0.15) | `file.writer(io, &buf)` — explicit buffer + `io` |
| `std.io.getStdOut().writer().print(...)` | buffered `Io.Writer` + `flush()` |
| `file.close()` | `file.close(io)` |
| `std.net` | `std.Io.net` (and all ops need `io`) |
| `std.Thread.Mutex` | `std.Io.Mutex` (`lock(io)` etc.) |
| `std.time.Timer` | `io.now(clock)` — `Clock` = `.real`, `.awake`, `.monotonic` |
| `std.fs.cwd()` | `std.Io.Dir.cwd()` |
| `std.ArrayList` managed | unmanaged since 0.15 (`init` → `.empty`, allocator per method) |
| `pub fn main() !void` | still works, but `pub fn main(init: std.process.Init) !void` = idiomatic 0.16 (gpa + io ready to use) |

**Main sources:** [Zig 0.16.0 release notes](https://ziglang.org/download/0.16.0/release-notes.html) ·
[std lib source](https://github.com/ziglang/zig/tree/master/lib/std) — when in doubt, read
the `lib/std` source directly: Zig's std lib is heavily documented through doc-comments.
