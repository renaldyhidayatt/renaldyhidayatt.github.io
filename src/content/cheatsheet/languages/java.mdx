## Mental model 5 menit

| Konsep | Ringkasan |
| :--- | :--- |
| Reference vs value | Java **semua** object adalah reference; primitive = value |
| `final` | variabel tidak bisa reassign; untuk object, referensinya saja |
| `static` | milik class, bukan instance; shared state = sumber bug |
| `==` vs `equals` | `==` bandingkan reference (untuk primitive: nilai), `equals` bandingkan konten |
| `hashCode` | harus konsisten dengan `equals`; dipakai `HashMap`/`HashSet` |
| Immutability | default terbaik: `record`, `final class`, field `final` |
| Null | bagian dari tipe — gunakan Optional di API boundary, null check di internal |
| Exception | unchecked = bug programmer; checked = kontrak eksplisit |
| Class loading | satu classloader per nama; static init sekali |
| Generics | erased di runtime → tidak ada `new T[]` |

## Record, sealed, pattern matching

```java
// record: data carrier immutable, equals/hashCode/toString otomatis
public record Money(BigDecimal amount, String currency) {

    // compact constructor: validasi + normalisasi
    public Money {
        Objects.requireNonNull(currency, "currency required");
        if (amount == null || amount.signum() < 0) {
            throw new IllegalArgumentException("amount must be >= 0");
        }
        if (amount.scale() > 2) {
            amount = amount.setScale(2, RoundingMode.HALF_UP);
        }
    }

    // method tambahan boleh
    public Money plus(Money other) {
        if (!currency.equals(other.currency)) {
            throw new IllegalArgumentException("currency mismatch");
        }
        return new Money(amount.add(other.amount), currency);
    }
}
```

```java
// sealed interface: hierarki tipe tertutup (exhaustive switch)
public sealed interface PaymentResult
        permits PaymentResult.Success, PaymentResult.Declined, PaymentResult.Error {

    record Success(String authCode, Instant at) implements PaymentResult {}
    record Declined(String reason) implements PaymentResult {}
    record Error(String code, String message) implements PaymentResult {}
}
```

```java
// pattern matching untuk switch (Java 21) — exhaustiveness dicek compiler
String describe(PaymentResult result) {
    return switch (result) {
        case PaymentResult.Success s      -> "ok: " + s.authCode();
        case PaymentResult.Declined d     -> "declined: " + d.reason();
        case PaymentResult.Error e        -> "error " + e.code();
    };   // tanpa default → compiler wajib menangani semua
}
```

```java
// record deconstruction pattern
if (result instanceof PaymentResult.Success(String code, Instant at)) {
    log.info("auth {} at {}", code, at);
}

// switch dengan guard
String label = switch (status) {
    case PAID   when amount > 1_000_000 -> "PAID_BIG";
    case PAID                          -> "PAID";
    case PENDING                       -> "PENDING";
    default                            -> "OTHER";
};
```

| Fitur | Versi | Catatan |
| :--- | :--- | :--- |
| Record | 16 | compact constructor untuk validasi |
| Sealed interface | 17 | `permits` mengunci hierarki |
| Pattern switch | 21 | exhaustiveness dicek compiler |
| Text block | 15 | `"""` |
| `instanceof` pattern | 16 | tidak perlu cast manual |
| Virtual thread | 21 | `Thread.ofVirtual().start()` |
| Record pattern (deconstruct) | 21 | `case Point(int x, int y)` |

## Virtual thread & concurrency

```java
// virtual thread: ringan, thousands of them OK
Thread vt = Thread.ofVirtual().start(() -> handle(request));
vt.join();

// virtual thread + executor
try (var executor = Executors.newVirtualThreadPerTaskExecutor()) {
    Future<String> a = executor.submit(() -> callServiceA());
    Future<String> b = executor.submit(() -> callServiceB());
    System.out.println(a.get() + b.get());
}   // close() = wait, jangan lupa
```

```java
// ConcurrencyStructuredTaskScope (preview di 21 — masih perlu --enable-preview)
try (var scope = new StructuredTaskScope.ShutdownOnFailure()) {
    var t1 = scope.fork(() -> fetchUser(id));
    var t2 = scope.fork(() -> fetchOrders(id));
    scope.join();                      // gagal satu → semua dibatalkan
    return new Result(t1.get(), t2.get());
}
```

```java
// Concurrency-safe collection
var map = new ConcurrentHashMap<String, AtomicLong>();
map.computeIfAbsent("orders", k -> new AtomicLong()).incrementAndGet();

var list = new CopyOnWriteArrayList<>();   // read-heavy, write jarang
var queue = new LinkedBlockingQueue<Task>(1000);
```

| Primitif | Untuk |
| :--- | :--- |
| Virtual thread | I/O-bound: HTTP client, JDBC (dengan driver async) |
| Platform thread | CPU-bound: encode, kompresi, kalkulasi |
| `CompletableFuture` | komposisi async non-blocking |
| `StructuredTaskScope` | kelompok task dengan scoped lifetime (preview di 21) |
| `ConcurrentHashMap` | map yang diakses multi-thread |
| `synchronized` | lock monitor — **jangan** di hot path |
| `ReentrantLock` | butuh `tryLock`, timeout, atau fairness |
| `AtomicLong` | counter thread-safe |
| `CountDownLatch` | tunggu N event selesai |
| `Semaphore` | batasi jumlahgnekan Resource yang jalan bersamaan |

> **Jebakan:** virtual thread **tidak** membuat CPU-bound work cepat. `synchronized` di dalam
> virtual thread memblokir **carrier thread** (pool-nya kecil). Untuk CPU-bound, tetap pakai
> platform thread pool.

## Optional & Stream

```java
// Optional: hanya di API boundary, jangan jadi field
Optional<User> findById(Long id);
if (findById(id).isEmpty()) { ... }

userOpt.map(User::email)
      .filter(s -> s.contains("@"))
      .ifPresent(System.out::println);

userOpt.ifPresentOrElse(
    u -> log.info("found {}", u.id()),
    () -> log.warn("not found"));

// orElseThrow — lebih baik dari orElse(null)
User u = repo.findById(id).orElseThrow(() -> new UserNotFoundException(id));

// map/flatMap
Optional<Address> addr = user.flatMap(User::address);
```

```java
// stream
List<Order> paid = orders.stream()
    .filter(o -> o.status() == PAID)
    .sorted(Comparator.comparing(Order::createdAt).reversed())
    .toList();                     // Java 16+, unmodifiable

Map<String, List<Order>> byMerchant = orders.stream()
    .collect(Collectors.groupingBy(Order::merchantId));

Map<String, BigDecimal> total = orders.stream()
    .collect(Collectors.toMap(
        Order::id,
        Order::total,
        (a, b) -> a,                  // merge function WAJIB kalau key bisa duplikat
        BigDecimal::add));            // akumulator

BigDecimal sum = orders.stream()
    .map(Order::total)
    .reduce(BigDecimal.ZERO, BigDecimal::add);

Map<String, Long> counts = orders.stream()
    .collect(Collectors.groupingBy(Order::status, Collectors.counting()));

// parallel — hanya kalau stream besar & operation CPU-bound
long n = hugeList.parallelStream().filter(...).count();
```

| Yang sebaiknya dihindari | Pakai |
| :--- | :--- |
| `stream().count()` | `list.size()` |
| `for` loop dengan `if` penapis | `filter()` |
| `Optional.get()` tanpa check | `orElseThrow()` |
| `Collectors.toMap` tanpa merge | tambah merge function |
| `parallelStream` untuk I/O | `CompletableFuture` + IO-bound pool |
| Side effect di stream | `forEach` hanya untuk terminal void, sisain pure |

| Struktur | Pilih saat |

## Exception

```java
// custom exception
public class OrderNotFoundException extends RuntimeException {
    public OrderNotFoundException(Long id) {
        super("order not found: " + id);
    }
}

// try-with-resources
try (var conn = dataSource.getConnection();
     var ps = conn.prepareStatement(SQL)) {
    ps.setLong(1, id);
    try (var rs = ps.executeQuery()) {
        return map(rs);
    }
}   // close otomatis, even on exception

// multi-catch & chaining
try {
    process();
} catch (IllegalStateException | IllegalArgumentException e) {
    log.warn("bad input", e);
} catch (Exception e) {
    log.error("unexpected", e);
    throw new ServiceException("gagal memproses order", e);
}

// suppress exception
try {
    risky();
} catch (IOException e) {
    // diabaikan dengan sengaja
}
```

| Jenis | Quando dipakai |
| :--- | :--- |
| `RuntimeException` (unchecked) | bug programmer; tidak wajib catch |
| `IOException` (checked) |>I/O bisa gagal — wajib ditangani atau declare |
| IllegalArgumentException | input tidak valid |
| IllegalStateException | dipanggil pada state yang salah |
| NoSuchElementException | `Optional.get()` kosong |
| Custom domain exception | kilogram domain (mis. `InsufficientBalanceException`) |

> **Jebakan:** jangan`tthrow new RuntimeException(e)` tanpa pesan —cause saja hilang di log.

## Boxing, equality, hashing

```java
// autoboxing
Integer a = 127, b = 127;
a == b;                    // true (cache -128..127)
Integer c = 1000, d = 1000;
c == d;                    // false! (di luar cache) → WAJIB .equals()
c.equals(d);               // true

// equals & hashCode harus konsisten
@Override public boolean equals(Object o) {
    if (this == o) return true;
    if (!(o instanceof Order other)) return false;
    return id.equals(other.id);
}
@Override public int hashCode() { return id.hashCode(); }

// compareTo untuk Comparable
@Override public int compareTo(Order o) {
    return createdAt.compareTo(o.createdAt);
}
```

| Tipe | Cache | Peringatan |
| :--- | :--- | :--- |
| `Integer` | −128..127 | `==` di luar cache = salah |
| `Long` | −128..127 | sama |
| `Boolean` | TRUE/FALSE | selalu cache |
| `Character` | 0..127 | selalu cache |
| `Double`/`Float` | **tidak ada** | `==` tetap bandingkan nilai, tapi hati-hati |

> **Jebakan:** `Double`/`Float` **tidak** punya cache — `==` selalu bandingkan nilai, tapi
> `Double.valueOf(0.1) == 0.1` tetap bisaTJ fails karena representasi. Tetap pakai `equals()`
> atau `compareTo()`.

```java
import java.util.function.*;
import java.util.stream.*;

// functional interface bawaan
Function<String, Integer> parse = Integer::parseInt;
BiFunction<Integer, Integer, Integer> add = Integer::sum;
Predicate<String> notBlank = s -> !s.isBlank();
Consumer<String> log = System.out::println;
Supplier<List<String>> factory = ArrayList::new;
UnaryOperator<Integer> inc = x -> x + 1;
BinaryOperator<Integer> sum = Integer::sum;

IntStream.rangeClosed(1, 10).sum();
IntStream.range(0, n).map(i -> i * 2).boxed().toList();

// collectors penting
Map<Boolean, List<Order>> partitioned = orders.stream()
    .collect(Collectors.partitioningBy(o -> o.total().signum() > 0));

Map<String, Long> counts = orders.stream()
    .collect(Collectors.groupingBy(Order::status, Collectors.counting()));

Map<String, BigDecimal> totals = orders.stream()
    .collect(Collectors.groupingBy(
        Order::merchantId,
        Collectors.reducing(BigDecimal.ZERO, Order::total, BigDecimal::add)));

TreeMap<String, List<Order>> sorted = orders.stream()
    .collect(Collectors.groupingBy(Order::status, TreeMap::new, Collectors.toList()));

String csv = orders.stream().map(Order::id).collect(Collectors.joining(","));

// teeing (Java 12+): dua hasil sekaligus
record Stats(long count, BigDecimal total) {}
Stats stats = orders.stream().collect(Collectors.teeing(
    Collectors.counting(),
    Collectors.reducing(BigDecimal.ZERO, Order::total, BigDecimal::add),
    Stats::new));

// takeWhile (Java 9+)
List<Order> recent = sortedByDate.stream()
    .takeWhile(o -> o.createdAt().isAfter(cutoff))
    .toList();

// grouping + downstream mapping
Map<String, Set<String>> merchantsByStatus = orders.stream()
    .collect(Collectors.groupingBy(Order::status,
             Collectors.mapping(Order::merchantId, Collectors.toSet())));

// flatMap + Optional::stream
List<Item> items = orders.stream().flatMap(o -> o.items().stream()).toList();
List<String> emails = users.stream().map(User::email).flatMap(Optional::stream).toList();
```

| Kolektor | Hasil |
| :--- | :--- |
| `toList()` | List immutable (Java 16+) |
| `groupingBy` | `Map<K, List<V>>`; + downstream untuk agregasi |
| `partitioningBy` | `Map<Boolean, List<V>>` |
| `mapping` | transform nilai downstream |
| `reducing` | agregasi manual dalam downstream |
| `joining` | String dengan delimiter/prefix/suffix |
| `teeing` | dua kolektor sekaligus (Java 12+) |
| `summarizingInt` | count/sum/min/max/avg |

> **Jebakan:** `Collectors.toMap` tanpa merge function melempar `IllegalStateException` saat
> key duplikat — selalu sediakan merge.

## std lib: java.util.concurrent lengkap

```java
import java.util.concurrent.*;
import java.util.concurrent.atomic.*;
import java.util.concurrent.locks.*;

// executor: pilih berdasarkan jenis beban
try (var io = Executors.newVirtualThreadPerTaskExecutor()) {        // Java 21
    io.submit(() -> callRemote());
}
var cpuBound = Executors.newFixedThreadPool(Runtime.getRuntime().availableProcessors());
var scheduled = Executors.newScheduledThreadPool(2);
scheduled.scheduleAtFixedRate(task, 0, 1, TimeUnit.MINUTES);

// CompletableFuture
CompletableFuture<User> user = CompletableFuture.supplyAsync(() -> fetchUser(id), pool);
CompletableFuture<List<Order>> orders = CompletableFuture.supplyAsync(() -> fetchOrders(id), pool);

Result combined = user.thenCombine(orders, Result::new)
    .exceptionally(ex -> Result.empty())
    .orTimeout(3, TimeUnit.SECONDS)
    .join();

CompletableFuture.allOf(user, orders).join();
CompletableFuture.anyOf(user, orders).join();

// sinkronisasi
ConcurrentHashMap<String, AtomicInteger> hits = new ConcurrentHashMap<>();
hits.computeIfAbsent("k", k -> new AtomicInteger()).incrementAndGet();
hits.merge("k", 1, Integer::sum);

CopyOnWriteArrayList<String> listeners = new CopyOnWriteArrayList<>();   // read-heavy
BlockingQueue<Task> queue = new LinkedBlockingQueue<>(1000);            // backpressure
AtomicLong counter = new AtomicLong();
LongAdder adder = new LongAdder();          // kontensi tinggi: lebih cepat dari AtomicLong
adder.increment();
long total = adder.sum();

// latch & barrier
CountDownLatch latch = new CountDownLatch(3);
latch.countDown();
latch.await(5, TimeUnit.SECONDS);
CyclicBarrier barrier = new CyclicBarrier(3);      // reusable
Semaphore permits = new Semaphore(10);              // batasi konkurensi

// lock manual (bila butuh tryLock / timeout)
ReentrantLock lock = new ReentrantLock();
if (lock.tryLock(100, TimeUnit.MILLISECONDS)) {
    try { mutate(); } finally { lock.unlock(); }
}
ReadWriteLock rw = new ReentrantReadWriteLock();
```

| Kelas | Kapan |
| :--- | :--- |
| `newVirtualThreadPerTaskExecutor` | I/O-bound skala besar (Java 21) |
| `newFixedThreadPool` | CPU-bound dengan batas jelas |
| `newScheduledThreadPool` | job periodik |
| `CompletableFuture` | komposisi async, timeout, fallback |
| `ConcurrentHashMap` | map multi-thread (tidak boleh null) |
| `CopyOnWriteArrayList` | listener list, read >> write |
| `LinkedBlockingQueue` | producer-consumer + backpressure |
| `AtomicLong` / `LongAdder` | counter; LongAdder untuk kontensi tinggi |
| `CountDownLatch` | tunggu N event (sekali pakai) |
| `Semaphore` | batasi konkurensi (mis. jumlah koneksi) |

> **Jebakan:** executor tanpa `shutdown()` (atau try-with-resources) membuat JVM tidak pernah
> mati karena thread non-daemon. Tutup di `@PreDestroy` atau shutdown hook.

```java
import java.net.URI;
import java.net.http.*;
import java.time.Duration;

HttpClient client = HttpClient.newBuilder()
    .connectTimeout(Duration.ofSeconds(5))
    .version(HttpClient.Version.HTTP_2)
    .followRedirects(HttpClient.Redirect.NORMAL)
    .build();

HttpRequest req = HttpRequest.newBuilder(URI.create("https://api.example.com/orders"))
    .header("Content-Type", "application/json")
    .header("Authorization", "Bearer " + token)
    .timeout(Duration.ofSeconds(10))
    .POST(HttpRequest.BodyPublishers.ofString(json))
    .build();

// sinkron
HttpResponse<String> res = client.send(req, HttpResponse.BodyHandlers.ofString());
if (res.statusCode() >= 400) {
    throw new IllegalStateException("HTTP " + res.statusCode() + ": " + res.body());
}

// asinkron
client.sendAsync(req, HttpResponse.BodyHandlers.ofByteArray())
      .thenApply(HttpResponse::body)
      .exceptionally(ex -> new byte[0]);

// body besar langsung ke file
client.send(req, HttpResponse.BodyHandlers.ofFile(Path.of("/tmp/out.bin")));
```

| `timeout` per request | tanpa ini koneksi menggantung |
| `System.Logger` | cukup untuk library tanpa dependency |

## Jebakan (wajib dibaca)

| Jebakan | Gejalanya | Solusinya |
| :--- | :--- | :--- |
| `==` untuk String | Perbandingan gagal diam-diam | Selalu `.equals()` |
| `Integer` di luar cache | `==` false | `Objects.equals` |
| `equals` tanpa `hashCode` | Item hilang di `HashSet`/`HashMap` | Override dua-duanya |
| `Optional` sebagai field | NPE/null noise | Optional hanya di return type |
| `Optional.get()` | `NoSuchElementException` | `orElseThrow` |
| `Collectors.toMap` tanpa merge | `IllegalStateException` duplikat key | Kasih merge function |
| `stream().count()` | Lambat, alokasi | `size()` |
| `parallelStream` untuk I/O | Thread pool jadi bottleneck | `CompletableFuture` + executor I/O |
| `synchronized` di virtual thread | Carrier thread terblokir | Lock hanya untuk bagian kritis kecil |
| Resource tanpa try-with-resources | FD/koneksi bocor | `try (var x = ...)` |
| Exception tanpa pesan | Log tidak berguna | Pesan + konteks + cause |
| `LocalDate` untuk jam | Bug zona waktu | `Instant` (UTC) + `LocalDateTime` + `ZoneId` |
| `LocalDateTime` untuk timestamp | Ambigu | `Instant` / `OffsetDateTime` |
| `double` untuk uang | Selisih pembulatan | `BigDecimal` + `setScale` |
| `BigDecimal.equals` | `1.0` != `1.00` | `compareTo() == 0` |
| Divide tanpa scale | `ArithmeticException` | `divide(d, 2, RoundingMode.HALF_UP)` |
| HashMap sebagai field static | Race condition | `ConcurrentHashMap` |
| `Thread.stop()` | Thread mati di tengah | Interrupt + cancel |
| `finalize()` | Tidak dipanggil | `Cleaner`/`PhantomReference` |
| `System.gc()` | Tidak menjamin | Jangan pakai |
| Reflection di hot path | Overhead besar | Cache `Method`/constructor |
| `String.format` di loop | Alokasi berlimpah | `StringBuilder` atau `formatted` sekali |
| checked exception ditangkap lalu dibuang | Error hilang | Log + rethrow, atau strategi yang jelas |
