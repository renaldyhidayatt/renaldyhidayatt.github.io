## 5-minute mental model

| Concept | Summary |
| :--- | :--- |
| Reference vs value | In Java **all** objects are references; primitives = values |
| `final` | variable cannot be reassigned; for objects, only the reference is final |
| `static` | belongs to the class, not the instance; shared state = source of bugs |
| `==` vs `equals` | `==` compares references (for primitives: values), `equals` compares content |
| `hashCode` | must be consistent with `equals`; used by `HashMap`/`HashSet` |
| Immutability | best default: `record`, `final class`, `final` fields |
| Null | part of the type — use Optional at API boundaries, null checks internally |
| Exception | unchecked = programmer bug; checked = explicit contract |
| Class loading | one classloader per name; static init once |
| Generics | erased at runtime → no `new T[]` |

## Records, sealed, pattern matching

```java
// record: immutable data carrier, equals/hashCode/toString generated automatically
public record Money(BigDecimal amount, String currency) {

    // compact constructor: validation + normalization
    public Money {
        Objects.requireNonNull(currency, "currency required");
        if (amount == null || amount.signum() < 0) {
            throw new IllegalArgumentException("amount must be >= 0");
        }
        if (amount.scale() > 2) {
            amount = amount.setScale(2, RoundingMode.HALF_UP);
        }
    }

    // additional methods are allowed
    public Money plus(Money other) {
        if (!currency.equals(other.currency)) {
            throw new IllegalArgumentException("currency mismatch");
        }
        return new Money(amount.add(other.amount), currency);
    }
}
```

```java
// sealed interface: closed type hierarchy (exhaustive switch)
public sealed interface PaymentResult
        permits PaymentResult.Success, PaymentResult.Declined, PaymentResult.Error {

    record Success(String authCode, Instant at) implements PaymentResult {}
    record Declined(String reason) implements PaymentResult {}
    record Error(String code, String message) implements PaymentResult {}
}
```

```java
// pattern matching for switch (Java 21) — exhaustiveness checked by the compiler
String describe(PaymentResult result) {
    return switch (result) {
        case PaymentResult.Success s      -> "ok: " + s.authCode();
        case PaymentResult.Declined d     -> "declined: " + d.reason();
        case PaymentResult.Error e        -> "error " + e.code();
    };   // no default → compiler must handle all cases
}
```

```java
// record deconstruction pattern
if (result instanceof PaymentResult.Success(String code, Instant at)) {
    log.info("auth {} at {}", code, at);
}

// switch with guard
String label = switch (status) {
    case PAID   when amount > 1_000_000 -> "PAID_BIG";
    case PAID                          -> "PAID";
    case PENDING                       -> "PENDING";
    default                            -> "OTHER";
};
```

| Feature | Version | Notes |
| :--- | :--- | :--- |
| Record | 16 | compact constructor for validation |
| Sealed interface | 17 | `permits` locks the hierarchy |
| Pattern switch | 21 | exhaustiveness checked by the compiler |
| Text block | 15 | `"""` |
| `instanceof` pattern | 16 | no manual cast needed |
| Virtual thread | 21 | `Thread.ofVirtual().start()` |
| Record pattern (deconstruct) | 21 | `case Point(int x, int y)` |

## Virtual threads & concurrency

```java
// virtual thread: lightweight, thousands of them are OK
Thread vt = Thread.ofVirtual().start(() -> handle(request));
vt.join();

// virtual thread + executor
try (var executor = Executors.newVirtualThreadPerTaskExecutor()) {
    Future<String> a = executor.submit(() -> callServiceA());
    Future<String> b = executor.submit(() -> callServiceB());
    System.out.println(a.get() + b.get());
}   // close() = wait, do not forget it
```

```java
// StructuredTaskScope (preview in 21 — still needs --enable-preview)
try (var scope = new StructuredTaskScope.ShutdownOnFailure()) {
    var t1 = scope.fork(() -> fetchUser(id));
    var t2 = scope.fork(() -> fetchOrders(id));
    scope.join();                      // one fails → all are cancelled
    return new Result(t1.get(), t2.get());
}
```

```java
// Concurrency-safe collections
var map = new ConcurrentHashMap<String, AtomicLong>();
map.computeIfAbsent("orders", k -> new AtomicLong()).incrementAndGet();

var list = new CopyOnWriteArrayList<>();   // read-heavy, rare writes
var queue = new LinkedBlockingQueue<Task>(1000);
```

| Primitive | For |
| :--- | :--- |
| Virtual thread | I/O-bound: HTTP client, JDBC (with async driver) |
| Platform thread | CPU-bound: encoding, compression, computation |
| `CompletableFuture` | non-blocking async composition |
| `StructuredTaskScope` | group of tasks with scoped lifetime (preview in 21) |
| `ConcurrentHashMap` | map accessed from multiple threads |
| `synchronized` | monitor lock — **do not** use on the hot path |
| `ReentrantLock` | need `tryLock`, timeout, or fairness |
| `AtomicLong` | thread-safe counter |
| `CountDownLatch` | wait for N events to complete |
| `Semaphore` | limit how many resources run concurrently |

> **Pitfall:** virtual threads **do not** make CPU-bound work faster. `synchronized` inside a
> virtual thread blocks the **carrier thread** (its pool is small). For CPU-bound work, keep using
> a platform thread pool.

## Optional & Stream

```java
// Optional: only at API boundaries, do not make it a field
Optional<User> findById(Long id);
if (findById(id).isEmpty()) { ... }

userOpt.map(User::email)
      .filter(s -> s.contains("@"))
      .ifPresent(System.out::println);

userOpt.ifPresentOrElse(
    u -> log.info("found {}", u.id()),
    () -> log.warn("not found"));

// orElseThrow — better than orElse(null)
User u = repo.findById(id).orElseThrow(() -> new UserNotFoundException(id));

// map/flatMap
Optional<Address> addr = user.flatMap(User::address);
```

```java
// stream
List<Order> paid = orders.stream()
    .filter(o -> o.status() == PAID)
    .sorted(Comparator.comparing(Order::createdAt).reversed())
    .toList();                     // Java 16+, unmodifiable

Map<String, List<Order>> byMerchant = orders.stream()
    .collect(Collectors.groupingBy(Order::merchantId));

Map<String, BigDecimal> total = orders.stream()
    .collect(Collectors.toMap(
        Order::id,
        Order::total,
        (a, b) -> a,                  // merge function REQUIRED if keys can be duplicated
        BigDecimal::add));            // accumulator

BigDecimal sum = orders.stream()
    .map(Order::total)
    .reduce(BigDecimal.ZERO, BigDecimal::add);

Map<String, Long> counts = orders.stream()
    .collect(Collectors.groupingBy(Order::status, Collectors.counting()));

// parallel — only if the stream is large and the operation is CPU-bound
long n = hugeList.parallelStream().filter(...).count();
```

| What to avoid | Use |
| :--- | :--- |
| `stream().count()` | `list.size()` |
| `for` loop with a filtering `if` | `filter()` |
| `Optional.get()` without a check | `orElseThrow()` |
| `Collectors.toMap` without merge | add a merge function |
| `parallelStream` for I/O | `CompletableFuture` + IO-bound pool |
| Side effects in streams | `forEach` only for void terminal ops, keep the rest pure |

## Collections

```java
List<String> list = new ArrayList<>();
Set<String> set = new HashSet<>();
Map<String, Integer> map = new HashMap<>();

// immutable
List<String> immutable = List.of("a", "b");            // compact, immutable
List<String> mutable = new ArrayList<>(List.of("a"));   // copy of an immutable list
Map<String, Integer> imap = Map.of("a", 1);            // max 10 key-value pairs
Set<String> iset = Set.copyOf(list);

// LinkedHashMap = preserves order
Map<String, Integer> ordered = new LinkedHashMap<>();

// deque for stack/queue
Deque<String> dq = new ArrayDeque<>();
dq.push("a"); dq.pollFirst();

// Arrays
int[] nums = {1, 2, 3};
Arrays.sort(nums);
int idx = Arrays.binarySearch(nums, 2);
System.out.println(Arrays.toString(nums));

// convert
int[] arr = list.stream().mapToInt(Integer::intValue).toArray();
```

| Structure | Choose when |
| :--- | :--- |
| `ArrayList` | default, random access by index |
| `LinkedList` | frequent insert/remove in the middle (rarely the right choice in production) |
| `HashMap`/`HashSet` | default |
| `TreeMap`/`TreeSet` | need sorted order |
| `ArrayDeque` | stack/queue, performant |
| `EnumMap`/`EnumSet` | enum keys → array-backed, very fast |
| `ConcurrentHashMap` | multi-threaded |
| `CopyOnWriteArrayList` | read-mostly, lock-free iteration |

> **Pitfall:** `HashMap` is not thread-safe. `ConcurrentHashMap` does **not** allow `null`
> keys/values (NPE on put).

```java
// text block
String json = """
        {
          "name": "%s",

// automatic indentation is stripped based on the closing delimiter line
String sql = """
        SELECT id, total

```

```java
// String
String s = "abc";
s.length(); s.isEmpty(); s.isBlank();          // isBlank: only whitespace
s.trim(); s.strip();                           // strip: Unicode-aware
s.split(",", -1);                              // -1 = keep trailing empty strings
s.replace('a', 'b'); s.replaceAll("\\d+", "#");
s.substring(0, 3); s.chars().forEach(...);
s.repeat(3); s.lines().toList();
String.join(",", list);
"a,b".formatted("x");                          // String.formatted (15+)
Integer.parseInt("42");
String.join("", "a", "b");
```

| Method | Watch out for |
| :--- | :--- |
| `isEmpty()` vs `isBlank()` | `isBlank` is also true for `" \t"` |
| `split` without a limit | discards trailing empty strings |
| `equals` | compares **content**, not reference |
| `==` for String | **do not** — it compares references |
| `String.intern()` | Generally avoid; use the constant pool |

## Exceptions

```java
// custom exception
public class OrderNotFoundException extends RuntimeException {
    public OrderNotFoundException(Long id) {
        super("order not found: " + id);
    }
}

// try-with-resources
try (var conn = dataSource.getConnection();
     var ps = conn.prepareStatement(SQL)) {
    ps.setLong(1, id);
    try (var rs = ps.executeQuery()) {
        return map(rs);
    }
}   // closed automatically, even on exception

// multi-catch & chaining
try {
    process();
} catch (IllegalStateException | IllegalArgumentException e) {
    log.warn("bad input", e);
} catch (Exception e) {
    log.error("unexpected", e);
    throw new ServiceException("failed to process order", e);
}

// suppressed exception
try {
    risky();
} catch (IOException e) {
    // intentionally ignored
}
```

| Type | When to use |
| :--- | :--- |
| `RuntimeException` (unchecked) | programmer bug; not required to catch |
| `IOException` (checked) | I/O can fail — must be handled or declared |
| IllegalArgumentException | invalid input |
| IllegalStateException | called in the wrong state |
| NoSuchElementException | `Optional.get()` on empty |
| Custom domain exception | domain rules (e.g. `InsufficientBalanceException`) |

> **Pitfall:** do not `throw new RuntimeException(e)` without a message — only the cause is lost in the log.
> Always provide a message that states the **context** (id, value, operation).

## Boxing, equality, hashing

```java
// autoboxing
Integer a = 127, b = 127;
a == b;                    // true (cached -128..127)
Integer c = 1000, d = 1000;
c == d;                    // false! (outside the cache) → MUST use .equals()
c.equals(d);               // true

// equals & hashCode must be consistent
@Override public boolean equals(Object o) {
    if (this == o) return true;
    if (!(o instanceof Order other)) return false;
    return id.equals(other.id);
}
@Override public int hashCode() { return id.hashCode(); }

// compareTo for Comparable
@Override public int compareTo(Order o) {
    return createdAt.compareTo(o.createdAt);
}
```

| Type | Cache | Warning |
| :--- | :--- | :--- |
| `Integer` | −128..127 | `==` outside the cache = wrong |
| `Long` | −128..127 | same |
| `Boolean` | TRUE/FALSE | always cached |
| `Character` | 0..127 | always cached |
| `Double`/`Float` | **none** | `==` still compares values, but be careful |

> **Pitfall:** `Double`/`Float` have **no** cache — `==` always compares values, but
> `Double.valueOf(0.1) == 0.1` can still fail because of representation. Keep using `equals()`
> or `compareTo()`.

## std lib: java.time

```java
import java.time.*;
import java.time.format.DateTimeFormatter;
import java.time.temporal.ChronoUnit;

// the right type for the right context
Instant now = Instant.now();                       // UTC point in time - store in the DB
LocalDate today = LocalDate.now(ZoneId.of("Asia/Jakarta"));
LocalDateTime ldt = LocalDateTime.now();           // no zone - AVOID for timestamps
ZonedDateTime zdt = ZonedDateTime.now(ZoneId.of("Asia/Jakarta"));
OffsetDateTime odt = OffsetDateTime.now(ZoneOffset.UTC);

// conversion
ZonedDateTime z = now.atZone(ZoneId.of("Asia/Jakarta"));
Instant back = z.toInstant();
long epochMilli = now.toEpochMilli();
Instant fromMillis = Instant.ofEpochMilli(epochMilli);

// arithmetic
LocalDate nextMonth = today.plusMonths(1);
LocalDate endOfMonth = today.withDayOfMonth(today.lengthOfMonth());
long daysBetween = ChronoUnit.DAYS.between(today, nextMonth);
Duration d = Duration.between(startInstant, Instant.now());
Period p = Period.between(today, LocalDate.of(2027, 1, 1));

// format & parse (thread-safe, unlike SimpleDateFormat)
DateTimeFormatter custom = DateTimeFormatter.ofPattern("dd/MM/yyyy HH:mm")
        .withZone(ZoneId.of("Asia/Jakarta"));
String s = custom.format(now);
Instant parsed = Instant.parse("2026-10-21T03:00:00Z");
LocalDate parsedDate = LocalDate.parse("2026-10-21");

// clock for tests
Clock fixed = Clock.fixed(Instant.parse("2026-01-01T00:00:00Z"), ZoneId.of("UTC"));
LocalDate testToday = LocalDate.now(fixed);
```

| Type | Use for | Do not use for |
| :--- | :--- | :--- |
| `Instant` | event timestamps, DB column `TIMESTAMPTZ` | human calendar dates |
| `LocalDate` | date without time (due dates) | event timestamps |
| `LocalDateTime` | local schedules without a zone | storing to the DB across zones |
| `ZonedDateTime` | rendering for users | repeated cross-zone calculations |
| `OffsetDateTime` | APIs that carry an offset | complex zone conversions |
| `Duration` | time-based duration (seconds) | calendar differences (months) |
| `Period` | date difference (years/months/days) | precise durations |

> **Pitfall:** `LocalDateTime` does not store a zone — two servers in different zones produce
> different values for "the same hour". Store `Instant`, render in the user's zone.

## std lib: java.util.function & advanced Stream

```java
import java.util.function.*;
import java.util.stream.*;

// built-in functional interfaces
Function<String, Integer> parse = Integer::parseInt;
BiFunction<Integer, Integer, Integer> add = Integer::sum;
Predicate<String> notBlank = s -> !s.isBlank();
Consumer<String> log = System.out::println;
Supplier<List<String>> factory = ArrayList::new;
UnaryOperator<Integer> inc = x -> x + 1;
BinaryOperator<Integer> sum = Integer::sum;

// primitive streams - avoid boxing
IntStream.rangeClosed(1, 10).sum();
IntStream.range(0, n).map(i -> i * 2).boxed().toList();

// important collectors
Map<Boolean, List<Order>> partitioned = orders.stream()
    .collect(Collectors.partitioningBy(o -> o.total().signum() > 0));

Map<String, Long> counts = orders.stream()
    .collect(Collectors.groupingBy(Order::status, Collectors.counting()));

Map<String, BigDecimal> totals = orders.stream()
    .collect(Collectors.groupingBy(
        Order::merchantId,
        Collectors.reducing(BigDecimal.ZERO, Order::total, BigDecimal::add)));

TreeMap<String, List<Order>> sorted = orders.stream()
    .collect(Collectors.groupingBy(Order::status, TreeMap::new, Collectors.toList()));

String csv = orders.stream().map(Order::id).collect(Collectors.joining(","));

// teeing (Java 12+): two results at once
record Stats(long count, BigDecimal total) {}
Stats stats = orders.stream().collect(Collectors.teeing(
    Collectors.counting(),
    Collectors.reducing(BigDecimal.ZERO, Order::total, BigDecimal::add),
    Stats::new));

// takeWhile (Java 9+)
List<Order> recent = sortedByDate.stream()
    .takeWhile(o -> o.createdAt().isAfter(cutoff))
    .toList();

// grouping + downstream mapping
Map<String, Set<String>> merchantsByStatus = orders.stream()
    .collect(Collectors.groupingBy(Order::status,
             Collectors.mapping(Order::merchantId, Collectors.toSet())));

// flatMap + Optional::stream
List<Item> items = orders.stream().flatMap(o -> o.items().stream()).toList();
List<String> emails = users.stream().map(User::email).flatMap(Optional::stream).toList();
```

| Collector | Result |
| :--- | :--- |
| `toList()` | List immutable (Java 16+) |
| `groupingBy` | `Map<K, List<V>>`; + downstream for aggregation |
| `partitioningBy` | `Map<Boolean, List<V>>` |
| `mapping` | transform downstream values |
| `reducing` | manual aggregation in a downstream |
| `joining` | String with delimiter/prefix/suffix |
| `teeing` | two collectors at once (Java 12+) |
| `summarizingInt` | count/sum/min/max/avg |

> **Pitfall:** `Collectors.toMap` without a merge function throws `IllegalStateException` when
> a key is duplicated — always provide a merge function.

## std lib: complete java.util.concurrent

```java
import java.util.concurrent.*;
import java.util.concurrent.atomic.*;
import java.util.concurrent.locks.*;

// executor: choose based on the kind of load
try (var io = Executors.newVirtualThreadPerTaskExecutor()) {        // Java 21
    io.submit(() -> callRemote());
}
var cpuBound = Executors.newFixedThreadPool(Runtime.getRuntime().availableProcessors());
var scheduled = Executors.newScheduledThreadPool(2);
scheduled.scheduleAtFixedRate(task, 0, 1, TimeUnit.MINUTES);

// CompletableFuture
CompletableFuture<User> user = CompletableFuture.supplyAsync(() -> fetchUser(id), pool);
CompletableFuture<List<Order>> orders = CompletableFuture.supplyAsync(() -> fetchOrders(id), pool);

Result combined = user.thenCombine(orders, Result::new)
    .exceptionally(ex -> Result.empty())
    .orTimeout(3, TimeUnit.SECONDS)
    .join();

CompletableFuture.allOf(user, orders).join();
CompletableFuture.anyOf(user, orders).join();

// synchronization
ConcurrentHashMap<String, AtomicInteger> hits = new ConcurrentHashMap<>();
hits.computeIfAbsent("k", k -> new AtomicInteger()).incrementAndGet();
hits.merge("k", 1, Integer::sum);

CopyOnWriteArrayList<String> listeners = new CopyOnWriteArrayList<>();   // read-heavy
BlockingQueue<Task> queue = new LinkedBlockingQueue<>(1000);            // backpressure
AtomicLong counter = new AtomicLong();
LongAdder adder = new LongAdder();          // high contention: faster than AtomicLong
adder.increment();
long total = adder.sum();

// latch & barrier
CountDownLatch latch = new CountDownLatch(3);
latch.countDown();
latch.await(5, TimeUnit.SECONDS);
CyclicBarrier barrier = new CyclicBarrier(3);      // reusable
Semaphore permits = new Semaphore(10);              // limit concurrency

// manual lock (if you need tryLock / timeout)
ReentrantLock lock = new ReentrantLock();
if (lock.tryLock(100, TimeUnit.MILLISECONDS)) {
    try { mutate(); } finally { lock.unlock(); }
}
ReadWriteLock rw = new ReentrantReadWriteLock();
```

| Class | When |
| :--- | :--- |
| `newVirtualThreadPerTaskExecutor` | large-scale I/O-bound (Java 21) |
| `newFixedThreadPool` | CPU-bound with a clear bound |
| `newScheduledThreadPool` | periodic jobs |
| `CompletableFuture` | async composition, timeout, fallback |
| `ConcurrentHashMap` | multi-threaded map (must not contain null) |
| `CopyOnWriteArrayList` | listener lists, read >> write |
| `LinkedBlockingQueue` | producer-consumer + backpressure |
| `AtomicLong` / `LongAdder` | counter; LongAdder for high contention |
| `CountDownLatch` | wait for N events (single use) |
| `Semaphore` | limit concurrency (e.g. number of connections) |

> **Pitfall:** an executor without `shutdown()` (or try-with-resources) keeps the JVM from
> ever exiting because of non-daemon threads. Close it in `@PreDestroy` or a shutdown hook.

## std lib: regex, Math, BigDecimal

```java
import java.math.BigDecimal;
import java.math.MathContext;
import java.math.RoundingMode;
import java.util.regex.Matcher;
import java.util.regex.Pattern;

// regex: compile once, reuse many times
private static final Pattern EMAIL = Pattern.compile("^[^@\\s]+@[^@\\s]+\\.[^@\\s]+$");
boolean ok = EMAIL.matcher(input).matches();

Matcher m = Pattern.compile("(?<key>\\w+)=(?<val>[^&]+)").matcher(query);
while (m.find()) {
    String key = m.group("key");
    String val = m.group("val");
}
String masked = Pattern.compile("(\\d{4})\\d{8}").matcher(card).replaceAll("$1********");

// Math
Math.abs(-1); Math.max(1, 2);
Math.round(2.5);                       // long
Math.ceil(2.1); Math.floor(2.9);
Math.pow(2, 10); Math.sqrt(16);
Math.addExact(a, b);                   // ArithmeticException on overflow
Math.multiplyExact(a, b);
Math.toIntExact(l);

// BigDecimal - money

BigDecimal total = price.multiply(qty).setScale(2, RoundingMode.HALF_UP);
total.compareTo(BigDecimal.ZERO) > 0;                // compare with compareTo
total.divide(qty, 2, RoundingMode.HALF_UP);          // divide MUST specify scale + rounding
BigDecimal pct = total.multiply(new BigDecimal("0.11"), MathContext.DECIMAL64);
```

| Rule | Why |
| :--- | :--- |
| `new BigDecimal(String)` / `valueOf` | `new BigDecimal(0.1)` stores binary error |
| `compareTo` not `equals` | `1.0` != `1.00` according to equals |
| `divide` requires scale+rounding | non-terminating division -> `ArithmeticException` |
| `setScale(2, HALF_UP)` before saving | explicit business rounding spec |
| `Math.*Exact` for ids/money | silent overflow is an expensive bug |
| `SecureRandom` for tokens | `Math.random` is easily predictable |
| `Pattern` as `static final` | compiling regex is expensive |

> **Pitfall:** `BigDecimal.equals` also compares scale. Money rule: always
> normalize to `setScale(2, ...)` at the boundary, compare with `compareTo`.

## std lib: java.net.http & logging

```java
import java.net.URI;
import java.net.http.*;
import java.time.Duration;

HttpClient client = HttpClient.newBuilder()
    .connectTimeout(Duration.ofSeconds(5))
    .version(HttpClient.Version.HTTP_2)
    .followRedirects(HttpClient.Redirect.NORMAL)
    .build();

HttpRequest req = HttpRequest.newBuilder(URI.create("https://api.example.com/orders"))
    .header("Content-Type", "application/json")
    .header("Authorization", "Bearer " + token)
    .timeout(Duration.ofSeconds(10))
    .POST(HttpRequest.BodyPublishers.ofString(json))
    .build();

// synchronous
HttpResponse<String> res = client.send(req, HttpResponse.BodyHandlers.ofString());
if (res.statusCode() >= 400) {
    throw new IllegalStateException("HTTP " + res.statusCode() + ": " + res.body());
}

// asynchronous
client.sendAsync(req, HttpResponse.BodyHandlers.ofByteArray())
      .thenApply(HttpResponse::body)
      .exceptionally(ex -> new byte[0]);

// large body straight to a file
client.send(req, HttpResponse.BodyHandlers.ofFile(Path.of("/tmp/out.bin")));
```

| Item | Notes |
| :--- | :--- |
| `HttpClient` | created **once**, reused (it has an internal pool) |
| `BodyHandlers.ofString` | small; `ofFile`/`ofInputStream` for large |
| `timeout` per request | without it connections hang |
| `System.Logger` | sufficient for libraries with no dependencies |
| SLF4J | parameterized `log.info("{}", x)` — do not concatenate strings |

> **Pitfall:** a new `HttpClient` per request = repeated TCP+TLS handshakes and leaked threads.
> Store it as a `static final` field / singleton bean.

| JVM Pitfall | Symptom | Solution |
| :--- | :--- | :--- |
| Heap too small | OOM under load | Raise `MaxRAMPercentage`, check retention |
| Metaspace exhausted | `OutOfMemoryError: Metaspace` | Check classloader leaks, restart, reduce dynamic proxies |
| Frequent GC | Latency increases | Reduce allocations, tune `MaxGCPauseMillis` |
| Thread leak | Thread count keeps growing | `jcmd Thread.print` |
| Direct buffer leak | `OutOfMemoryError: Direct buffer memory` | Close buffers (`try-with-resources`) |

## Pitfalls (must read)

| Pitfall | Symptom | Solution |
| :--- | :--- | :--- |
| `==` for String | Comparison silently fails | Always `.equals()` |
| `Integer` outside the cache | `==` is false | `Objects.equals` |
| `equals` without `hashCode` | Items go missing in `HashSet`/`HashMap` | Override both |
| `Optional` as a field | NPE/null noise | Optional only in return types |
| `Optional.get()` | `NoSuchElementException` | `orElseThrow` |
| `Collectors.toMap` without merge | `IllegalStateException` on duplicate key | Provide a merge function |
| `stream().count()` | Slow, allocates | `size()` |
| `parallelStream` for I/O | Thread pool becomes a bottleneck | `CompletableFuture` + I/O executor |
| `synchronized` in a virtual thread | Carrier thread blocked | Lock only the small critical section |
| Resource without try-with-resources | FD/connection leaks | `try (var x = ...)` |
| Exception without a message | Useless logs | Message + context + cause |
| `LocalDate` for time | Time zone bugs | `Instant` (UTC) + `LocalDateTime` + `ZoneId` |
| `LocalDateTime` for timestamps | Ambiguous | `Instant` / `OffsetDateTime` |
| `double` for money | Rounding errors | `BigDecimal` + `setScale` |
| `BigDecimal.equals` | `1.0` != `1.00` | `compareTo() == 0` |
| Divide without scale | `ArithmeticException` | `divide(d, 2, RoundingMode.HALF_UP)` |
| HashMap as a static field | Race condition | `ConcurrentHashMap` |
| `Thread.stop()` | Thread dies mid-execution | Interrupt + cancel |
| `finalize()` | Not called | `Cleaner`/`PhantomReference` |
| `System.gc()` | Gives no guarantee | Do not use |
| Reflection on the hot path | Large overhead | Cache `Method`/constructor |
| `String.format` in a loop | Excess allocation | `StringBuilder` or `formatted` once |
| checked exception caught then discarded | Error disappears | Log + rethrow, or a clear strategy |
