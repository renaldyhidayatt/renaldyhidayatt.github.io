## 5-minute mental model

| Concept | Summary |
| :--- | :--- |
| Ownership | every value has **one** owner; when it is dropped, the value is gone |
| Borrowing | `&T` (read) or `&mut T` (write) — **never two mutable at once** |
| `move` | transfers ownership; the old value can no longer be used |
| Copy trait | `i32`, `bool`, `f64` = copied; `String`, `Vec` = moved |
| Drop | values are discarded automatically at the end of scope; the `Drop` trait for custom logic |
| Trait | a behavior contract; satisfied implicitly (no `implements`) |
| Generic | monomorphization — zero runtime overhead |
| `Option<T>` | a value that may be present |
| `Result<T, E>` | a result that may fail |
| `?` | quick error propagation |
| `panic!` | a program bug, **not** flow control |
| `unsafe` | escapes compiler checks; you hold the responsibilities |
| `Send`/`Sync` | markers for transferring across threads |
| Lifetime `'a` | the validity scope of a reference, not a duration |

## Ownership, borrow, lifetime

```rust
// move vs copy
let s1 = String::from("hello");
let s2 = s1;                 // move: s1 can no longer be used
// println!("{}", s1);       // error: value borrowed after move

let n1 = 5;
let n2 = n1;                 // copy (i32 = Copy)
println!("{} {}", n1, n2);  // safe

// borrow — not a move
fn len(s: &String) -> usize { s.len() }
let s = String::from("hello");
let l = len(&s);
println!("{} {}", s, l);     // s is still usable

// &mut — a mutable borrow, no other borrower may exist at that time
fn append_bang(s: &mut String) { s.push('!'); }
let mut s = String::from("hello");
append_bang(&mut s);

// slice: a view into part of a slice/array/String
fn first_word(s: &str) -> &str {
    s.split_whitespace().next().unwrap_or("")
}

// implicit lifetime elision
fn longest<'a>(a: &'a str, b: &'a str) -> &'a str { ... }

// explicit lifetime when the compiler needs it
struct Parser<'a> {
    input: &'a str,
    pos: usize,
}

impl<'a> Parser<'a> {
    fn new(input: &'a str) -> Self { Parser { input, pos: 0 } }
}
```

| Rule | Meaning |
| :--- | :--- |
| N borrows `&T` | many allowed **at the same time** |
| N borrows `&mut T` | **at most one** at a time |
| A borrow is always shorter than its owner | the owner must outlive the borrow |
| `&mut` to a struct = borrows **all fields** | field-level borrowing needs `split_at_mut` |

> **Pitfall:** `&mut` on a structural field blocks borrowing other fields of the same struct.
> Fix: `let [a, b] = slice.split_at_mut(i);` or `std::mem::take` / `Option::take`.

## Trait, generic, enum

```rust
// trait + impl
trait Repository {
    type Error;
    fn find(&self, id: u64) -> Result<Option<User>, Self::Error>;
    fn save(&mut self, user: &User) -> Result<(), Self::Error> {
        let _ = user;    // default implementation
        Ok(())
    }
}

struct PgRepo { pool: PgPool }

impl Repository for PgRepo {
    type Error = sqlx::Error;
    fn find(&self, id: u64) -> Result<Option<User>, sqlx::Error> { ... }
}

// generic with a trait bound
fn longest<T: AsRef<str>>(items: &[T]) -> &str {
    items.iter().map(|s| s.as_ref()).max().unwrap_or("")
}

// generic with a where clause
fn show<T>(v: &T) -> String
where
    T: std::fmt::Display + Clone,
{ v.to_string() }

// enum with data — the replacement for a tagged union
enum Message {
    Ping,
    Text(String),
    Move { x: i32, y: i32 },
    Data(Vec<u8>),
}

// impl trait in argument & return position
fn print_it(item: &impl ToString) { println!("{}", item); }
fn make_iter() -> impl Iterator<Item = u32> { (0..10).map(|x| x * 2) }

// trait statis (associated const/func)
trait Version { const MAJOR: u32; fn name() -> String; }
```

| Form | When |
| :--- | :--- |
| Generic `fn f<T: Trait>` | monomorphized at the call site (most common) |
| `impl Trait` in arguments | sugar for an anonymous generic |
| `impl Trait` in return | sugar for `-> impl Trait` |
| `dyn Trait` | dynamic dispatch (vtable) |
| Associated type | 1 concrete type per impl |
| Generic associated type (GAT) | a type that depends on `Self` |

> `impl Trait` in arguments = generic; `dyn Trait` = dynamic dispatch. If the trait is
> implemented by many types → use `dyn` (or an enum).

## Error handling

```rust
// explicit error enum
#[derive(Debug)]
enum AppError {
    NotFound(String),
    Db(sqlx::Error),
    InvalidInput { field: &'static str, reason: String },
}

impl std::fmt::Display for AppError {
    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
        match self {
            AppError::NotFound(id) => write!(f, "not found: {id}"),
            AppError::Db(e) => write!(f, "db error: {e}"),
            AppError::InvalidInput { field, reason } => write!(f, "invalid {field}: {reason}"),
        }
    }
}

impl std::error::Error for AppError {
    fn source(&self) -> Option<&(dyn std::error::Error + 'static)> {
        match self {
            AppError::Db(e) => Some(e),
            _ => None,
        }
    }
}

// From — automatic error conversion
impl From<sqlx::Error> for AppError {
    fn from(e: sqlx::Error) -> Self { AppError::Db(e) }
}

// ? — propagate + convert via From
fn load(id: u64) -> Result<User, AppError> {
    let row = sqlx::query!("SELECT * FROM users WHERE id = $1", id as i64)
        .fetch_optional(&pool)
        .await?;              // sqlx::Error -> AppError via From
    Ok(row.map(User::from).unwrap_or_default())
}

// anyhow for dynamic errors (an app, not a library)
use anyhow::{Context, Result, anyhow, bail};

fn process() -> Result<()> {
    let cfg = std::fs::read_to_string("config.json")
        .context("failed to read config.json")?;
    if cfg.is_empty() {
        bail!("config is empty");
    }
    Ok(())
}

// thiserror to derive Display/Error on an enum
#[derive(Debug, thiserror::Error)]
enum ParseError {
    #[error("invalid number: {0}")]
    InvalidNumber(String),
    #[error("io failure: {0}")]
    Io(#[from] std::io::Error),
}
```

| Approach | When |
| :--- | :--- |
| `Result<T, E>` + error enum | **Library**: the caller needs to know every variant |
| `anyhow::Result` | **Application**: the caller does not need to tell errors apart |
| `thiserror` | derive `Display` + `Error` for an enum |
| `?` | propagate errors (needs `From`) |
| `panic!` | bug / violated invariant — **never** for runtime errors |
| `unwrap()` / `expect()` | tests or invariants that are truly guaranteed |
| `.unwrap_or()` / `.unwrap_or_else()` | fallback value |
| `.ok()` | discard the error into an `Option` |

> **Pitfall:** `unwrap()` on a path that can fail = panic = dead process. If you are not certain,
> use `?`, `unwrap_or`, or `expect("invariant reason")` so the intent is clear.

## Option, Result, pattern matching

```rust
// Option
let opt: Option<i32> = Some(5);
match opt {
    Some(v) if v > 3 => println!("big: {v}"),
    Some(v) => println!("small: {v}"),
    None => println!("nothing"),
}

opt.map(|v| v * 2)
   .filter(|v| *v > 4)
   .unwrap_or(0);

opt.as_ref().map(|v| &v.to_string());
opt.as_deref();                       // Option<&T> → Option<&U>
opt.take();                           // take the value, leaving None (for &mut fields)

// let-else (1.65)
let Some(user) = find_user(id) else {
    return Err(AppError::NotFound(id.to_string()));
};

// if let chain (edition 2024)
if let Some(user) = find_user(id)
    && user.is_active()
{
    println!("active");
}

// Result
let res: Result<i32, String> = "42".parse::<i32>().map_err(|e| e.to_string());
match res {
    Ok(v) => println!("{v}"),
    Err(e) => println!("{e}"),
}

// if let ... else chain + let chain
match result {
    Ok(v) if v > 100 => {}
    Ok(v) => {}
    Err(e) => return Err(e.into()),
}
```

| Method | Meaning |
| :--- | :--- |
| `map` | transform if `Some` |
| `and_then` | transform into another `Option`/`Result` (**not** a nested Option) |
| `filter` | filter out when the predicate is false |
| `unwrap_or` | default (eager, computed even if unused) |
| `unwrap_or_else` | default (lazy) |
| `ok_or` | `Option` → `Result` |
| `ok_or_else` | same, lazy |
| `expect` | panic with a clear message |
| `is_some` / `is_none` | check without taking |

> **Pitfall:** `Option<Option<T>>` — use `and_then`, not `map`, so you don't end up with
> a confusing `Option<Option<T>>`.

## Collections

```rust
use std::collections::{HashMap, HashSet, BTreeMap, VecDeque};

// Vec
let mut v: Vec<i32> = Vec::new();
v.push(1);
v.extend([2, 3]);
let popped: Option<i32> = v.pop();
let first = v.first();
let slice = &v[0..2];                    // may panic if out of range
let slice = v.get(0..2);                  // Option, safe

// HashMap
let mut m: HashMap<String, i32> = HashMap::new();
m.insert("a".into(), 1);
m.entry("b".or_default()).or_insert(0);
if let Some(v) = m.get_mut("a") { *v += 1; }
let removed = m.remove("a");
let (k, v) = m.get_key_value("a").unwrap_or((&"".to_string(), &0));

// HashSet
let mut s: HashSet<u32> = HashSet::new();
s.insert(1);
s.contains(&1);

// BTreeMap — sorted (O(log n))
let mut b: BTreeMap<String, i32> = BTreeMap::new();

// iteration
for (k, v) in &m { ... }
for v in m.values() { ... }
for k in m.keys() { ... }
let mut keys: Vec<_> = m.keys().cloned().collect();
keys.sort();                              // HashMap output is unordered!

// filter + collect
let big: Vec<_> = m.iter().filter(|(_, v)| **v > 10).map(|(k, v)| (k.clone(), *v)).collect();

// entry API
let count = words.entry(word).or_insert(0);
*count += 1;

// VecDeque
let mut dq: VecDeque<u32> = VecDeque::new();
dq.push_back(1);
dq.push_front(0);
dq.pop_front();
```

| Structure | Ordered | Lookup complexity |
| :--- | :--- | :--- |
| `Vec<T>` | yes (by insert) | O(n) linear search |
| `HashMap<K,V>` | **no** | O(1) on average |
| `BTreeMap<K,V>` | yes | O(log n) |
| `HashSet<T>` | no | O(1) on average |
| `BTreeSet<T>` | yes | O(log n) |
| `VecDeque<T>` | yes (FIFO) | O(1) at both ends |

> **Pitfall:** `HashMap` output order is **random** between runs. If you need determinism
> (tests, CLI output, diffs), sort first.

## String & formatting

```rust
let s = String::from("hello");
let t = "world";                    // &str, literal
let u = s.clone();                  // duplicate
let v = s + t;                      // consumes s
let w = format!("{s} {t}");         // interpolation (1.58+)

s.push_str("!");
s.len(); s.chars().count();          // len = bytes, chars = unicode characters
s.contains("ha");
s.split_whitespace().collect::<Vec<_>>();

// &str → String
let owned: String = t.to_owned();
let owned2: String = String::from(t);

// String → &str (a borrow, no allocation)
let view: &str = &owned;

// format with specifiers
format!("{:<10}|", "left");     // left-aligned
format!("{:>10}|", "right");     // right-aligned
format!("{:^10}|", "center");    // centered
format!("{:.2}", 3.14159);       // precision
format!("{:#x}", 255);            // 0xff
format!("{:08.3}", 3.14159);      // zero-pad + precision
format!("{name} {age}", name = "budi", age = 30);   // named arg

// write! into a buffer without allocating
use std::fmt::Write;
let mut out = String::new();
write!(out, "{}-{}", 1, 2).unwrap();
```

| Type | Meaning |
| :--- | :--- |
| `&str` | a string slice, **no allocation** |
| `String` | an owned string, it can grow |
| `char` | one Unicode scalar value (not a byte) |
| `Vec<u8>` | raw bytes |

> **Pitfall:** `s.len()` counts **bytes**, not characters. `"é".len() == 2`. Use
> `s.chars().count()` for the character count.

## Async & concurrency

```rust
use tokio::sync::{Mutex, RwLock, mpsc, Semaphore};
use tokio::task::JoinSet;

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    // spawn
    let handle = tokio::spawn(async move {
        fetch("https://example.com").await
    });
    let body = handle.await??;          // JoinError then AppError

    // JoinSet — a group of tasks
    let mut set = JoinSet::new();
    for id in ids {
        set.spawn(async move { fetch(id).await });
    }
    while let Some(res) = set.join_next().await {
        results.push(res??);
    }

    // select
    tokio::select! {
        r = fetch_a() => handle_a(r),
        r = fetch_b() => handle_b(r),
        _ = tokio::time::sleep(Duration::from_secs(2)) => timeout(),
    }

    // semaphore — limit concurrency
    let sem = Semaphore::new(10);
    let permit = sem.acquire().await?;

    // channel
    let (tx, mut rx) = mpsc::channel(100);
    tokio::spawn(async move { tx.send(item).await });
    while let Some(item) = rx.recv().await { ... }

    Ok(())
}

// select! with timeout & cancel
let result = tokio::time::timeout(Duration::from_secs(5), slow_call()).await;
```

| Primitive | For |
| :--- | :--- |
| `tokio::spawn` | background task |
| `JoinSet` | many tasks, collect results one by one |
| `select!` | pick the first operation to finish |
| `Semaphore` | limit concurrent operations |
| `mpsc` | channel multi-producer single-consumer |
| `broadcast` | multi-consumer, every consumer gets all messages |
| `watch` | the latest state (config/feature flag) |
| `Mutex` | write critical section |
| `RwLock` | many readers, one writer |
| `Notify` | wake up a waiting task |
| `CancellationToken` | cancel a group of tasks |

> **Pitfall:** `std::sync::Mutex` **must not** be held across `.await` — it can deadlock
> (the task holding the lock is suspended, the lock is held forever). Use `tokio::sync::Mutex`.

## Unsafe

```rust
// unsafe block — you hold the responsibilities
unsafe {
    let p = raw_ptr::read(ptr);       // read without checks
    raw_ptr::write(ptr, new_value);
}

// the safety contract MUST be documented
/// # Safety
///
/// `ptr` must point to a valid `T` value and the caller must ensure there is no
/// aliasing that violates the borrow rules.
unsafe fn read_value<T>(ptr: *const T) -> T {
    unsafe { *ptr }
}

// FFI
extern "C" {
    fn strlen(s: *const c_char) -> usize;
}

let c = CString::new("hello")?;
let len = unsafe { strlen(c.as_ptr()) };

// slice from raw parts
let arr: [i32; 3] = [1, 2, 3];
let slice = unsafe { std::slice::from_raw_parts(arr.as_ptr(), arr.len()) };
```

| Rule | Detail |
| :--- | :--- |
| `unsafe` | the compiler cannot guarantee it; you are accountable |
| Aliasing | no `&mut` and `&` to the same data at the same time |
| Pointers must be valid | aligned, initialized, and alive while in use |
| `# Safety` | mandatory in the doc comment of every `unsafe fn` |
| Miri | a tool for finding UB — run it in CI |

> **Pitfall:** `unsafe` does not mean "unchecked code" — it means "code that needs
> manual guarantees". A bug here = undefined behavior, not a panic.

## std: advanced `std::collections`

```rust
use std::collections::{BTreeMap, HashMap, VecDeque, BinaryHeap};

// HashMap: entry API & initial capacity
let mut counts: HashMap<&str, u32> = HashMap::with_capacity(64);
for w in words {
    *counts.entry(w).or_insert(0) += 1;
}
counts.entry("k").and_modify(|v| *v += 1).or_insert(1);
counts.get("k");
counts.retain(|_, v| *v > 1);
for (k, v) in &counts { let _ = (k, v); }

// BTreeMap: ordered iteration, range queries
let mut b: BTreeMap<u64, &str> = BTreeMap::new();
b.insert(3, "c");
for (k, v) in b.range(2..=3) { let _ = (k, v); }
b.first_key_value();
b.last_key_value();

// VecDeque: FIFO/LIFO ring buffer
let mut q: VecDeque<u32> = VecDeque::with_capacity(32);
q.push_back(1); q.push_front(0);
q.make_contiguous();
let (a, b) = q.as_slices();

// BinaryHeap: priority queue (max-heap)
let mut heap = BinaryHeap::new();
heap.push(5); heap.push(9);
let top = heap.peek();
let mut minheap = BinaryHeap::new();
minheap.push(std::cmp::Reverse(5));      // min-heap

// sort & dedup
let mut v = vec![3, 1, 3, 2];
v.sort();                       // stable
v.dedup();                      // remove consecutive duplicates
v.sort_unstable();              // faster, not stable
v.sort_by_key(|x| -*x);         // descending
v.sort_by(|a, b| b.cmp(a));     // full control

// binary_search: the slice must be sorted
let idx = v.binary_search(&3);

// safe access
let got = v.get(10).copied().unwrap_or_default();
```

| Type | Characteristics |
| :--- | :--- |
| `HashMap` | O(1) on average, random order |
| `BTreeMap` | O(log n), sorted, supports `range` |
| `VecDeque` | O(1) at both ends, `as_slices` for contiguous access |
| `BinaryHeap` | max-heap; `Reverse` for a min-heap |
| `HashSet` / `BTreeSet` | sets of the types above |
| `SmallVec` (crate) | inline storage for small collections |

> **Pitfall:** `sort()` cannot be used on `f64` (not `Ord`) — use
> `sort_by(|a, b| a.partial_cmp(b).unwrap())`.

## std: string, format, regex & parsing

```rust
let s = String::from("héllo");
let n_bytes = s.len();              // bytes
let n_chars = s.chars().count();    // characters
let cap = s.capacity();
s.get(0..2);                        // Option, safe across UTF-8 boundaries
s.is_char_boundary(2);

// split & parse
let parts: Vec<&str> = "a,b,,c".split(',').collect();
"key=value".split_once('=');        // Option<(&str, &str)>
"  x ".trim(); "  x ".trim_start();
"a-b-c".rsplitn(2, '-').collect::<Vec<_>>();

// build string efisien
let mut out = String::with_capacity(128);
out.push_str("id=");
out.push_str(&id.to_string());
out.push(';');

// case & char
'a'.is_uppercase();
s.to_lowercase();                   // allocates
s.chars().rev().collect::<String>();
s.as_bytes();                       // &[u8]

// advanced formatting
format!("{name:>8}|{id:04}", name = "budi", id = 7);
format!("{:?} {:#?}", v, v);        // Debug, pretty Debug

// parse into a type
let n: i64 = "42".parse()?;
let f: f64 = "3.14".parse().unwrap_or(0.0);
```

| Package | Notes |
| :--- | :--- |
| `std::str` | `split`, `split_once`, `lines`, `trim`, `parse` |
| `String` | `with_capacity` avoids realloc |
| `regex` (crate) | compile once, keep it in a `static LazyLock` |
| `serde` + `serde_json` | de-facto standard; `#[serde(rename)]` for API contracts |
| `std::fmt` | `{:?}`, `{:#?}`, `{:>8}`, `{:04}`, custom `Display` |

> **Pitfall:** slicing `&s[..n]` in the middle of a UTF-8 character = panic. Use
> `char_indices()` or `s.get(..n)`.

## std: file, path, process & env

```rust
use std::env;
use std::fs;
use std::io::{BufRead, BufReader, BufWriter, Write};
use std::path::{Path, PathBuf};

// read & write
let text = fs::read_to_string("config.toml")?;
let bytes = fs::read("image.png")?;
fs::write("out.txt", text.as_bytes())?;
fs::create_dir_all("/tmp/a/b")?;
fs::remove_file("f.txt")?;
for e in fs::read_dir(".")?.filter_map(Result::ok) {
    let _ = e.path();
}

// buffered line-by-line I/O
let f = fs::File::open("access.log")?;
for line in BufReader::new(f).lines() {
    let line = line?;
    let _ = line;
}

// buffered writes (explicit flush)
let mut w = BufWriter::new(fs::File::create("out.csv")?);
writeln!(w, "id,total")?;
w.write_all(b"1,1500\n")?;
w.flush()?;

// path
let p = Path::new("/var/app/config.yaml");
p.file_name(); p.parent(); p.extension();
let joined = Path::new("/var").join("app").join("x.toml");
let canonical = fs::canonicalize(p)?;     // resolve symlinks
let mut pb = PathBuf::from(env::temp_dir());
pb.push("x");

// process
let out = std::process::Command::new("git")
    .args(["rev-parse", "--short", "HEAD"])
    .output()?;
if out.status.success() {
    let sha = String::from_utf8_lossy(&out.stdout).trim().to_string();
}

// env
let port = env::var("PORT").unwrap_or_else(|_| "8080".into());
let args: Vec<String> = std::env::args().skip(1).collect();
```

| API | Notes |
| :--- | :--- |
| `fs::read_to_string` | small files; use `BufReader` for large ones |
| `BufReader::lines()` | allocates per line; `read_line(&mut buf)` to reuse |
| `BufWriter` | explicit flush to catch write errors |
| `canonicalize` | resolves symlinks; fails on paths that don't exist yet |
| `Command::output` | captures stdout/stderr |
| `env::var_os` | for non-UTF-8 values |

> **Pitfall:** a `BufWriter` dropped without `flush()` swallows write errors. Always
> `flush()?` before leaving the scope.

## std: thread, channel, Mutex, time

```rust
use std::sync::{Arc, Mutex, RwLock, atomic::{AtomicUsize, Ordering}};
use std::sync::mpsc;
use std::thread;
use std::time::{Duration, Instant, SystemTime, UNIX_EPOCH};

// thread + join
let h = thread::spawn(move || {
    thread::sleep(Duration::from_millis(10));
    42
});
let v = h.join().unwrap();

// Arc<Mutex<T>>: shared mutable state
let counter = Arc::new(Mutex::new(0u64));
let handles: Vec<_> = (0..8).map(|_| {
    let c = Arc::clone(&counter);
    thread::spawn(move || {
        let mut n = c.lock().unwrap();
        *n += 1;
    })
}).collect();
for h in handles { h.join().unwrap(); }

// RwLock: many readers
let rw = Arc::new(RwLock::new(vec![1, 2, 3]));
{ let guard = rw.read().unwrap(); assert_eq!(guard.len(), 3); }
{ let mut guard = rw.write().unwrap(); guard.push(4); }

// atomic
let hits = Arc::new(AtomicUsize::new(0));
hits.fetch_add(1, Ordering::Relaxed);

// mpsc channel
let (tx, rx) = mpsc::channel();
for i in 0..3 {
    let tx = tx.clone();
    thread::spawn(move || tx.send(i).unwrap());
}
drop(tx);                                   // close the original sender
for msg in rx { println!("{msg}"); }

// bounded channel = backpressure
let (btx, brx) = mpsc::sync_channel::<u32>(8);

// scoped thread (1.63+): may borrow stack data
let data = vec![1, 2, 3];
thread::scope(|s| {
    s.spawn(|| println!("{}", data.len()));
});

// time
let start = Instant::now();
let elapsed = start.elapsed();
let since_epoch = SystemTime::now().duration_since(UNIX_EPOCH)?.as_secs();
```

| Primitive | When |
| :--- | :--- |
| `thread::scope` | threads that need a non-`'static` `&T` (no `Arc`) |
| `Arc<Mutex<T>>` | shared state that gets written |
| `Arc<RwLock<T>>` | read-heavy workloads |
| `Atomic*` | counters/flags without locks |
| `mpsc::channel` | unbounded, multi-producer |
| `mpsc::sync_channel` | bounded (backpressure) |
| `Instant` | measure durations (monotonic) |
| `SystemTime` | absolute timestamps (can go backwards) |

> **Pitfall:** `std::sync::Mutex` must not be held across `.await` (deadlock in async).
> Use `tokio::sync::Mutex` on async paths.

## std: Display and commonly derived traits

```rust
use std::fmt;

#[derive(Debug, Clone, PartialEq, Eq, Hash, Default)]
struct User {
    id: u64,
    name: String,
}

// Display custom
impl fmt::Display for User {
    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
        write!(f, "User({}, {})", self.id, self.name)
    }
}

// From -> Into automatically
impl From<(u64, &str)> for User {
    fn from((id, name): (u64, &str)) -> Self {
        User { id, name: name.to_string() }
    }
}
let u: User = (1, "budi").into();

// Default + update
let u2 = User { id: 2, ..Default::default() };

// FromStr -> "x".parse::<T>()
impl std::str::FromStr for User {
    type Err = std::num::ParseIntError;
    fn from_str(s: &str) -> Result<Self, Self::Err> {
        Ok(User { id: s.parse()?, name: s.to_string() })
    }
}

// Ord for sorting
#[derive(PartialOrd, Ord)]
struct Priority(u8);
```

| Trait | Derive? | Use for |
| :--- | :--- | :--- |
| `Debug` | yes | logging, tests |
| `Clone` / `Copy` | yes | duplication (Copy only for small types without Drop) |
| `PartialEq` / `Eq` | yes | comparison |
| `Hash` | yes | `HashMap` keys |
| `Default` | yes | `..Default::default()` |
| `Display` | no | user-facing output |
| `From`/`Into` | no | conversion (`?` uses `From`) |
| `FromStr` | no | `"x".parse::<T>()` |
| `AsRef` | no | flexible parameters (`&str`, `Path`) |
| `Deref` | no | smart pointers only — not "inheritance" |

> **Pitfall:** a derived `PartialEq` compares **all** fields — don't include
> cache/derived fields in domain comparisons.

## Pitfalls (must read)

| Pitfall | Symptom | Fix |
| :--- | :--- | :--- |
| `std::sync::Mutex` across `.await` | Deadlock | `tokio::sync::Mutex` |
| `unwrap()` on a runtime path | Dead process | `?`, `unwrap_or`, `expect` |
| Excessive `clone()` | Allocation spikes | Borrow `&T`, borrow fields |
| Mixing `String` vs `&str` | Needless allocations | `&str` for arguments |
| `.iter()` then `collect::<Vec<_>>()` | Extra allocation | `.iter()` alone is enough to iterate |
| `format!` in a loop | Allocation per iteration | `write!` into a reused `String` |
| Borrow checker failure | "cannot borrow as mutable" | `split_at_mut`, `Option::take`, `mem::replace` |
| `Arc<Mutex<T>>` for read-heavy data | Total serialization | `RwLock` or a channel (actor) |
| `HashMap` without `Default` | compile error | `#[derive(Default)]` |
| Large structs copied | Stack overflow / allocation | Box, or derive `Clone` carefully |
| `Box<dyn Error>` on a hot path | Allocation per error | `anyhow` or a concrete enum |
| Async fn without a time limit | Task hangs | `tokio::time::timeout` |
| `spawn` without join | Task hangs / panic swallowed | `JoinSet` or a stored `JoinHandle` |
| Blocking call in an async context | Event loop stalls | `spawn_blocking` |
| `unsafe` without `# Safety` | Hard-to-diagnose bugs | Document the contract |
| Old edition (`2018`) | New features unavailable | Migrate: `cargo fix --edition` |
| MSRV not tested | Builds fail on older CI | Set `rust-version` + check in CI |
