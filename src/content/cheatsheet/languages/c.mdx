## Mental model & compilation pipeline

```text
main.c ──preprocessor──▶ main.i ──compiler──▶ main.s ──assembler──▶ main.o ──linker──▶ main
         gcc -E                        gcc -S                   gcc -c                 gcc
```

| Stage | What happens | Watch out for |
| :--- | :--- | :--- |
| Preprocessor | `#include`/`#define` are replaced **textually** | no scope; macros = text substitution |
| Compiler | C → assembly; type checking, optimization | `-O0` vs `-O2` can behave differently |
| Assembler | assembly → object file | machine code exists, symbols not yet connected |
| Linker | object + library → executable | resolving symbols (`main`, `printf`) |

**Three rules that explain almost every C bug:**

1. **No object bounds are checked.** An array = pointer to the first element; the index is not
   validated. The compiler is the only guardrail, and it can be bypassed with a cast.
2. **UB = "anything can happen"**, including a program that looks correct. The compiler assumes UB
   does not occur, so optimization can change the meaning of the program.
3. **No GC.** Ownership is explicit: whoever `malloc`s, `free`s.

## Toolchain: gcc, make, sanitizers

```bash
# MANDATORY on every compile
gcc -std=c11 -Wall -Wextra -g source.c -o prog

# release
gcc -std=c11 -Wall -Wextra -O2 -DNDEBUG source.c -o prog

# sanitizers (mandatory during development)
gcc -std=c11 -Wall -Wextra -g -O2 \
    -fsanitize=address,undefined -fno-omit-frame-pointer \
    source.c -o prog_asan
./prog_asan          # must be 0 errors AND 0 leaks

# data race
gcc -std=c11 -g -fsanitize=thread -pthread source.c -o prog_tsan
```

| Flag | Meaning |
| :--- | :--- |
| `-std=c11` / `-std=c17` | language standard (do not use the gcc default) |
| `-Wall -Wextra -Wpedantic` | warnings = bugs that haven't blown up yet |
| `-Wconversion -Wshadow` | implicit conversions & shadowed variables |
| `-g` | debug symbols (without this gdb/asan are blind) |
| `-O0`/`-O1`/`-O2`/`-O3` | optimization level |
| `-DNDEBUG` | disable `assert()` |
| `-fsanitize=address,undefined` | overflow, use-after-free, leaks, UB |
| `-fsanitize=thread` | data races |
| `-fsanitize=memory` (clang) | reads of uninitialized memory |
| `-fno-omit-frame-pointer` | accurate stack traces |
| `-pthread` | link POSIX threads |
| `-lm` | link the math library |
| `-fanalyzer` | gcc static analysis |

```makefile
# Minimal Makefile — recipe lines MUST use a TAB
CC     := gcc
CFLAGS := -std=c11 -Wall -Wextra -g
SAN    := -fsanitize=address,undefined -fno-omit-frame-pointer

.PHONY: all asan clean

all: prog

prog: main.c util.c util.h
	$(CC) $(CFLAGS) main.c util.c -o $@

asan: main.c util.c util.h
	$(CC) $(CFLAGS) $(SAN) main.c util.c -o prog_asan
	./prog_asan

clean:
	rm -f prog prog_asan
```

> **Pitfall:** Makefile recipe lines **must** start with a TAB — spaces produce a
> confusing "missing separator".

## Basic types & conversions

```c
#include <stdint.h>     /* int32_t, uint64_t, SIZE_MAX */
#include <stddef.h>     /* size_t, ptrdiff_t, NULL, offsetof */
#include <stdbool.h>    /* bool, true, false */
#include <inttypes.h>   /* PRIu64, PRId32 */
#include <limits.h>     /* INT_MAX, CHAR_BIT */
```

| Type | Size (typical) | Notes |
| :--- | :--- | :--- |
| `char` | 1 | signed/unsigned **implementation-defined** — don't use for arithmetic |
| `signed char` / `unsigned char` | 1 | use these for bytes |
| `int8_t`..`uint64_t` | 1..8 | fixed width, required in C99+ |
| `size_t` | pointer size | **unsigned**; result of `sizeof` |
| `ptrdiff_t` | pointer size | *signed*; result of pointer subtraction |
| `intptr_t`/`uintptr_t` | pointer size | pointer ↔ integer conversion |
| `float`/`double`/`long double` | 4/8/≥8 | IEEE-754 (long double is platform-dependent) |
| `_Bool`/`bool` | 1 | any non-zero value = true |
| `void *` | — | generic pointer, no arithmetic |

```c
size_t n = (size_t)count;              /* explicit = documentation */
uint64_t bytes = 1024;
printf("%" PRIu64 " bytes\n", bytes);  /* format macro, not %llu */

if (value > INT32_MAX) return -1;      /* check the range BEFORE the cast */
int32_t v = (int32_t)value;
```

| Conversion | Behavior |
| :--- | :--- |
| integer → integer (narrower) | implementation-defined if it doesn't fit |
| `int` → `double` | precision lost above 2^53 |
| `double` → `int` | **UB** if out of range / NaN |
| `unsigned` → `signed` | implementation-defined if it doesn't fit |
| pointer → integer | implementation-defined (requires `uintptr_t`) |
| integer → pointer | implementation-defined |

> **Pitfall:** a float→int cast that overflows is not an "odd value" — it is **UB**, and the compiler
> may delete the entire branch. Always check the range first.

## Operators & control flow

```c
if (p != NULL && p->len > 0) { ... }      /* short-circuit: right side not evaluated */

for (int i = 0, j = n - 1; i < j; i++, j--) { ... }

unsigned m = 0xF0F0u;
m &= ~0x00FFu;         /* clear   */
m |= 0x0001u;          /* set     */
m ^= 0x0100u;          /* toggle  */

switch (op) {
    case 'a': case 'b': handle(); break;
    default: break;    /* always have a default; don't forget break */
}

int rc = work(&state);
if (rc < 0) goto cleanup;                  /* goto for cleanup: idiomatic in C */

cleanup:
    release(&state);
    return rc;
```

| Operator | Watch out for |
| :--- | :--- |
| `a & b` vs `a && b` | bitwise vs logical (boolean) |
| `<<`/`>>` | shifting a negative signed value / by ≥ the type width = UB |
| `/`, `%` | division by zero = UB; `INT_MIN / -1` = UB |
| `++`, `--` | unsequenced modify+access = UB |
| `sizeof` | result is `size_t`; on an array = the whole array |
| `,` | comma operator, not an argument separator |

> **Pitfall:** `a[i] = i++` and `f(i++, i++)` are **UB** — evaluation order is not guaranteed.

## Functions, scope, linkage

```c
static int helper(int x);       /* internal linkage: this file only */
extern int shared_global;       /* declaration, defined in another file */
static int counter;             /* static storage, zero-initialized */
volatile int hw_register;       /* don't let the compiler cache it */

static inline int max2(int a, int b) { return a > b ? a : b; }

_Static_assert(sizeof(int32_t) == 4, "int32_t must be 4 bytes");

_Noreturn void die(const char *msg);   /* C11 */

#define type_name(x) _Generic((x),      /* C11 */
    int: "int", double: "double", char *: "char*", default: "other")
```

| Qualifier | Meaning |
| :--- | :--- |
| `static` (file scope) | internal symbol, not exported |
| `static` (local variable) | lifetime = program, value persists across calls |
| `extern` | declaration without definition |
| `const` | must not be modified through that name |
| `volatile` | access must not be cached/eliminated (hardware registers) |
| `restrict` | the only pointer to that object (optimization) |
| `inline` | a hint; `static inline` in a header is safest |

> **Pitfall:** `volatile` is **not** thread synchronization. For that use
> `<stdatomic.h>` or a mutex.

## Pointers & arrays

```c
int a[5] = {1, 2, 3, 4, 5};
int *p = a;                    /* decays to &a[0] */
p[2] = *(p + 2) = 30;          /* identical */
ptrdiff_t d = &a[3] - &a[0];   /* 3, in element units */

int *arr[5];                   /* array of 5 pointers */
int (*parr)[5];                /* pointer to an array of 5 elements */
int (*fp)(int, int);           /* function pointer */

typedef int (*cmp_fn)(const void *, const void *);
int my_sort(void *base, size_t n, size_t sz, cmp_fn cmp);
```

| Concept | Watch out for |
| :--- | :--- |
| Array decay | to a pointer in expressions, **except** with `sizeof` and `&` |
| `p + 1` | advances `sizeof(*p)` bytes |
| Pointer − pointer | only valid within a single array |
| `NULL` / `nullptr` | `NULL` in C; not literally address 0 |
| `(*fp)(a,b)` = `fp(a,b)` | dereference is optional |
| `const char *` vs `char * const` | const data vs const pointer |

```c
size_t len = 0;

/* DO NOT */
size_t last = len - 1;      /* len==0 -> SIZE_MAX */

/* CORRECT */
size_t last = (len > 0) ? len - 1 : 0;
```

> **Pitfall:** unsigned `size_t` arithmetic → `0 - 1` becomes `SIZE_MAX`, not `-1`.

## Memory: allocation & ownership

```c
#include <stdlib.h>

int *buf = malloc(n * sizeof *buf);     /* sizeof *buf, not sizeof(int) */
if (!buf) return -1;

int *tmp = realloc(buf, bigger * sizeof *buf);
if (!tmp) { free(buf); return -1; }     /* buf is still valid if realloc fails */
buf = tmp;

free(buf);
buf = NULL;                             /* prevents double free / use-after-free */
```

| Function | Meaning |
| :--- | :--- |
| `malloc(n)` | n bytes, uninitialized |
| `calloc(cnt, sz)` | cnt×sz bytes, all zero |
| `realloc(p, n)` | resize; moves and frees `p` if needed |
| `free(p)` | release; `free(NULL)` is safe |
| `aligned_alloc(a, n)` | custom alignment (C11) |

```c
/* grow-2x pattern */
int push(IntVec *v, int x) {
    if (v->len == v->cap) {
        size_t cap = v->cap ? v->cap * 2 : 4;
        int *data = realloc(v->data, cap * sizeof *data);
        if (!data) return -1;
        v->data = data;
        v->cap = cap;
    }
    v->data[v->len++] = x;
    return 0;
}

/* multiple allocations + goto cleanup */
int load(Config *cfg) {
    char *host = NULL, *port = NULL;
    int rc = -1;

    host = strdup(cfg->host); if (!host) goto out;
    port = strdup(cfg->port); if (!port) goto out;
    rc = connect_to(host, port);
out:
    free(host);
    free(port);
    return rc;
}
```

| Ownership rule | Why |
| :--- | :--- |
| One allocation = one `free` with a clear owner | avoids leaks/double free |
| `*_create` functions return a pointer owned by the caller | explicit contract |
| `*_destroy` functions are safe on `NULL` | simple cleanup |
| Document "ownership transfer" in the header | prevents confusion |

> **Pitfall:** `realloc` **frees** the old pointer on success — do not store the result
> directly into a variable still used for cleanup.

## Undefined behavior

UB = the compiler may assume it never happens, then optimize based on that assumption.

| Source of UB | Example | Sanitizer |
| :--- | :--- | :--- |
| Out-of-bounds index | `buf[10]` on `buf[5]` | ASan |
| Use-after-free | accessing a pointer after `free` | ASan |
| Double free | `free` twice | ASan |
| Returning a local address | `return &local;` | ASan |
| Signed integer overflow | `INT_MAX + 1` | UBSan |
| Division by zero | `x / 0` | UBSan |
| Shifting too far | `1 << 40` on `int` | UBSan |
| NULL dereference | `*p` when `p == NULL` | ASan |
| Strict aliasing violation | accessing `int` through `float *` | UBSan (partial) |
| Unsequenced modify/access | `i++` + `i` in one expression | UBSan |
| Reading uninitialized memory | `int x; if (x)` | MSan |
| Modifying a string literal | `char *s = "hi"; s[0] = 'H';` | crash |

```c
int i = 1;
float f;
memcpy(&f, &i, sizeof f);        /* OK: bit copy is legal */

float *pf = (float *)&i;         /* UB: aliasing int through float* */
*pf = 2.0f;
```

> **Pitfall:** code that is "safe" at `-O0` can vanish at `-O2` because it contains UB.
> Always test with sanitizers **and** `-O2`.

## struct, union, bitfield, alignment

```c
typedef struct {
    uint32_t id;
    char     name[32];
    double   score;
} User;

User u = { .id = 1, .name = "budi", .score = 99.5 };   /* designated initializer */

typedef struct {
    uint32_t type;
    union {
        uint32_t as_int;
        float    as_float;
        uint8_t  as_bytes[4];
    } value;
} Variant;

/* flexible array member: last element, no size */
typedef struct {
    size_t count;
    int    items[];
} IntArray;

struct Packed {
    uint32_t a;
    uint8_t  b;
};   /* sizeof may be 8 because of padding */
```

| Layout rule | Detail |
| :--- | :--- |
| Alignment | each member starts at an offset that is a multiple of its alignment |
| struct size | a multiple of the largest alignment → padding exists |
| `offsetof(S, member)` | from `<stddef.h>` |
| Reordering fields | reduces padding without changing semantics |
| Bitfields | order & size are **implementation-defined** |
| `__attribute__((packed))` | removes padding → unaligned access (slow/forbidden) |

| struct A (padding in the middle) | struct B (tidied up) |
| :--- | :--- |
| `{ int32_t; int64_t; }` → 16 byte | `{ int64_t; int32_t; }` → 16 byte |
| `{ int8_t; int32_t; int8_t; }` → 12 byte | `{ int32_t; int8_t; int8_t; }` → 8 byte |

> **Pitfall:** `memcpy(&a, &b, sizeof a)` copies internal pointers verbatim — if there are
> owned pointers, the result is two owners for one block of memory → double free.

## Preprocessor

```c
#ifndef CONFIG_H
#define CONFIG_H

#define MAX_ITEMS 128
#define SQUARE(x) ((x) * (x))          /* ALWAYS parenthesize arguments & result */
#define STR(x) #x                       /* stringify */
#define CAT(a, b) a##b                  /* concat */

#if defined(DEBUG) && DEBUG >= 2
#  define LOG(...) fprintf(stderr, __VA_ARGS__)
#else
#  define LOG(...) ((void)0)
#endif

/* variadic macro */
#define COUNT_ARGS(...) COUNT_ARGS_IMPL(__VA_ARGS__, 5,4,3,2,1)
#define COUNT_ARGS_IMPL(_1,_2,_3,_4,_5,N,...) N

#ifdef __cplusplus
extern "C" {
#endif
/* header usable from C++ */
#ifdef __cplusplus
}
#endif

#endif /* CONFIG_H */
```

| Directive | Purpose |
| :--- | :--- |
| `#include "x.h"` / `<x.h>` | project header (via `-I`) vs system |
| `#define` / `#undef` | object / function macros |
| `#ifdef`/`#ifndef`/`#if`/`#elif` | conditional compilation |
| `#pragma once` | de facto, not ISO C — still use an include guard |
| `__FILE__`, `__LINE__`, `__func__` | location for logs/asserts |
| `__VA_ARGS__`, `##__VA_ARGS__` | variadic macros |

> **Pitfall:** `#define SQUARE(x) x*x` without parentheses makes `SQUARE(1+2)` = `1+2*1+2`.
> Macros are also evaluated **repeatedly** if a parameter is used twice.

## stdlib: `stdio.h`

```c
#include <stdio.h>

FILE *f = fopen("data.txt", "r");
if (!f) { perror("fopen"); return 1; }    /* perror: prints strerror(errno) */

char line[256];
while (fgets(line, sizeof line, f)) {      /* includes '\n', NUL-terminated */
    fputs(line, stdout);
}
if (ferror(f)) { /* read error */ }
fclose(f);

/* mode fopen */
fopen("a.txt", "r");    /* read */
fopen("a.txt", "w");    /* write, truncate */
fopen("a.txt", "a");    /* append */
fopen("b.bin", "rb");   /* binary (important on Windows) */
fopen("b.bin", "w+b");  /* read/write, truncate */

/* formatted & unformatted */
printf("%-10s|%05d|%.2f|%c|%p\n", name, id, price, ch, (void *)ptr);
int n = snprintf(buf, sizeof buf, "%s-%d", name, id);   /* check n >= (int)sizeof buf */
fprintf(stderr, "error: %s\n", strerror(errno));
fputs("text", stdout); fputc('x', stdout);

size_t got = fread(buf, 1, sizeof buf, f);    /* returns ITEMS */
size_t put = fwrite(buf, 1, got, f);

int ch = fgetc(f); fputc(ch, f);              /* returns int: may be EOF */
int c2 = getchar(); putchar('x');
```

| Function | Notes |
| :--- | :--- |
| `fopen`/`fclose` | always check for `NULL`; `fclose` can fail too |
| `fgets` | safe bound; stops at `\n` or `size-1` |
| `fread`/`fwrite` | number of **items**, not bytes |
| `fseek`/`ftell`/`rewind` | position; `fseek(f, 0, SEEK_SET)` |
| `fflush` | force a buffer write (including `fflush(NULL)`) |
| `ferror`/`feof` | `feof` is only true **after** a read fails |
| `rename`/`remove` | basic file operations |
| `tmpfile` | temporary file deleted when closed |
| `setvbuf` | configure buffering (`_IONBF`, `_IOLBF`, `_IOFBF`) |
| `perror` | one line: message + `strerror(errno)` |

| Specifier | Argument |
| :--- | :--- |
| `%d %u %ld %lld %zu` | `int`, `unsigned`, `long`, `long long`, `size_t` |
| `%x %o %#x` | hex, octal, hex with a 0x prefix |
| `%f %e %g` | float/double (fixed, exponent, compact) |
| `%c %s %p` | char, string, pointer (cast to `void *`) |
| `%.*s` | precision taken from an argument |
| `%" PRIu64` | portable `uint64_t` |

> **Pitfall:** `fflush` followed by `fork`/`_exit` — a child that calls `exit()` flushes
> the parent's inherited buffer, so the line is printed twice.

## stdlib: `stdlib.h`

```c
#include <stdlib.h>

/* memory */
void *p = malloc(64);
p = realloc(p, 128);
free(p);
void *z = calloc(10, sizeof *z);        /* zero-initialized */

/* string ↔ number conversion */
long v   = strtol("42abc", &end, 10);    /* end points at 'a' */
if (*end != '\0') { /* trailing input, invalid */ }
unsigned long ul = strtoul("0x1f", NULL, 16);
long long ll = strtoll("-9000", NULL, 10);
double d = strtod("3.14e2", &end);

char buf[32];
snprintf(buf, sizeof buf, "%ld", v);     /* number -> string (use snprintf) */

/* random numbers (not cryptographic) */
srand((unsigned)time(NULL));
int r = rand() % 100;                    /* modulo bias; use a RAND_MAX-based form if it matters */
#define RAND_RANGE(n) ((int)((double)rand() / RAND_MAX * (n)))

/* environment & processes */
char *home = getenv("HOME");
if (setenv("APP_ENV", "prod", 1) != 0) { /* error */ }
exit(EXIT_SUCCESS);      /* flush & atexit */
_Exit(1);                /* no flush */
if (atexit(cleanup) != 0) { /* error */ }
abort();                 /* SIGABRT, no cleanup */

/* generic search & sort */
qsort(arr, n, sizeof *arr, cmp_int);
void *found = bsearch(&key, arr, n, sizeof *arr, cmp_int);
int abs(int); long labs(long); long long llabs(long long);
int cmp_int(const void *a, const void *b) {
    int x = *(const int *)a, y = *(const int *)b;
    return (x > y) - (x < y);            /* avoids overflow */
}
```

| Function | Notes |
| :--- | :--- |
| `strtol`/`strtoul`/`strtoll` | the only parsing that can detect errors |
| `strtod` | float parsing, supports `inf`/`nan` |
| `atoi`/`atol` | **no** error detection — avoid |
| `qsort`/`bsearch` | comparator returns negative/0/positive |
| `exit`/`_Exit`/`abort` | flush+atexit / immediate / SIGABRT |
| `getenv` | pointer to an internal string — do not `free` |
| `setenv`/`unsetenv` | POSIX, not ISO C |
| `system` | shell injection — avoid for user input |

> **Pitfall:** `rand()` has a `RAND_MAX` that can be as low as 32767 — not enough for fine-grained
> simulation. For security use `getrandom`/OS entropy.

## stdlib: `string.h` & `strings.h`

```c
#include <string.h>

size_t n = strlen(s);                       /* O(n), store it in a variable */
char *dup = malloc(n + 1);
memcpy(dup, s, n + 1);                      /* copy including the NUL */
memmove(buf, buf + 4, len);                 /* safe for overlap */
int is_eq = memcmp(a, b, n) == 0;

strcpy(dst, src);                           /* unsafe: unbounded */
strncpy(dst, src, sizeof dst - 1);          /* does not guarantee a NUL */
dst[sizeof dst - 1] = '\0';
strcat(lhs, rhs);                           /* unbounded */
strncat(lhs, rhs, sizeof lhs - strlen(lhs) - 1);

int same = strcmp(a, b) == 0;
int ci   = strcasecmp(a, b) == 0;           /* POSIX/<strings.h> */
char *at = strchr(s, '@');
char *last = strrchr(path, '/');
char *needle = strstr(hay, "needle");
size_t span = strspn(s, "0123456789");

char *copy = strdup(s);                     /* POSIX: malloc + copy */
memset(buf, 0, sizeof buf);                 /* memset 0x20, NOT 20 */
```

| Function | Pitfall |
| :--- | :--- |
| `strlen` | O(n); inside a loop = O(n²) |
| `strcpy`/`strcat` | unbounded overflow |
| `strncpy` | does not NUL-terminate if the source ≥ n; zero-fills padding (expensive) |
| `strcmp` | result is not just -1/0/1 |
| `strtok` | not reentrant — use `strtok_r` |
| `memcpy` | **must not** overlap; use `memmove` |
| `memset` | the second argument is a **byte** (`int`), not a value |
| `strdup` | result must be `free`d |

> **Pitfall:** `memset(arr, 1, n)` on an `int arr[]` fills bytes with `0x01`, not the value 1.
> For numeric arrays use a loop or `calloc`.

## stdlib: `ctype.h` & `errno.h`

```c
#include <ctype.h>
#include <errno.h>
#include <string.h>

/* MUST cast to unsigned char for non-ASCII input */
for (const char *p = s; *p; p++) {
    if (isalpha((unsigned char)*p)) { ... }
}
int d = isdigit((unsigned char)c);
int sp = isspace((unsigned char)c);
int up = toupper((unsigned char)c);
int lo = tolower((unsigned char)c);

/* errno: save the value NOW */
errno = 0;
FILE *f = fopen(path, "r");
if (!f) {
    int err = errno;                    /* copy before another function runs */
    fprintf(stderr, "open %s: %s\n", path, strerror(err));
}
```

| `ctime` function | Check |
| :--- | :--- |
| `isalpha`, `isdigit`, `isalnum`, `isxdigit` | character class (locale-dependent) |
| `isspace` | ` `, `\t`, `\n`, `\v`, `\f`, `\r` |
| `isupper`, `islower`, `isprint`, `iscntrl` | classification |
| `toupper`, `tolower` | an `int` value, not `char` |
| `isblank` | space/tab (C99) |

| `errno` | Meaning |
| :--- | :--- |
| `EACCES` | permission denied |
| `ENOENT` | path does not exist |
| `EINTR` | syscall interrupted by a signal — **retry** |
| `ERANGE` | conversion result overflow |
| `ENOMEM` | out of memory |
| `EINVAL` | invalid argument |

> **Pitfall:** `isdigit(c)` with `c` of type `char` holding a negative value (≥0x80) = UB.
> Always cast to `unsigned char`.

## stdlib: `math.h` & `float.h`

```c
#include <math.h>
#include <float.h>

double r = sqrt(2.0);
double p = pow(2.0, 10.0);
double e = exp(1.0), lg = log(10.0), lg2 = log2(8.0), lg10 = log10(1000.0);
double s = sin(0.5), c = cos(0.5), t = tan(0.5);
double sd = sin(M_PI / 6);
double a = fabs(-3.5), f = floor(2.7), ce = ceil(2.1);
double rt = round(2.5);                 /* half away from zero */
double tr = trunc(-2.7);
double mod = fmod(7.0, 2.0);            /* sign follows the dividend */
double rem = remainder(7.0, 2.0);       /* IEEE remainder */
int ex; double mant = frexp(6.5, &ex);
double l = ldexp(0.8125, 3);

/* classifiers (for computed results) */
int nan = isnan(NAN);
int inf = isinf(INFINITY);
int fin = isfinite(1.0);
/* never compare floats with == */

/* safe float → int conversion */
if (x > INT_MAX || x < INT_MIN) { /* reject */ }
int i = (int)x;
```

| `float.h` constant | Meaning |
| :--- | :--- |
| `FLT_EPSILON`, `DBL_EPSILON` | smallest difference from 1 |
| `FLT_MAX`, `DBL_MAX` | maximum value |
| `DBL_DIG`, `FLT_DIG` | guaranteed decimal digits |
| `DBL_MANT_DIG` | mantissa bits |

| Rule | Why |
| :--- | :--- |
| Compare with epsilon | `a == b` is almost always wrong |
| `fabs(a-b) < eps` | float comparison |
| Money: integer cents / decimal | floats round incorrectly |
| `-lm` when linking | math is not linked automatically |

> **Pitfall:** `sqrt(-1)` produces NaN with no error (errno `EDOM` only if requested
> and the implementation supports it). Check with `isnan()` at business domain boundaries.

## stdlib: `time.h`

```c
#include <time.h>

time_t now = time(NULL);                /* epoch seconds */
struct tm local;
localtime_r(&now, &local);              /* POSIX, reentrant; localtime() uses a static buffer */
struct tm utc;
gmtime_r(&now, &utc);

char out[32];
strftime(out, sizeof out, "%Y-%m-%d %H:%M:%S", &local);   /* UTC / local according to the struct */
mktime(&local);                         /* struct tm -> time_t (local) */

/* monotonic clock (not the wall clock) */
struct timespec t0, t1;
clock_gettime(CLOCK_MONOTONIC, &t0);
/* ... work ... */
clock_gettime(CLOCK_MONOTONIC, &t1);
double ms = (t1.tv_sec - t0.tv_sec) * 1e3 + (t1.tv_nsec - t0.tv_nsec) / 1e6;

clock_t cpu0 = clock();                 /* CPU time, not wall clock */
```

| API | Notes |
| :--- | :--- |
| `time_t` | seconds since the epoch (may be signed/unsigned) |
| `struct tm` | fields: `tm_year` = year-1900, `tm_mon` = 0..11 |
| `localtime`/`gmtime` | static — not thread-safe; use `_r` |
| `strftime` | format `%Y %m %d %H %M %S %Z %z` |
| `mktime` | `tm` is treated as **local time** |
| `CLOCK_MONOTONIC` | for measuring durations |
| `CLOCK_REALTIME` | wall clock, can go backwards |
| `nanosleep` | precise sleep (POSIX) |

> **Pitfall:** `tm_mon` starts at 0 and `tm_year` = year − 1900 — the most common
> date bug in C is forgetting `+1900`.

#include <stddef.h>

size_t sz = sizeof(int);

## stdlib: `assert` / `setjmp` / `signal`

```c
#include <assert.h>

assert(ptr != NULL);            /* disabled in release with -DNDEBUG */
static_assert(sizeof(int) == 4, "int must be 4 bytes");   /* C11, compile-time */
```

```c
#include <setjmp.h>

/* error handling without goto/exceptions — use WITH CARE */
jmp_buf env;

int try_run(void) {
    if (setjmp(env) != 0) {
        /* returns here after longjmp */
        return -1;
    }
    risky_work();               /* may longjmp(env, 1) inside */
    return 0;
}
```

```c
#include <signal.h>

static volatile sig_atomic_t stop = 0;

static void on_term(int sig) {
    (void)sig;
    stop = 1;                   /* ONLY set the flag — no printf/malloc */
}

struct sigaction sa = {0};
sa.sa_handler = on_term;
sigemptyset(&sa.sa_mask);
sa.sa_flags = SA_RESTART;
sigaction(SIGINT, &sa, NULL);
sigaction(SIGTERM, &sa, NULL);

raise(SIGTERM);
```

| API | Notes |
| :--- | :--- |
| `assert(expr)` | abort if false and `NDEBUG` is not defined |
| `static_assert` | checked at compile time (C11) |
| `setjmp`/`longjmp` | jumps across functions; does **not** run cleanup |
| `signal` | old API; behavior differs between platforms |
| `sigaction` | modern API (blocking mask, flags) |
| `volatile sig_atomic_t` | the only safe type inside a handler |

> **Pitfall:** `longjmp` skips frames that hold allocations → leak. And `setjmp` may
> only be used in certain conditional expressions (`if`, `switch`, `while`).

## stdlib: `stdatomic.h` & `threads.h`

```c
#include <stdatomic.h>

atomic_int counter = 0;
atomic_fetch_add(&counter, 1);
int val = atomic_load(&counter);
atomic_store(&counter, 0);

atomic_bool ready = false;
atomic_store_explicit(&ready, true, memory_order_release);
while (!atomic_load_explicit(&ready, memory_order_acquire)) { }

atomic_flag flag = ATOMIC_FLAG_INIT;
while (atomic_flag_test_and_set(&flag)) { /* spin */ }
atomic_flag_clear(&flag);

/* compare-and-swap */
int expected = 5;
atomic_compare_exchange_strong(&counter, &expected, 6);
```

| Memory order | Meaning |
| :--- | :--- |
| `memory_order_relaxed` | atomic only, no ordering |
| `memory_order_acquire` | load: subsequent reads must not move up |
| `memory_order_release` | store: preceding writes must not move down |
| `memory_order_acq_rel` | both (RMW) |
| `memory_order_seq_cst` | total order — default, safest |

```c
#include <threads.h>

int worker(void *arg) {
    int *n = arg;
    *n += 1;
    return 0;
}

thrd_t t;
int result;
if (thrd_create(&t, worker, &result) != thrd_success) return 1;
thrd_join(t, NULL);

mtx_t mtx;
if (mtx_init(&mtx, mtx_plain) != thrd_success) return 1;
mtx_lock(&mtx);
/* critical section */
mtx_unlock(&mtx);
mtx_destroy(&mtx);

cnd_t cond;
cnd_init(&cond);
mtx_lock(&mtx);
while (!ready) cnd_wait(&cond, &mtx);   /* always loop: spurious wakeup */
mtx_unlock(&mtx);
```

| Item | Notes |
| :--- | :--- |
| `threads.h` (C11) | optional; implementation support varies |
| `pthread` (POSIX) | most common on Linux — more complete |
| `volatile` | **not** synchronization |
| Data race | UB, not an "unexpected result" — use TSan |
| `_Atomic` tipe | can be used without `stdatomic` for data declarations |

> **Pitfall:** reading a non-atomic variable written by another thread = **data race** = UB,
> even if its type is `int` and it looks "atomic" on some CPUs.

## Pitfalls (must read)

| Pitfall | Symptom | Solution |
| :--- | :--- | :--- |
| `char` signed/unsigned differs by platform | `char c = 200` gives different results | `int8_t`/`uint8_t` |
| `size_t` is unsigned | `len - 1` when 0 → `SIZE_MAX` | check `len > 0` |
| `realloc` frees the old pointer | use-after-free | go through a temporary variable |
| `malloc` without a NULL check | crash | check & return an error |
| `free` then use the pointer | use-after-free | `free` then set `NULL` |
| Double free | crash (ASan) | set the pointer to `NULL` |
| `strncpy` without a NUL | string leak | set `dst[n-1] = '\0'` |
| `snprintf` return value ignored | truncated output | check `n < 0 \|\| n >= size` |
| `strlen` in a loop | O(n²) | store the length |
| `strcmp(...) == 1` | logic bug | `== 0` for equal |
| Signed overflow | **UB**, branch can be deleted | `uint32_t` / check the range |
| Shift ≥ the type width | **UB** | use a 64-bit type |
| float → int overflow | **UB** | check the range |
| struct copy containing pointers | double free | explicit ownership transfer |
| struct padding | wasted memory | reorder fields |
| bitfields for wire formats | layout differs per compiler | manual serialization |
| macro without parentheses | `SQUARE(1+2)` is wrong | parenthesize arguments & result |
| `memset(arr,1,n)` on an int array | fills bytes, not values | loop / `calloc` |
| `volatile` for synchronization | data race | `stdatomic`/mutex |
| `localtime` in multithreaded code | results get mixed up | `localtime_r` |
| `tm_year`/`tm_mon` | date is off | `+1900`, `+1` |
| `errno` read later | wrong diagnosis | save it immediately |
| `fclose` not checked | data not flushed | check the return value |
| `fflush` before fork | line printed twice | `fflush` before `fork`/`_exit` |
| `feof` as a loop condition | extra iteration | check the read result |
| `rand()` for security | predictable tokens | OS entropy |
| `-Wall -Wextra` turned off | undetected bugs | always enable them |
| sanitizers not used | UB only shows up in production | `-fsanitize=address,undefined` |
