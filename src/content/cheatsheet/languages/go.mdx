## CLI & toolchain

```sh
go build ./...                 # compile all packages
go build -o bin/api ./cmd/api  # output binary
go run ./cmd/api               # compile + run
go test ./...                  # run tests
go test -race ./...            # race detector
go test -run TestCheckout -v ./internal/order
go test -bench=. -benchmem ./internal/crypto
go test -coverprofile=cover.out ./... && go tool cover -html=cover.out
go vet ./...                   # built-in analyzers (including new 'waitgroup' & 'hostport' in 1.25)
```

## 5-minute mental model

| Concept | Summary |
| :--- | :--- |
| Goroutine | lightweight execution unit; `go f()` |
| Channel | communicate between goroutines; typed, FIFO |
| `defer` | runs when the function exits (LIFO) — including on panic |
| Zero value | every type has a **useful** initial value (`0`, `""`, `nil`, `false`) |
| Interface | satisfied **implicitly** — the type has the methods, no declaration needed |
| Error | a value, not an exception; always check `err != nil` |
| Pointer | alias to memory; `&` takes the address, `*` dereferences |
| Slices | header (ptr, len, cap) — append may reallocate |
| Map | built-in hash map; **not safe** for concurrent writes |
| Generic | type parameters to avoid duplication without losing type safety |
| `context.Context` | cancellation + deadline + request-scoped values |

## What's new in 1.26

```go
// `new` now accepts an EXPRESSION, not just a type
type Person struct {
    Name string `json:"name"`
    Age  *int   `json:"age"`   // pointer = optional
}

func personJSON(name string, born time.Time) ([]byte, error) {
    return json.Marshal(Person{
        Name: name,
        Age:  new(yearsSince(born)),   // 1.26: new(expression)
    })
}
```

```go
// Generics may refer to themselves in the type parameter list
type Adder[A Adder[A]] interface {
    Add(A) A
}

func algo[A Adder[A]](x, y A) A { return x.Add(y) }
```

| 1.26 change | Impact |
| :--- | :--- |
| `new(expr)` | value-based optional fields can be set without a temporary variable |
| Generic self-reference | Type parameter constraints can be more expressive |
| `go fix` → modernizer | Automatic migration of old idioms (`interface{}` → `any`, etc.) |
| **Green Tea GC** (default) | GC overhead drops 10–40% for GC-heavy programs |
| `errors.AsType[T]` | Generic version of `errors.As` — type-safe & faster |
| `slog.NewMultiHandler` | One log record to many handlers at once |
| `http.ServeMux` trailing slash | Redirect 301 → **307** (does not change the method) |
| `http.CrossOriginProtection` | CSRF protection based on Fetch metadata |
| `os.Root` (new method) | File operations safe against symlink escaping |
| `testing.T.ArtifactDir` | Test output directory (screenshots, dumps) |
| `B.Loop` | Modern benchmark; prevents inlining of the loop body |
| `testing/cryptotest` | `SetGlobalRandom` for deterministic cryptography tests |
| `crypto/hpke` | Hybrid Public Key Encryption (RFC 9180) |
| `runtime/secret` (experimental) | Secure wiping of secret data (registers/stack/heap) |
| `simd/archsimd` (experimental) | Architecture-specific SIMD (GOEXPERIMENT=simd) |
| Goroutine leak profile (experimental) | `GOEXPERIMENT=goroutineleakprofile` |
| Heap base randomization | Randomized heap base on 64-bit (hardening) |
| Go 1.24.6+ for bootstrap | Toolchain requirement raised |

> Green Tea can be disabled with `GOEXPERIMENT=nogreenteagc` (expected to be removed in 1.27),
> just like `GOEXPERIMENT=norandomizedheapbase64` for heap randomization.

## Goroutine, channel, select

```go
// goroutine + WaitGroup (1.25+: WaitGroup.Go)
var wg sync.WaitGroup
for _, item := range items {
    wg.Go(func() {           // 1.25+: no Add(1)/defer Done()
        process(item)
    })
}
wg.Wait()
```

```go
// channel: producer/consumer
ch := make(chan Order, 100)   // buffer = 100; unbuffered = strict blocking
go func() {
    defer close(ch)            // the producer closes the channel
    for _, o := range orders {
        ch <- o
    }
}()

for o := range ch {            // range stops when the channel is closed
    handle(o)
}
```

```go
// select: multiple channels + timeout + cancel
select {
case o := <-orders:
    handle(o)
case res := <-results:
    use(res)
case <-ctx.Done():
    return ctx.Err()
case <-time.After(2 * time.Second):
    return ErrTimeout
}
```

```go
// fan-out/fan-in
var wg sync.WaitGroup
out := make(chan Result, len(jobs))
for _, job := range jobs {
    wg.Go(func() { out <- run(job) })
}
go func() { wg.Wait(); close(out) }()   // close after everything finishes

for r := range out { collect(r) }
```

```go
// context: cancel all workers
ctx, cancel := context.WithCancel(context.Background())
defer cancel()
go func() {
    for {
        select {
        case <-ctx.Done():
            return
        case job := <-jobs:
            go process(ctx, job)
        }
    }
}()
```

| Principle | Rule |
| :--- | :--- |
| Blocking | An unbuffered channel blocks until a receiver arrives |
| Close | Only the producer closes; closing twice = panic |
| Select default | `default` makes select non-blocking |
| Loop variable | Go 1.22+ **per-iteration** — safe to use in a goroutine without copying |
| Goroutine leak | A permanently blocked goroutine never goes away; it must be cancelled via context |

## Context

```go
// making: always from a parent, never store in a struct
ctx, cancel := context.WithTimeout(parent, 2*time.Second)
defer cancel()          // MANDATORY — otherwise the timer leaks until the parent finishes

ctx = context.WithValue(ctx, RequestIDKey, id)   // only for cross-request data (trace id)
v := ctx.Value(RequestIDKey).(string)
```

```go
// propagate: the context parameter MUST be the first parameter
func (s *Service) Get(ctx context.Context, id string) (*Order, error) {
    req, _ := http.NewRequestWithContext(ctx, "GET", s.url+id, nil)
    resp, err := s.client.Do(req)
    if err != nil {
        return nil, err
    }
    defer resp.Body.Close()
    ...
}
```

| Function | Meaning |
| :--- | :--- |
| `WithCancel` | cancel manually |
| `WithTimeout` / `WithDeadline` | time limit |
| `WithCancelCause` | cancel **with a reason** (Go 1.20+) |
| `WithValue` | store a value; DO NOT use for required parameters |
| `ctx.Done()` | channel closed when the context is done |
| `ctx.Err()` | `Canceled` or `DeadlineExceeded` |

> **Pitfall:** `context.Background()` inside a function that receives `ctx` = breaks
> timeout propagation. Always pass along the caller's `ctx`.

## Error handling

```go
// wrapping with context
if err != nil {
    return fmt.Errorf("load order %s: %w", id, err)   // %w = bungkus
}

// check error type
var e *sql.ErrNoRows
if errors.As(err, &e) { ... }

// check sentinel
if errors.Is(err, sql.ErrNoRows) { ... }

// join several errors (1.20+)
if err := doAll(); err != nil {
    return errors.Join(err1, err2)   // errors.Is/As still work
}

// AsType (1.26) — generic, type-safe
if n, ok := errors.AsType[*net.OpError](err); ok {
    log.Printf("network: %v", n)
}

// sentinel error
var ErrNotFound = errors.New("not found")
```

| Convention | Example |
| :--- | :--- |
| Error value (sentinel) | `var ErrNotFound = errors.New(...)` |
| Error type | `type ValidationError struct{ Field string }` + `Error() string` |
| Wrap | `%w` — **only** one wrap level per keyword |
| String | lowercase, no comma or trailing period |
| Inspect | `errors.Is` for sentinels, `errors.As` for types |

## Generics

```go
// generic function
func Map[T, U any](in []T, f func(T) U) []U {
    out := make([]U, 0, len(in))
    for _, v := range in {
        out = append(out, f(v))
    }
    return out
}

// constraint
type Number interface {
    ~int | ~int64 | ~float64
}

func Sum[T Number](xs []T) T {
    var total T
    for _, x := range xs {
        total += x
    }
    return total
}

// generic type
type Stack[T any] struct {
    items []T
}

func (s *Stack[T]) Push(v T) { s.items = append(s.items, v) }
func (s *Stack[T]) Pop() (T, bool) {
    var zero T
    if len(s.items) == 0 {
        return zero, false
    }
    v := s.items[len(s.items)-1]
    s.items = s.items[:len(s.items)-1]
    return v, true
}
```

| Convention | Form |
| :--- | :--- |
| Constraint | `any`, `comparable`, or a union `~int \| ~string` |
| `~` | allow type aliases (e.g. `type MyInt int`) |
| Don't | use generics for just 1–2 types; use a small interface instead |

## HTTP server & client

```go
// server with timeouts (DO NOT skip these)
srv := &http.Server{
    Addr:              ":8080",
    Handler:           mux,
    ReadHeaderTimeout: 5 * time.Second,   // mandatory — slowloris protection
    ReadTimeout:       15 * time.Second,
    WriteTimeout:      30 * time.Second,
    IdleTimeout:       120 * time.Second,
}
go func() {
    if err := srv.ListenAndServe(); err != nil && !errors.Is(err, http.ErrServerClosed) {
        log.Fatal(err)
    }
}()

// graceful shutdown
ctx, cancel := context.WithTimeout(context.Background(), 15*time.Second)
defer cancel()
if err := srv.Shutdown(ctx); err != nil { log.Fatal(err) }
```

```go
// ServeMux with method patterns (1.22+)
mux := http.NewServeMux()
mux.HandleFunc("GET /api/orders/{id}", getOrder)   // {id} = wildcard
mux.HandleFunc("POST /api/orders", createOrder)
```

```go
// client with timeout & connection pool
tr := &http.Transport{
    MaxIdleConns:        100,
    MaxIdleConnsPerHost: 20,       // default 2 — the main cause of connection leaks!
    IdleConnTimeout:     90 * time.Second,
}
client := &http.Client{Transport: tr, Timeout: 10 * time.Second}

req, _ := http.NewRequestWithContext(ctx, http.MethodGet, url, nil)
resp, err := client.Do(req)
if err != nil { return err }
defer resp.Body.Close()
body, _ := io.ReadAll(resp.Body)
```

> **Pitfall:** `http.DefaultTransport` has `MaxIdleConnsPerHost = 2`. For a service that
> calls many hosts in parallel, connections get discarded constantly → a TLS handshake
> on every request. Set `MaxIdleConnsPerHost` explicitly.

## JSON

```go
// marshal
data, err := json.Marshal(user)

// unmarshal
var u User
if err := json.Unmarshal(data, &u); err != nil { ... }

// streaming decode (large body)
dec := json.NewDecoder(resp.Body)
dec.DisallowUnknownFields()      // optional: reject unknown fields
for {
    var order Order
    if err := dec.Decode(&order); err == io.EOF { break }
    else if err != nil { return err }
    handle(order)
}

// marshal with indent
data, _ := json.MarshalIndent(user, "", "  ")

// map[string]any
var m map[string]any
json.Unmarshal(data, &m)

// custom marshal
func (t Time) MarshalJSON() ([]byte, error) {
    return []byte(`"` + t.Format(time.RFC3339) + `"`), nil
}
```

| Tag | Meaning |
| :--- | :--- |
| `json:"name"` | field name |
| `json:"-"` | abaikan |
| `json:"name,omitempty"` | omit when empty |
| `json:"-"` + custom | field privat tetap diserialisasi lewat method |

> `encoding/json/v2` is still **experimental** in 1.25–1.26 (enabled via `GOEXPERIMENT=jsonv2`).
> Do not use it in production before it stabilizes.

## Database

```go
db, err := sql.Open("pgx", dsn)
db.SetMaxOpenConns(20)
db.SetMaxIdleConns(10)
db.SetConnMaxLifetime(30 * time.Minute)
db.SetConnMaxIdleTime(5 * time.Minute)
defer db.Close()

ctx, cancel := context.WithTimeout(ctx, 2*time.Second)
defer cancel()

row := db.QueryRowContext(ctx, `SELECT id, total FROM orders WHERE id = $1`, id)
var id int64
var total int64
if err := row.Scan(&id, &total); err != nil {
    if errors.Is(err, sql.ErrNoRows) { return ErrNotFound }
    return err
}

// transaction
tx, err := db.BeginTx(ctx, &sql.TxOptions{Isolation: sql.LevelReadCommitted})
if err != nil { return err }
defer tx.Rollback()   // no-op if already Committed

if _, err := tx.ExecContext(ctx, `UPDATE accounts SET balance = balance - $1 WHERE id = $2`, amt, src); err != nil {
    return err
}
if _, err := tx.ExecContext(ctx, `INSERT INTO outbox(...) VALUES(...)`); err != nil {
    return err
}
return tx.Commit()
```

| Practice | Why |
| :--- | :--- |
| Always `?`/placeholders, never string concat | SQL injection |
| `QueryRowContext` for a single row | Closes the row automatically |
| `defer tx.Rollback()` | Safe on both commit and error |
| `SetConnMaxLifetime` | Load balancers kill idle connections |
| `rows.Close()` + `rows.Err()` | Don't forget to check for errors after the loop |

## Testing & benchmark

```go
// table test
func TestCalculate(t *testing.T) {
    tests := []struct {
        name    string
        amount  int64
        want    int64
        wantErr bool
    }{
        {"normal", 100, 111, false},
        {"zero", 0, 0, false},
        {"negative", -50, 0, true},
    }
    for _, tt := range tests {
        t.Run(tt.name, func(t *testing.T) {
            t.Parallel()                     // parallel test
            got, err := Calculate(tt.amount)
            if (err != nil) != tt.wantErr {
                t.Fatalf("err = %v, wantErr %v", err, tt.wantErr)
            }
            if got != tt.want {
                t.Errorf("got %d, want %d", got, tt.want)
            }
        })
    }
}
```

```go
// modern benchmark (1.24+): B.Loop
func BenchmarkHash(b *testing.B) {
    h := NewHasher()
    b.ReportAllocs()
    for b.Loop() {                    // not for i := 0; i < b.N; i++
        h.Write([]byte("payload"))
    }
}
```

```go
// concurrency test with virtual time (1.25+: synctest GA)

    })
}
```

| `log/slog` | `Info/Error/Warn/Debug`, JSON/Text handlers | use it since 1.21 |
| `os` | `ReadFile`, `WriteFile`, `Getenv`, `LookupEnv` | `os.Exit` skips `defer` |
| `time` | `Duration`, `Ticker`, `Timer`, `LoadLocation` | format layout = `2006-01-02` |
| `math` | `Max`, `Sqrt`, `Round`, `IsNaN` | never use `float64` for money |
| `sync` | `Mutex`, `RWMutex`, `Once`, `WaitGroup` | `RWMutex` pays off when reads >> writes |
| `sync/atomic` | `atomic.Int64`, `Bool`, `Pointer` | generic types since 1.19 |

> **Pitfall:** `Ticker`/`Timer` without `Stop()` = goroutine leak. Always `defer ticker.Stop()`.

## std lib: I/O & file

```go
import (
    "bufio"
    "bytes"
    "embed"
    "io"
    "io/fs"
    "os"
    "path/filepath"
)

// io.Copy — stream without loading into memory
src, _ := os.Open("in.bin")
defer src.Close()
dst, _ := os.Create("out.bin")
defer dst.Close()
_, err := io.Copy(dst, src)

// bufio: read line by line & buffered writes
sc := bufio.NewScanner(src)
sc.Buffer(make([]byte, 0, 64*1024), 1024*1024)      // raise the line limit (default 64K)
for sc.Scan() {
    line := sc.Bytes()                              // temporary []byte, copy it if you keep it
    _ = line
}
if err := sc.Err(); err != nil { return err }

w := bufio.NewWriter(dst)
w.WriteString("hello\n")
w.Flush()                                           // MANDATORY, otherwise the buffer is lost

// composing Reader/Writer
r := io.LimitReader(src, 1<<20)                     // maximum 1 MiB
r = io.TeeReader(src, os.Stdout)                    // read + copy
mw := io.MultiWriter(os.Stdout, dst)                // one write, many destinations
var buf bytes.Buffer
io.Copy(&buf, r)

// embed: files bundled into the binary
//go:embed templates/*.html
var tmplFS embed.FS

//go:embed version.txt
var version string

// fs.FS — uniform access (disk, embed, zip)
sub, _ := fs.Sub(tmplFS, "templates")
entries, _ := fs.ReadDir(sub, ".")
for _, e := range entries {
    if !e.IsDir() { _ = e.Name() }
}
content, _ := fs.ReadFile(sub, "index.html")

// path/filepath
filepath.Join("a", "b", "c")                        // a/b/c (OS-aware)
filepath.Base("/tmp/x.log")                         // x.log
filepath.Ext("x.log")                               // .log
filepath.Dir("/tmp/x.log")                          // /tmp
filepath.WalkDir(".", func(p string, d fs.DirEntry, err error) error {
    if err != nil { return err }
    if d.IsDir() && d.Name() == ".git" { return fs.SkipDir }
    return nil
})
matched, _ := filepath.Match("*.go", "main.go")
```

| API | Purpose |
| :--- | :--- |
| `io.Copy` | copy a stream (uses `WriterTo`/`ReaderFrom` when available) |
| `io.ReadAll` | read until EOF (limit the size!) |
| `io.LimitReader` | limit the number of bytes |
| `io.MultiWriter` | one write → many destinations |
| `bufio.Scanner` | read line/token by token (default limit 64K) |
| `bufio.Writer` | buffered write — `Flush` is mandatory |
| `embed.FS` | assets bundled in the binary, no `os` needed |
| `fs.WalkDir` | allocation-light traversal |
| `filepath.Join` | portable paths (never string concat) |

> **Pitfall:** `io.ReadAll` on `http.Request.Body` without `io.LimitReader` = OOM caused by a client.

```go
mux := http.NewServeMux()

    id := r.PathValue("id")

func withAuth(next http.Handler) http.Handler {
    return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
        if r.Header.Get("Authorization") == "" {
            http.Error(w, "unauthorized", http.StatusUnauthorized)
            return
        }
        next.ServeHTTP(w, r)
    })
}
handler := withAuth(mux)

handler.ServeHTTP(rec, req)
```

## std lib: advanced testing (testdata, ArtifactDir, race)

```go
// golden file: large output that is not rewritten by hand
func TestRender(t *testing.T) {
    got := render(config())
    golden := filepath.Join("testdata", t.Name()+".golden")

    if *update {                              // the -update flag
        if err := os.WriteFile(golden, got, 0o644); err != nil { t.Fatal(err) }
    }
    want, err := os.ReadFile(golden)
    if err != nil { t.Fatal(err) }
    if !bytes.Equal(got, want) {
        dir := t.ArtifactDir()                // 1.26: test output directory
        path := filepath.Join(dir, "got.txt")
        _ = os.WriteFile(path, got, 0o644)
        t.Fatalf("diff: see %s vs %s", path, golden)
    }
}

// automatic cleanup (LIFO)
func TestServer(t *testing.T) {
    srv := httptest.NewServer(handler())
    t.Cleanup(srv.Close)
    t.Cleanup(func() { t.Log("cleanup") })
}

// use t.Helper so errors point at the caller's line
func assertEqual[T comparable](t *testing.T, got, want T) {
    t.Helper()
    if got != want { t.Fatalf("got %v, want %v", got, want) }
}
```

| Feature | Use |
| :--- | :--- |
| `testdata/` | inputs & golden files; ignored by Go tooling |
| `-update` flag | deliberately regenerate goldens |
| `t.ArtifactDir()` | save failing output (1.26) |
| `t.Cleanup` | LIFO teardown, safer than defer |
| `t.Helper` | errors point at the caller location |
| `t.TempDir()` | temporary directory removed automatically |
| `-race` | mandatory for packages that use goroutines |
| `-count=100 ./pkg` | test for flakiness |

> **Pitfall:** a golden file changed without review = a test that always passes. Diff the goldens in the PR.

## Pitfalls (must read)

| Pitfall | Symptom | Fix |
| :--- | :--- | :--- |
| Loop variable in a goroutine (pre-1.22) | Every goroutine reads the last value | Go 1.22+ is per-iteration safe; still copy if you need cross-version support |
| `defer` inside a loop | All defers run at the end of the function | Wrap each iteration in a func |
| `context.Background()` inside a function that takes ctx | Timeout does not propagate | Accept & pass along `ctx` |
| Forgetting `defer cancel()` | Context & timer leak | `defer cancel()` right after creation |
| Missing / misordered `wg.Add(1)` | Panic "negative WaitGroup counter" | Use `wg.Go` (1.25+) |
| Closing a channel twice | Panic | Only the producer closes |
| Sending to a channel nobody reads | Goroutine blocks forever | Select with `ctx.Done()` |
| Map written from 2 goroutines | Fatal error: concurrent map writes | `sync.Map` or a per-key lock |
| `interface{}` vs `any` | Mixed style | Use `any` (1.18+) |
| `http.DefaultTransport` | Connections keep getting discarded (2 per host) | Your own Transport + `MaxIdleConnsPerHost` |
| Forgetting `rows.Close()` | Connection leak | `defer rows.Close()` + check `rows.Err()` |
| Checking `err != nil` after `defer resp.Body.Close()` | Body is never sent | Check the error before the defer |
| `time.Now()` for durations | Always positive, can never be negative | `time.Since(start)` |
| `fmt.Sprintf` for SQL | SQL injection | Always use placeholders |
| `panic` in a goroutine | Process crash | `recover()` in the same goroutine |
| `float64` for money | Rounding errors | `int64` cents / `decimal` |
| Struct with `sync.Mutex` copied | `go vet` copylocks | Use a pointer |
| `interface{}` in a public API | Hard to evolve | Generics or a small trait |
| `unsafe` without a reason | Hard-to-track bugs | Write the invariant in a comment |
| Slicing in a loop with `append` | O(n²) allocations | Pre-allocate with `make(..., 0, len(x))` |
