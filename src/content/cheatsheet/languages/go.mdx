## CLI & toolchain

```sh
go build ./...                 # compile semua paket
go build -o bin/api ./cmd/api  # output binary
go run ./cmd/api               # compile + run
go test ./...                  # jalankan test
go test -race ./...            # race detector
go test -run TestCheckout -v ./internal/order
go test -bench=. -benchmem ./internal/crypto
go test -coverprofile=cover.out ./... && go tool cover -html=cover.out
go vet ./...                   # analyzer bawaan (termasuk 'waitgroup' & 'hostport' baru di 1.25)
go fix ./...                   # MODERNIZER: rapikan kode ke idiom terbaru
gofmt -w .                     # format (gofumpt lebih ketat, opsional)
go mod tidy                    # rapikan go.mod/go.sum
go mod download                # prefetch dependency
go work init ./svc-a ./svc-b   # workspace multi-repo
go build -trimpath -ldflags="-s -w"   # binary kecil + path reproduibel
```

| Perintah | Fungsi |
| :--- | :--- |
| `go build` | compile |
| `go run` | compile & jalankan (bukan untuk prod) |
| `go test` | test; `-race`, `-bench`, `-cover`, `-count`, `-shuffle` |

## Mental model 5 menit

| Konsep | Ringkasan |
| :--- | :--- |
| Goroutine | unit eksekusi ringan; `go f()` |
| Channel | communicate antar goroutine; typed, FIFO |
| `defer` | jalan saat fungsi keluar (LIFO) — termasuk saat panic |
| Zero value | setiap tipe punya nilai awal yang **berguna** (`0`, `""`, `nil`, `false`) |
| Interface | satisfied **implisit** — tipe punya method-nya, tidak perlu deklarasi |
| Error | nilai, bukan exception; selalu cek `err != nil` |
| Pointer | alias ke memori; `&` ambil address, `*` deref |
| Slices | header (ptr, len, cap) — append bisa reallocate |
| Map | hash map bawaan; **tidak aman** untuk concurrent write |
| Generic | param tipe untuk menghindari duplikasi tanpa kehilangan type safety |
| `context.Context` | pembatalan + deadline + nilai lintas request |

## Yang baru di 1.26

```go
// `new` sekarang menerima EKSPRESI, bukan hanya tipe
type Person struct {
    Name string `json:"name"`
    Age  *int   `json:"age"`   // pointer = optional
}

func personJSON(name string, born time.Time) ([]byte, error) {
    return json.Marshal(Person{
        Name: name,
        Age:  new(yearsSince(born)),   // 1.26: new(ekspresi)
    })
}
```

```go
// Generic boleh merujuk ke dirinya sendiri di daftar type parameter
type Adder[A Adder[A]] interface {
    Add(A) A
}

func algo[A Adder[A]](x, y A) A { return x.Add(y) }
```

| Perubahan 1.26 | Dampak |
| :--- | :--- |
| `new(expr)` | field optional yang berbasis nilai bisa diisi tanpa variabel sementara |
| Generic self-reference | Batasan type parameter bisa lebih ekspresif |
| `go fix` → modernizer | Migrasi idiom lama otomatis (`interface{}` → `any`, dsb) |
| **Green Tea GC** (default) | Overhead GC turun 10–40% untuk program GC-heavy |
| `errors.AsType[T]` | Versi generik dari `errors.As` — type-safe & lebih cepat |
| `slog.NewMultiHandler` | Satu log record ke banyak handler sekaligus |
| `http.ServeMux` trailing slash | Redirect 301 → **307** (tidak mengubah method) |
| `http.CrossOriginProtection` | Proteksi CSRF berbasis Fetch metadata |
| `os.Root` (method baru) | Operasi file aman terhadap symlink escaping |
| `testing.T.ArtifactDir` | Direktori output test (screenshot, dump) |
| `B.Loop` | Benchmark modern; tidak lagi/Askor inlining |
| `testing/cryptotest` | `SetGlobalRandom` untuk test kriptografi deterministik |
| `crypto/hpke` | Hybrid Public Key Encryption (RFC 9180) |
| `runtime/secret` (eksperimen) | Penghapusan aman data rahasia (register/stack/heap) |
| `simd/archsimd` (eksperimen) | SIMD arsitektur-spesifik (GOEXPERIMENT=simd) |
| Goroutine leak profile (eksperimen) | `GOEXPERIMENT=goroutineleakprofile` |
| Heap base randomization | Randomized heap base di 64-bit (hardening) |
| Go 1.24.6+ untuk bootstrap | Toolchain requirement naik |

> Green Tea bisa dimatikan dengan `GOEXPERIMENT=nogreenteagc` (diperkirakan dihapus di 1.27),
> sama seperti `GOEXPERIMENT=norandomizedheapbase64` untuk randomisasi heap.

## Goroutine, channel, select

```go
// goroutine + WaitGroup (1.25+: WaitGroup.Go)
var wg sync.WaitGroup
for _, item := range items {
    wg.Go(func() {           // 1.25+: tanpa Add(1)/defer Done()
        process(item)
    })
}
wg.Wait()
```

```go
// channel: producer/consumer
ch := make(chan Order, 100)   // buffer = 100; unbuffered = blocking strict
go func() {
    defer close(ch)            // producer menutup channel
    for _, o := range orders {
        ch <- o
    }
}()

for o := range ch {            // range berhenti saat channel ditutup
    handle(o)
}
```

```go
// select: beberapa channel + timeout + cancel
select {
case o := <-orders:
    handle(o)
case res := <-results:
    use(res)
case <-ctx.Done():
    return ctx.Err()
case <-time.After(2 * time.Second):
    return ErrTimeout
}
```

```go
// fan-out/fan-in
var wg sync.WaitGroup
out := make(chan Result, len(jobs))
for _, job := range jobs {
    wg.Go(func() { out <- run(job) })
}
go func() { wg.Wait(); close(out) }()   // tutup setelah semua selesai

for r := range out { collect(r) }
```

```go
// context: batalkan semua worker
ctx, cancel := context.WithCancel(context.Background())
defer cancel()
go func() {
    for {
        select {
        case <-ctx.Done():
            return
        case job := <-jobs:
            go process(ctx, job)
        }
    }
}()
```

| Prinsip | Aturan |
| :--- | :--- |
| Blocking | Channel unbuffered memblokir sampai ada penerima |
| Close | Hanya producer yang menutup; menutup dua kali = panic |
| Select default | `default` membuat select non-blocking |
| Loop variable | Go 1.22+ **per-iteration** — aman dipakai di goroutine tanpa salin |
| Goroutine bocor | Goroutine yang terblokir selamanya tidak hilang; harus di-cancel via context |

## Context

```go
// making: selalu dari parent, jangan simpan di struct
ctx, cancel := context.WithTimeout(parent, 2*time.Second)
defer cancel()          // WAJIB — kalau tidak, timer bocor sampai parent selesai

ctx = context.WithValue(ctx, RequestIDKey, id)   // hanya untuk data lintas request (trace id)
v := ctx.Value(RequestIDKey).(string)
```

```go
// propagate: parameter context HARUS di parameter pertama
func (s *Service) Get(ctx context.Context, id string) (*Order, error) {
    req, _ := http.NewRequestWithContext(ctx, "GET", s.url+id, nil)
    resp, err := s.client.Do(req)
    if err != nil {
        return nil, err
    }
    defer resp.Body.Close()
    ...
}
```

| Fungsi | Arti |
| :--- | :--- |
| `WithCancel` | batalkan manual |
| `WithTimeout` / `WithDeadline` | batas waktu |
| `WithCancelCause` | batalkan **dengan alasan** (Go 1.20+) |
| `WithValue` | simpan nilai; JANGAN untuk parameter wajib |
| `ctx.Done()` | channel yang ditutup saat context selesai |
| `ctx.Err()` | `Canceled` atau `DeadlineExceeded` |

> **Jebakan:** `context.Background()` di dalam fungsi yang menerima `ctx` = membatalkan
> propagasi timeout. Selalu teruskan `ctx` dari pemanggil.

## Error handling

```go
// wrapping dengan konteks
if err != nil {
    return fmt.Errorf("load order %s: %w", id, err)   // %w = bungkus
}

// cek tipe error
var e *sql.ErrNoRows
if errors.As(err, &e) { ... }

// cek sentinel
if errors.Is(err, sql.ErrNoRows) { ... }

// gabung beberapa error (1.20+)
if err := doAll(); err != nil {
    return errors.Join(err1, err2)   // errors.Is/As tetap jalan
}

// AsType (1.26) — generik, type-safe
if n, ok := errors.AsType[*net.OpError](err); ok {
    log.Printf("network: %v", n)
}

// sentinel error
var ErrNotFound = errors.New("not found")
```

| Konvensi | Contoh |
| :--- | :--- |
| Error value (sentinel) | `var ErrNotFound = errors.New(...)` |
| Error type | `type ValidationError struct{ Field string }` + `Error() string` |
| Wrap | `%w` — **hanya** satu level wrap per kata kunci |
| String | lowercase, tanpa koma atau titik di akhir |
| Inspect | `errors.Is` untuk sentinel, `errors.As` untuk tipe |

slices.Sort(users)                       // ascend by natural order

slices.SortStableFunc(users, cmp.Compare(a.Age, b.Age))

## Generics

```go
// fungsi generik
func Map[T, U any](in []T, f func(T) U) []U {
    out := make([]U, 0, len(in))
    for _, v := range in {
        out = append(out, f(v))
    }
    return out
}

// constraint
type Number interface {
    ~int | ~int64 | ~float64
}

func Sum[T Number](xs []T) T {
    var total T
    for _, x := range xs {
        total += x
    }
    return total
}

// tipe generik
type Stack[T any] struct {
    items []T
}

func (s *Stack[T]) Push(v T) { s.items = append(s.items, v) }
func (s *Stack[T]) Pop() (T, bool) {
    var zero T
    if len(s.items) == 0 {
        return zero, false
    }
    v := s.items[len(s.items)-1]
    s.items = s.items[:len(s.items)-1]
    return v, true
}
```

| Konvensi | Bentuk |
| :--- | :--- |
| Batas | `any`, `comparable`, atau union `~int \| ~string` |
| `~` | izinkan type alias (mis. `type MyInt int`) |
| Jangan | generic untuk 1–2 tipe saja; pakai interface kecil saja |

## HTTP server & client

```go
// server dengan timeouts (JANGAN tanpa ini)
srv := &http.Server{
    Addr:              ":8080",
    Handler:           mux,
    ReadHeaderTimeout: 5 * time.Second,   // wajib —slowloris protection
    ReadTimeout:       15 * time.Second,
    WriteTimeout:      30 * time.Second,
    IdleTimeout:       120 * time.Second,
}
go func() {
    if err := srv.ListenAndServe(); err != nil && !errors.Is(err, http.ErrServerClosed) {
        log.Fatal(err)
    }
}()

// graceful shutdown
ctx, cancel := context.WithTimeout(context.Background(), 15*time.Second)
defer cancel()
if err := srv.Shutdown(ctx); err != nil { log.Fatal(err) }
```

```go
// ServeMux dengan method pattern (1.22+)
mux := http.NewServeMux()
mux.HandleFunc("GET /api/orders/{id}", getOrder)   // {id} = wildcard
mux.HandleFunc("POST /api/orders", createOrder)
```

```go
// client dengan timeout & connection pool
tr := &http.Transport{
    MaxIdleConns:        100,
    MaxIdleConnsPerHost: 20,       // default 2 — penyebab utama connection leak!
    IdleConnTimeout:     90 * time.Second,
}
client := &http.Client{Transport: tr, Timeout: 10 * time.Second}

req, _ := http.NewRequestWithContext(ctx, http.MethodGet, url, nil)
resp, err := client.Do(req)
if err != nil { return err }
defer resp.Body.Close()
body, _ := io.ReadAll(resp.Body)
```

> **Jebakan:** `http.DefaultTransport` punya `MaxIdleConnsPerHost = 2`. Untuk service yang
> memanggil banyak host secara paralel, connection dibuang terus-menerus → handshake
> TLS tiap request. Set `MaxIdleConnsPerHost` secara eksplisit.

## JSON

```go
// marshal
data, err := json.Marshal(user)

// unmarshal
var u User
if err := json.Unmarshal(data, &u); err != nil { ... }

// decode streaming (body besar)
dec := json.NewDecoder(resp.Body)
dec.DisallowUnknownFields()      // opsional: tolak field tak dikenal
for {
    var order Order
    if err := dec.Decode(&order); err == io.EOF { break }
    else if err != nil { return err }
    handle(order)
}

// marshal dengan indent
data, _ := json.MarshalIndent(user, "", "  ")

// map[string]any
var m map[string]any
json.Unmarshal(data, &m)

// custom marshal
func (t Time) MarshalJSON() ([]byte, error) {
    return []byte(`"` + t.Format(time.RFC3339) + `"`), nil
}
```

| :--- | :--- |
| `json:"name"` | nama field |
| `json:"-"` | abaikan |
| `json:"name,omitempty"` | omit kalau kosong |
| `json:"-"` + custom | field privat tetap diserialisasi lewat method |

## Database

```go
db, err := sql.Open("pgx", dsn)
db.SetMaxOpenConns(20)
db.SetMaxIdleConns(10)
db.SetConnMaxLifetime(30 * time.Minute)
db.SetConnMaxIdleTime(5 * time.Minute)
defer db.Close()

ctx, cancel := context.WithTimeout(ctx, 2*time.Second)
defer cancel()

row := db.QueryRowContext(ctx, `SELECT id, total FROM orders WHERE id = $1`, id)
var id int64
var total int64
if err := row.Scan(&id, &total); err != nil {
    if errors.Is(err, sql.ErrNoRows) { return ErrNotFound }
    return err
}

// transaksi
tx, err := db.BeginTx(ctx, &sql.TxOptions{Isolation: sql.LevelReadCommitted})
if err != nil { return err }
defer tx.Rollback()   // no-op kalau sudah Commit

if _, err := tx.ExecContext(ctx, `UPDATE accounts SET balance = balance - $1 WHERE id = $2`, amt, src); err != nil {
    return err
}
if _, err := tx.ExecContext(ctx, `INSERT INTO outbox(...) VALUES(...)`); err != nil {
    return err
}
return tx.Commit()
```

| Praktik | Kenapa |
| :--- | :--- |
| Selalu `?`/placeholder, jangan string concat | SQL injection |
| `QueryRowContext` untuk 1 baris | Otomatis menutup row |
| `defer tx.Rollback()` | Aman baik commit maupun error |
| `SetConnMaxLifetime` | Load balancer kills koneksi idle |
| `rows.Close()` + `rows.Err()` | Jangan lupa cek error setelah loop |

## Testing & benchmark

```go
// table test
func TestCalculate(t *testing.T) {
    tests := []struct {
        name    string
        amount  int64
        want    int64
        wantErr bool
    }{
        {"normal", 100, 111, false},
        {"zero", 0, 0, false},
        {"negative", -50, 0, true},
    }
    for _, tt := range tests {
        t.Run(tt.name, func(t *testing.T) {
            t.Parallel()                     // test paralel
            got, err := Calculate(tt.amount)
            if (err != nil) != tt.wantErr {
                t.Fatalf("err = %v, wantErr %v", err, tt.wantErr)
            }
            if got != tt.want {
                t.Errorf("got %d, want %d", got, tt.want)
            }
        })
    }
}
```

## Jebakan (wajib dibaca)

| Jebakan | Gejalanya | Solusinya |
| :--- | :--- | :--- |
| Loop variable di goroutine (pra-1.22) | Semua goroutine baca variabel terakhir | Go 1.22+ aman per-iteration; tetap salin kalau butuh cross-version |
| `defer` di dalam loop | Semua defer jalan di akhir fungsi | Bungkus per-iterasi dalam func |
| `context.Background()` di dalam fungsi ber-ctx | Timeout tidak propagasi | Terima & teruskan `ctx` |
| Lupa `defer cancel()` | Context & timer bocor | `defer cancel()` langsung setelah dibuat |
| `wg.Add(1)` lupa / salah urutan | Panic "negative WaitGroup counter" | Pakai `wg.Go` (1.25+) |
| Menutup channel dua kali | Panic | Producer saja yang close |
| Kirim ke channel yang tidak dibaca | Goroutine memblokir selamanya | Select dengan `ctx.Done()` |
| Map ditulis dari 2 goroutine | Fatal error: concurrent map writes | `sync.Map` atau lock per key |
| `interface{}` vs `any` | Gaya campur | Pakai `any` (1.18+) |
| `http.DefaultTransport` | Connection dibuang terus (2 per host) | Transport sendiri + `MaxIdleConnsPerHost` |
| `rows.Close()` lupa | Connection leak | `defer rows.Close()` + cek `rows.Err()` |
| `err != nil` dicek setelah `defer resp.Body.Close()` | Body tidak terkirim | Cek error sebelum defer |
| `time.Now()` untuk durasi | Selalu positif, tidak bisa negatif | `time.Since(start)` |
| `fmt.Sprintf` untuk SQL | SQL injection | Selalu placeholder |
| `panic` di goroutine | Proses crash | `recover()` di goroutine yang sama |
| `float64` untuk uang | Selisih pembulatan | `int64` cents / `decimal` |
| Struct dengan `sync.Mutex` disalin | `go vet` copylocks | Pakai pointer |
| `interface{}` di API publik | Sulit di-evolusi | Generic atau trait kecil |
| `unsafe` tanpa alasan | Bug sulit dilacak | Tulis invariant di komentar |
| Slice di-loop dengan `append` | O(n²) alokasi | Pre-alokasi dengan `make(..., 0, len(x))` |
