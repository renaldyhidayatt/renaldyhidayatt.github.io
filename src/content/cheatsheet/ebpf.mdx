# eBPF — Cheat Sheet

> Target: **Linux kernel 6.x**, **libbpf 1.x**, **bpftrace 0.20+**, clang 16+.
> eBPF = small programs that run **inside the kernel** without a kernel module: for tracing,
> networking, security, and observability. All examples require `CAP_BPF`/`CAP_SYS_ADMIN`
> (or `root`, or `CAP_PERFMON` for tracing).

## Architecture & program lifecycle

```text
  C source ──clang -target bpf──▶ .bpf.o (ELF, BTF) ──loader──▶ kernel
                                                      │
                                       verifier  ◀────┤ (static analysis + bounds check)
                                       JIT       ◀────┤ (bytecode → native)
                                       attach    ◀────┘ (kprobe, XDP, cgroup, ...)
                                                       │
                                       maps  ◀─────────┴──▶ user space (read/write)
```

| Stage | What happens | Fails because |
| :--- | :--- | :--- |
| Load | loader calls `bpf(BPF_PROG_LOAD)` | insufficient privileges |
| Verify | verifier walks **all paths**, checks bounds, loops, map access | "invalid mem access", "loop not bounded" |
| JIT | bytecode → native instructions | rare; `/proc/sys/net/core/bpf_jit_enable` |
| Attach | program is bound to a hook | hook missing / wrong program type |
| Detach | when fd is closed / link is destroyed | — |

| Concept | Meaning |
| :--- | :--- |
| **Program** | verified code; many instances can attach to the same hook |
| **Map** | kernel↔user space storage (hash, array, ringbuf, ...) |
| **Helper** | kernel function that BPF may call (`bpf_probe_read_user`, `bpf_get_current_pid_tgid`, ...) |
| **BTF** | type metadata in the kernel & programs (`vmlinux.h`) |
| **CO-RE** | compile once, run everywhere — BTF-based field relocation |
| **Link** | attach handle (libbpf 1.x: `bpf_link`), safer than fd attach |
| **Pin** | keep objects in bpffs so they survive past the loader process |

```bash
# check kernel support
uname -r                                  # 6.x ideal
ls /sys/fs/bpf/                           # bpffs (mount -t bpf)
cat /proc/sys/kernel/unprivileged_bpf_disabled   # 2 = root only (recommended)
bpftool feature probe | head -40          # supported program types & helpers
```

## Verifier, JIT, helpers

```text
verifier rules that are most often violated:
  - pointers must be bounds-checked before dereference
  - every loop must be proven finite (bounded loops, kernel 5.3+)
  - BPF stack is only 512 bytes
  - user-space memory cannot be accessed directly (use bpf_probe_read_user)
  - map values must be looked up & NULL-checked
  - instruction count is limited (1 million by default for complexity)
```

```c
/* correct validation order */
struct event *e = bpf_map_lookup_elem(&events, &key);
if (!e) return 0;                 /* MUST check NULL */

if (ctx->len < sizeof(*ctx)) return 0;    /* bounds check */
bpf_probe_read_kernel(&e->data, sizeof(e->data), ptr);   /* read via helper */
```

| Popular helper | Purpose |
| :--- | :--- |
| `bpf_probe_read_user` / `_kernel` | safely read user/kernel memory |
| `bpf_get_current_pid_tgid` | process pid/tgid |
| `bpf_get_current_comm` | process name (16 bytes) |
| `bpf_ktime_get_ns` | monotonic time in ns |
| `bpf_map_lookup_elem` / `update` / `delete` | map access |
| `bpf_ringbuf_output` / `bpf_ringbuf_reserve` | send events to user space |
| `bpf_trace_printk` | quick debugging (**avoid in production**, slow & limited) |
| `bpf_get_stackid` | stack trace to a map |
| `bpf_get_current_task` | task struct |
| `bpf_send_signal` | send a signal (security) |
| `bpf_redirect` / `bpf_clone_redirect` | networking |

```bash
# see verifier log (source of truth when load fails)
sudo bpftool prog load x.bpf.o /sys/fs/bpf/x type kprobe 2>&1 | head -50
sudo cat /sys/kernel/debug/tracing/trace_pipe        # trace_printk
sudo bpftool prog show
sudo bpftool prog dump xlated id 42 | head -30       # bytecode after verifier
sudo bpftool prog dump jited id 42 | head -30        # native code
```

> **Pitfall:** verifier messages always point to an **instruction** (`R1 invalid mem access 'map_value_or_null'`),
> not a C line. Translate them via `bpftool prog dump xlated` or `llvm-objdump -S`.

## Program types & attach points

| Type | Attach | Use for |
| :--- | :--- | :--- |
| `kprobe`/`kretprobe` | kernel function | tracing any function (unstable across versions) |
| `tracepoint` | kernel tracepoint | stable tracing (names & format in `/sys/kernel/tracing/events`) |
| `raw_tracepoint` | raw tracepoint | higher performance, no format |
| `fentry`/`fexit` | BTF + kernel function | **stable & fast** kprobe replacement |
| `tp_btf` | BTF tracepoint | tracepoint via types |
| `uprobe`/`uretprobe` | user space function | tracing your own binary/application |
| `usdt` | USDT probe | applications with probe points (node, python, ruby) |
| `perf_event` | hardware/software perf | CPU sampling, cache misses |
| `XDP` | NIC driver (ingress) | earliest packet drop/filter, DDoS |
| `tc` (clsact) | ingress/egress qdisc | shaping, L3/L4 filtering |
| `socket_filter` | socket | per-socket packet capture |
| `cgroup/*` | cgroup hook | per-cgroup resource control |
| `lsm` | LSM hook | security policy (needs kernel with BPF-LSM) |
| `struct_ops` | kernel struct implementation | custom TCP congestion control |

```bash
# list available tracepoints & kprobes
ls /sys/kernel/tracing/events/syscalls/ | head
sudo bpftrace -l 'tracepoint:syscalls:*' | head
sudo bpftrace -l 'kprobe:tcp_*' | head
```

| Choose | If |
| :--- | :--- |
| `tracepoint` | you need **stability** across kernel versions |
| `fentry`/`fexit` | you need kernel functions + stability + performance |
| `kprobe` | quick to explore, willing to accept version risk |
| `XDP` | you need the drop decision before `sk_buff` is created |
| `tc` | you need packet modification & L3 forwarding |

## Maps

```c
/* map definition (libbpf) */
struct {
    __uint(type, BPF_MAP_TYPE_RINGBUF);
    __uint(max_entries, 1 << 24);          /* 16 MiB, MUST be power of two */
} events SEC(".maps");

struct {
    __uint(type, BPF_MAP_TYPE_HASH);
    __type(key, __u32);
    __type(value, __u64);
    __uint(max_entries, 10240);
} counters SEC(".maps");

/* access */
__u64 *cnt = bpf_map_lookup_elem(&counters, &pid);
if (cnt) __sync_fetch_and_add(cnt, 1);
else { __u64 one = 1; bpf_map_update_elem(&counters, &pid, &one, BPF_ANY); }
```

| Map type | Purpose | Notes |
| :--- | :--- | :--- |
| `HASH` | lookup by arbitrary key | allocated per entry on insert |
| `ARRAY` | index 0..n | preallocated, fast, key = index |
| `PERCPU_HASH`/`PERCPU_ARRAY` | per-CPU counters | lock-free, sum on read |
| `LRU_HASH` | bounded cache | old entries evicted automatically |
| `RINGBUF` | event streaming | **perf buffer replacement**, consumed per commit |
| `PERF_EVENT_ARRAY` | legacy perf buffer | larger & wasteful per CPU |
| `STACK_TRACE` | stack trace | used together with `bpf_get_stackid` |
| `PROG_ARRAY` | tail call | program chaining (33 hop limit) |
| `LPM_TRIE` | longest-prefix match | routing / CIDR allowlist |
| `QUEUE`/`STACK` | FIFO/LIFO | rarely used |
| `BTF_MAP` | map declaration via BTF | map of maps |

```bash
sudo bpftool map list
sudo bpftool map dump id 12 | head -20
sudo bpftool map update id 12 key 0x01 0x00 0x00 0x00 value 0x0a 0x00 0x00 0x00
```

> **Pitfall:** `PERF_EVENT_ARRAY` creates one buffer per CPU → memory usage grows with the
> number of cores. For event streams use **ringbuf**.

## BTF & CO-RE

```bash
# single header from kernel BTF: portable without distro headers
bpftool btf dump file /sys/kernel/btf/vmlinux format c > vmlinux.h

# compile: target bpf + BTF + CO-RE
clang -O2 -g -target bpf -D__TARGET_ARCH_x86 \
      -I/usr/include/x86_64-linux-gnu \
      -c probe.bpf.c -o probe.bpf.o
```

```c
#include "vmlinux.h"
#include <bpf/bpf_helpers.h>
#include <bpf/bpf_core_read.h>

struct {
    __uint(type, BPF_MAP_TYPE_RINGBUF);
    __uint(max_entries, 1 << 24);
} rb SEC(".maps");

SEC("fentry/do_sys_openat2")
int BPF_PROG(on_open, int dfd, const char *filename, struct open_how *how)
{
    struct event *e = bpf_ringbuf_reserve(&rb, sizeof(*e), 0);
    if (!e) return 0;

    e->pid = bpf_get_current_pid_tgid() >> 32;
    bpf_get_current_comm(&e->comm, sizeof(e->comm));
    bpf_probe_read_user_str(&e->path, sizeof(e->path), filename);

    bpf_ringbuf_submit(e, 0);       /* submit or discard, both are mandatory */
    return 0;
}

char LICENSE[] SEC("license") = "GPL";
```

| CO-RE macro | Purpose |
| :--- | :--- |
| `BPF_CORE_READ(task, mm, exe_file, f_path.dentry)` | safely read chained pointers |
| `bpf_core_read(&dst, size, &src->field)` | read a single field |
| `bpf_core_field_exists(field)` | check whether the field exists on this kernel |
| `bpf_core_type_exists(struct x)` | check whether the type exists |
| `bpf_core_field_size(field)` | field size on the target kernel |

| Rule | Why |
| :--- | :--- |
| Always use `vmlinux.h` + CO-RE | the program keeps working on different kernel versions |
| Do not include distro kernel headers | type conflicts |
| `BPF_CORE_READ` for chained pointers | safe verifier + field relocation |
| `bpf_core_field_exists` for optional fields | backwards compatibility |

> **Pitfall:** CO-RE requires BTF on the target kernel (`CONFIG_DEBUG_INFO_BTF=y`). Without it,
> the loader fails at relocation — check `/sys/kernel/btf/vmlinux`.

## bcc / libbpf / bpftrace

```text
bpftrace  : one-liners & scripts, quick tracing, not for daemons
bcc       : python/lua + inline C, prototyping & ready-made tools (execsnoop, biolatency)
libbpf-rs : modern C/C++/Rust loader, good for production agents
cilium/ebpf (Go) : popular Go loader
```

```bash
# bpftrace: one line for 80% of questions
sudo bpftrace -e 'tracepoint:syscalls:sys_enter_openat { printf("%s %s\n", comm, str(args->filename)); }'
sudo bpftrace -e 'kprobe:vfs_read { @[comm] = count(); }'
sudo bpftrace -e 'kprobe:tcp_sendmsg { @bytes[comm] = hist(arg2); }'
sudo bpftrace -e 'profile:hz:99 { @[comm, ustack] = count(); }'      # CPU sampling
sudo bpftrace -e 'interval:s:5 { print(@); clear(@); }'
```

```c
/* bcc: python + C inline */
from bcc import BPF

prog = """
#include <uapi/linux/ptrace.h>
int on_open(struct pt_regs *ctx) {
    bpf_trace_printk("open called\n");
    return 0;
}
"""
b = BPF(text=prog)
b.attach_kprobe(event="do_sys_openat2", fn_name="on_open")
b.trace_print()
```

```c
/* libbpf: user space loader */
#include <bpf/libbpf.h>

libbpf_set_print(NULL);
struct bpf_object *obj = bpf_object__open_file("probe.bpf.o", NULL);
if (!obj || libbpf_get_error(obj)) return 1;

if (bpf_object__load(obj)) return 1;

struct bpf_program *prog = bpf_object__find_program_by_name(obj, "on_open");
struct bpf_link *link = bpf_program__attach(prog);     /* auto-detach on close */
```

| Tool | Use for |
| :--- | :--- |
| `bpftrace` | ad-hoc investigation, one-liners |
| `bcc` | ready-made tools (`execsnoop`, `biolatency`, `tcpconnect`) |
| `libbpf` | production agents (C/C++/Rust bindings) |
| `cilium/ebpf` | production agents in Go |
| `aya` (Rust) | alternative without libbpf |

> **Pitfall:** `bpf_trace_printk` takes only 3 arguments and writes to the global trace pipe →
> never use it as a production event path.

## Observability & production tracing

```c
/* production pattern: ringbuf + event struct + aggregation */
struct event {
    __u32 pid;
    __u32 cpu;
    __u64 ts;
    __u64 latency_ns;
    __u64 bytes;
    char  comm[16];
};

SEC("fexit/tcp_rcv_established")
int BPF_PROG(on_recv, struct sock *sk, struct sk_buff *skb)
{
    if (bpf_ktime_get_ns() - start_ts < THRESHOLD_NS) return 0;   /* sampling */
    ...
}
```

| Production principle | Why |
| :--- | :--- |
| Sample, don't emit 100% of events | uncontrolled overhead & volume |
| Ringbuf + `bpf_ringbuf_reserve` + NULL check | avoid drops when the consumer is slow |
| Filter in the kernel (`if (pid != target) return 0;`) | don't send then discard in user space |
| Aggregate in per-CPU maps | reduce events reaching user space |
| Track drops & errors (ringbuf callback) | without this, events are lost silently |
| Verify load before/after | verifier & program registers change |

```bash
# quick diagnosis path
sudo bpftrace -e 'kprobe:do_sys_openat2 /pid == $1/ { printf("%s\n", str(args->filename)); }' -p 1234
sudo bpftrace -e 'tracepoint:sched:sched_switch { @[comm] = count(); }'
sudo bpftrace -e 'kfunc:tcp_retransmit_skb { @[args->sk->__sk_common.skc_daddr] = count(); }'
```

| Metric | Source |
| :--- | :--- |
| Syscall latency (p50/p99) | `sys_enter`/`sys_exit` tracepoint |
| Block I/O latency | `block:block_rq_issue`/`complete` |
| TCP retransmit | `tcp:tcp_retransmit_skb` |
| Scheduler delay | `sched_switch` + runqueue |
| OOM & page fault | kprobe `oom_kill_process`, `handle_mm_fault` |
| Process exec | `sched_process_exec` |

> **Pitfall:** computing latency as "exit − enter" without storing the timestamp in a per-tid
> map produces wrong numbers when a thread migrates to another CPU between the two events.

## Networking (XDP, TC, socket)

```c
/* XDP: drop packets at the earliest point */
SEC("xdp")
int xdp_drop_udp(struct xdp_md *ctx)
{
    void *data = (void *)(long)ctx->data;
    void *data_end = (void *)(long)ctx->data_end;
    struct ethhdr *eth = data;
    if ((void *)(eth + 1) > data_end) return XDP_PASS;
    if (eth->h_proto != bpf_htons(ETH_P_IP)) return XDP_PASS;

    struct iphdr *ip = (void *)(eth + 1);
    if ((void *)(ip + 1) > data_end) return XDP_PASS;
    if (ip->protocol == IPPROTO_UDP && bpf_ntohs(ip->dest) == 53) {
        return XDP_DROP;                     /* drop inbound DNS */
    }
    return XDP_PASS;
}
```

| XDP return | Meaning |
| :--- | :--- |
| `XDP_PASS` | pass to the stack |
| `XDP_DROP` | drop (fastest) |
| `XDP_TX` | send back out the same interface |
| `XDP_REDIRECT` | redirect to another interface/CPU |
| `XDP_ABORTED` | error, drop + trace |

```bash
# attach XDP
sudo ip link set dev eth0 xdp obj xdp_drop.bpf.o sec xdp
sudo ip link set dev eth0 xdpgeneric obj xdp_drop.bpf.o sec xdp   # generic mode
sudo ip link set dev eth0 xdp off                                  # detach

# TC clsact
sudo tc qdisc add dev eth0 clsact
sudo tc filter add dev eth0 ingress bpf da obj tc_filter.bpf.o sec ingress
sudo tc filter show dev eth0 ingress
```

| Concept | Notes |
| :--- | :--- |
| Native XDP | needs driver support (fastest) |
| Generic XDP | fallback in the stack, slower |
| Offload XDP | specific NICs |
| TC `clsact` | ingress + egress |
| `bpf_redirect_map` | fast map-based forwarding |
| `sk_lookup`/`sockmap` | connection redirect (L4 load balancing) |

> **Pitfall:** XDP only sees **ingress** packets. For egress/outbound traffic use
> TC on the egress qdisc.

## Security (LSM, seccomp, audit)

```c
/* BPF-LSM: deny exec from a specific path */
SEC("lsm/bprm_check_security")
int BPF_PROG(block_exec, struct linux_binprm *bprm)
{
    char path[64];
    bpf_probe_read_kernel_str(path, sizeof(path), bprm->filename);
    if (path_matches_blocklist(path))
        return -EPERM;
    return 0;
}
```

| Mechanism | Function |
| :--- | :--- |
| BPF-LSM | per-hook security policy (needs `CONFIG_BPF_LSM`) |
| seccomp-bpf | per-process syscall filter (classic BPF, not full eBPF) |
| `CAP_BPF`/`CAP_SYS_ADMIN` | requirement for loading programs |
| `kernel.unprivileged_bpf_disabled=2` | reject unprivileged loads |
| `bpf_jit_harden` | JIT hardening (constant blinding) |
| `bpf_stats_enabled` | measure program execution time |

```bash
# host security baseline
sysctl kernel.unprivileged_bpf_disabled kernel.kptr_restrict
cat /proc/sys/net/core/bpf_jit_harden
bpftool prog show | head
```

| Risk | Mitigation |
| :--- | :--- |
| Malicious programs / verifier exploits | latest kernel + `unprivileged_bpf_disabled=2` |
| Silent attach (eBPF rootkits) | audit `bpftool prog list`, anomaly detection, integrity |
| Unexpected overhead | `bpf_stats_enabled` + alert on `run_time_ns` |
| Data leaking through ringbuf | filter in the kernel, never send raw paths/credentials |
| Overly strict seccomp | test with the `SCMP_ACT_LOG` profile before `ERRNO` |

> **Pitfall:** seccomp is **classic BPF** (no maps & helpers) — don't assume you can use
> eBPF helpers in a seccomp profile.

## Performance & overhead

```bash
# measure program cost
echo 1 | sudo tee /proc/sys/kernel/bpf_stats_enabled
sudo bpftool prog show | grep -E 'name|run_time_ns|run_cnt'

# JIT log overhead
sudo bpftool prog dump jited id 42 | wc -l
```

| Cost source | Mitigation |
| :--- | :--- |
| Per-syscall events without filtering | early-return filter in the kernel |
| Excessive `bpf_probe_read_*` | read the minimum fields, use `BPF_CORE_READ` |
| Stack traces (`bpf_get_stackid`) | sampling + limit depth |
| Large hash maps per event | per-CPU map / aggregation |
| Ringbuf too small | power-of-two `max_entries`, monitor drops |
| kprobe on hot functions | move to fentry/fexit or tracepoint |

| Reference numbers (order of magnitude) | Value |
| :--- | :--- |
| Simple kprobe overhead | ~100–500 ns per call |
| fentry/fexit | lower than kprobe |
| XDP drop | ~10–50 ns per packet |
| Verifier (large program) | hundreds of ms at load |

## Pitfalls (must read)

| Pitfall | Symptom | Solution |
| :--- | :--- | :--- |
| Map value without NULL check | verifier rejects | `if (!ptr) return 0;` |
| Memory access without bounds check | "invalid mem access" | check `data_end`/`len` |
| Loop not proven finite | "loop not bounded" | `#pragma unroll` or an explicit bound |
| Stack > 512 bytes | "stack limit exceeded" | move to a map/ringbuf |
| `trace_printk` in production | slow, lossy, global | ringbuf |
| `PERF_EVENT_ARRAY` for high-volume events | per-CPU memory balloons | `RINGBUF` |
| Ringbuf reserve without submit/discard | events stall | always submit/discard |
| Program without detach | keeps running after the loader dies | `bpf_link` / deliberate pinning |
| kprobe on an inline function | never called | use fentry or a tracepoint |
| Struct fields change between kernels | load fails | CO-RE + `vmlinux.h` |
| No BTF on the target | relocation fails | check `/sys/kernel/btf/vmlinux` |
| `unprivileged_bpf_disabled=0` | attack vector | set 2 |
| Sampling 100% of traffic | CPU goes up, events drop | threshold & aggregation |
| Latency computed without a per-tid map | wrong numbers | store ts in a tid-keyed map |
| XDP used for egress | does not work | TC egress |
| Seccomp mistaken for eBPF | helpers unavailable | seccomp = classic BPF |
| Double attach on the same hook | duplicate events | check `bpftool net list` |
| Program using non-GPL-compatible helper | load rejected for a non-GPL license | set `SEC("license")` accordingly |
