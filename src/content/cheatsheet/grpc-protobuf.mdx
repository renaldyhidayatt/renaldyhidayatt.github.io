## The `.proto` contract

```proto
syntax = "proto3";

package com.sanedge.pos.order.v1;      // package = namespace, MUST be versioned

option java_multiple_files = true;      // each message becomes a separate Java file
option java_package = "com.sanedge.pos.order.v1";
option java_outer_classname = "OrderProto";
option go_package = "github.com/sanedge/pos/gen/order/v1;orderv1";

// Enums: DO NOT use 0 as a meaningful value
enum OrderStatus {
  ORDER_STATUS_UNSPECIFIED = 0;   // proto3 default — always present
  ORDER_STATUS_PENDING = 1;
  ORDER_STATUS_PAID = 2;
  ORDER_STATUS_FAILED = 3;
}

message Order {
  string id = 1;                 // NEVER change the type of an existing field
  string merchant_id = 2;
  OrderStatus status = 3;
  int64 total_price_cents = 4;   // money in the smallest unit, DO NOT use float/double
  repeated OrderItem items = 5;
  google.protobuf.Timestamp created_at = 6;
  map<string, string> attributes = 7;
}

message OrderItem {
  string product_id = 1;
  int32 quantity = 2;
  int64 price_cents = 3;
}

message ListOrdersRequest {
  string merchant_id = 1;
  int32 page_size = 2;           // default page size
  string page_token = 3;         // cursor, not an offset
  string idempotency_key = 4;    // for mutations
}
```

**Contract folder structure** (one proto per domain, shared library):

```
common/src/main/proto/
├── order.proto
├── order_item.proto
├── product.proto
├── transaction.proto
└── common/types.proto          # shared: money, timestamp, pagination
```

## Service & message definitions

```proto
service OrderService {
  // Unary: 1 request → 1 response
  rpc CreateOrder (CreateOrderRequest) returns (Order);

  // Server streaming: 1 request → N responses (stream from server to client)
  rpc WatchOrders (WatchOrdersRequest) returns (stream Order);

  // Client streaming: N requests → 1 response
  rpc UploadOrders (stream Order) returns (UploadSummary);

  // Bidi: N requests ↔ N responses
  rpc SyncOrders (stream SyncRequest) returns (stream SyncResponse);
}
```

```java
// Generated: OrderServiceGrpc.OrderServiceImplBase
@Service
public class OrderGrpcService extends OrderServiceGrpc.OrderServiceImplBase {

    @Override
    public void createOrder(CreateOrderRequest req, StreamObserver<Order> observer) {
        try {
            observer.onNext(command.create(req));
            observer.onCompleted();
        } catch (Exception e) {
            observer.onError(GrpcErrorMapper.map(e));
        }
    }
}
```

```go
// Generated: orderv1.OrderServiceServer
type OrderServer struct {
    orderv1.UnimplementedOrderServiceServer
    cmd *OrderCommandService
}

func (s *OrderServer) CreateOrder(ctx context.Context, req *orderv1.CreateOrderRequest) (*orderv1.Order, error) {
    order, err := s.cmd.Create(ctx, req)
    if err != nil {
        return nil, status.Error(codes.Internal, "create order failed")
    }
    return order, nil
}
```

## Naming & compatibility

Rules that keep the wire format backward-compatible:

| Rule | Example | Why |
| :--- | :--- | :--- |
| Field numbers **must not** be changed/swapped | `id = 1` is always `id` | The number is the identity on the wire |
| Removed fields → `reserved` | `reserved 4, 7;` | Prevents reuse |
| Field type **must not** change | `int64` → `string` = BREAKING | Old data becomes unreadable |
| New type → new field | add `optional string note = 12;` | Safe, old field stays default |
| `optional` = field may be absent | `optional string coupon = 8;` | proto3 scalars without `optional` always exist (default) |
| Enums: add values, never reorder | add `ORDER_STATUS_CANCELLED = 4;` | Ordinal/string consistency |
| Enum 0 = `UNSPECIFIED` | required | Old protobuf doesn't know the new enum → falls back to 0 |
| Package is versioned | `com.sanedge.pos.order.v1` | v1 & v2 can coexist |
| Service name & method name stable | `OrderService/CreateOrder` | The name is part of the contract |

```proto
message Order {
  reserved 4, 7;                  // `discount` & `note` used to exist, already removed
  reserved "discount_code";       // do not reuse

  string id = 1;
  string merchant_id = 2;
  OrderStatus status = 3;
  optional string coupon_code = 8;  // new field → safe
}
```

## Status codes & error mapping

**Official `grpc status` → HTTP map** (used by gateways & tracing):

| gRPC code | HTTP | When to use |
| :--- | :--- | :--- |
| `OK` | 200 | success |
| `INVALID_ARGUMENT` | 400 | bad input → **do not** retry |
| `UNAUTHENTICATED` | 401 | token missing/expired |
| `PERMISSION_DENIED` | 403 | not allowed to access |
| `NOT_FOUND` | 404 | resource doesn't exist |
| `ALREADY_EXISTS` | 409 | unique constraint conflict |
| `FAILED_PRECONDITION` | 400 | state doesn't meet preconditions |
| `RESOURCE_EXHAUSTED` | 429 | rate limit / quota exhausted |
| `ABORTED` | 409 | optimistic lock failed → **retryable** |
| `UNAVAILABLE` | 503 | dependency down → **retryable** |
| `DEADLINE_EXCEEDED` | 504 | timeout → retryable *only* if idempotent |
| `INTERNAL` | 500 | bug in the server |
| `UNIMPLEMENTED` | 501 | method doesn't exist (client version > server) |
| `DATA_LOSS` | 500 | corrupted data |

```java
// Mapping exception → status (JVM)
public final class GrpcErrorMapper {

    public static StatusRuntimeException map(Throwable t) {
        if (t instanceof StatusRuntimeException sre) return sre;

        if (t instanceof EntityNotFoundException)
            return Status.NOT_FOUND.withDescription("not found").withCause(t).asRuntimeException();

        if (t instanceof DataIntegrityViolationException)
            return Status.ALREADY_EXISTS.withDescription("conflict").withCause(t).asRuntimeException();

        if (t instanceof IllegalArgumentException)
            return Status.INVALID_ARGUMENT.withDescription(t.getMessage()).withCause(t).asRuntimeException();

        if (t instanceof AccessDeniedException)
            return Status.PERMISSION_DENIED.withDescription("forbidden").withCause(t).asRuntimeException();

        // REQUIRED: never leak internal details to the client
        return Status.INTERNAL.withDescription("internal error").withCause(t).asRuntimeException();
    }
}
```

```go
// Mapping errors → status (Go)
func ToStatus(err error) error {
    switch {
    case err == nil:
        return nil
    case errors.Is(err, ErrNotFound):
        return status.Error(codes.NotFound, "not found")
    case errors.Is(err, ErrConflict):
        return status.Error(codes.AlreadyExists, "conflict")
    case errors.Is(err, context.DeadlineExceeded):
        return status.Error(codes.DeadlineExceeded, "timeout")
    case errors.Is(err, context.Canceled):
        return status.Error(codes.Canceled, "canceled")
    default:
        return status.Error(codes.Internal, "internal error")
    }
}
```

> **Pitfall:** `Status.INTERNAL.withDescription(err.Error())` leaks table/column names
> to the client. The description must be generic; the details belong in the server log.

## Deadlines, timeouts, retries

A deadline is **automatic propagation**: the caller's deadline value is copied to every call
below it. Without it, a long chain can hang.

```java
// JVM client — always set a deadline
OrderServiceGrpc.OrderServiceBlockingStub stub =
        OrderServiceGrpc.newBlockingStub(channel)
                .withDeadlineAfter(2, TimeUnit.SECONDS);

Order order = stub.createOrder(request);
```

```go
// Go client — deadline via context
ctx, cancel := context.WithTimeout(ctx, 2*time.Second)
defer cancel()

order, err := client.CreateOrder(ctx, req)
if errors.Is(err, context.DeadlineExceeded) {
    return status.Error(codes.DeadlineExceeded, "upstream timeout")
}
```

| Practice | Value |
| :--- | :--- |
| Default deadline | 2–5 seconds for internal calls |
| Total deadline | shorter for long chains (edge → 3 services) |
| Retry | only `UNAVAILABLE` & `ABORTED`, **and** idempotent operations |
| Backoff | exponential + jitter, max 3 attempts |
| Retry budget | cap at 10% of requests, otherwise → retry storm |

## Interceptors

An interceptor is the cheapest place for things that cross all RPCs: logging, tracing, auth,
metrics. Put them in the **server** for observability, in the **client** for retry/auth.

```java
// Server interceptor — logging + trace propagation
public class LoggingInterceptor implements ServerInterceptor {

    @Override
    public <ReqT, RespT> ServerCall.Listener<ReqT> interceptCall(
            ServerCall<ReqT, RespT> call, Metadata headers, ServerCallHandler<ReqT, RespT> next) {

        long start = System.nanoTime();
        String method = call.getMethodDescriptor().getFullMethodName();

        return new ForwardingServerCallListener.SimpleForwardingServerCallListener<>(
                next.startCall(call, headers)) {
            @Override
            public void onComplete() {
                long ms = (System.nanoTime() - start) / 1_000_000;
                Status status = call.getStatus();
                log.info("grpc method={} status={} durationMs={}", method, status.getCode(), ms);
                Metrics.grpcCall(method, status.getCode().name(), ms);
            }
        };
    }
}
```

```go
// Go client interceptor — retry + auth
func UnaryRetryInterceptor(maxAttempts int) grpc.UnaryClientInterceptor {
    return func(ctx context.Context, method string, req, reply any,
        cc *grpc.ClientConn, invoker grpc.UnaryInvoker, opts ...grpc.CallOption) error {

        for attempt := 0; attempt < maxAttempts; attempt++ {
            err := invoker(ctx, method, req, reply, cc, opts...)
            if err == nil {
                return nil
            }
            st, _ := status.FromError(err)
            if st.Code() != codes.Unavailable && st.Code() != codes.Aborted {
                return err
            }
            time.Sleep(backoff(attempt))
        }
        return status.Error(codes.Unavailable, "retries exhausted")
    }
}
```

## Streaming: unary, server, client, bidi

```java
// Server streaming — iterator on the server
@Override
public void watchOrders(WatchOrdersRequest req, StreamObserver<Order> observer) {
    Flux<Order> flux = orderService.watch(req.getMerchantId());
    flux.subscribe(
        order -> observer.onNext(order),
        err -> observer.onError(GrpcErrorMapper.map(err)),
        () -> observer.onCompleted()
    );
}
```

```go
// Server streaming — Send
func (s *OrderServer) WatchOrders(req *orderv1.WatchOrdersRequest, srv orderv1.OrderService_WatchOrdersServer) error {
    for _, o := range s.svc.Watch(req.MerchantId) {
        if err := srv.Send(o); err != nil {
            return err
        }
    }
    return nil
}
```

| Type | Cardinality | Use case |
| :--- | :--- | :--- |
| Unary | 1 → 1 | the majority (99% of RPCs) |
| Server streaming | 1 → N | order notifications, live updates, log tailing |
| Client streaming | N → 1 | bulk upload, batch insert |
| Bidi | N ↔ N | chat, two-way sync, interactive |

> **Pitfall:** streaming opens a **long-lived** connection. In Envoy/Nginx you need a sufficient
> `grpc_http2_max_duration`, and each stream holds 1 goroutine/thread. If thousands of order
> monitors are active at once, the server threads run out.

## Spring gRPC (server & client)

```java
// Server
@SpringBootApplication
@EnableGrpc
public class OrderApplication { public static void main(String[] args) {
    SpringApplication.run(OrderApplication.class, args);
} }

@Configuration
public class GrpcServerConfig {

    @Bean
    GrpcServerBuilderCustomizer grpcCustomizer(OrderGrpcService service) {
        return builder -> builder
                .addService(service)
                .intercept(new LoggingInterceptor())
                .maxInboundMessageSize(4 * 1024 * 1024);   // default 4 MiB
    }
}
```

```java
// Client — stub + load balancing via Eureka
@Bean
OrderServiceGrpc.OrderServiceBlockingStub orderStub(
        @Qualifier("orderChannel") ManagedChannel channel) {
    return OrderServiceGrpc.newBlockingStub(channel)
            .withDeadlineAfter(2, TimeUnit.SECONDS)
            .withWaitForReady();            // queue while the service isn't ready, don't fail immediately
}
```

## grpc-go (server & client)

```go
// Server
func NewServer(svc OrderService) *grpc.Server {
    s := grpc.NewServer(
        grpc.ChainUnaryInterceptor(logInterceptor, authInterceptor),
        grpc.MaxRecvMsgSize(4*1024*1024),
        grpc.KeepaliveParams(keepalive.ServerParameters{
            MaxConnectionIdle: 5 * time.Minute,
            Time:              30 * time.Second,
            Timeout:           10 * time.Second,
        }),
    )
    orderv1.RegisterOrderServiceServer(s, svc)
    return s
}

// Client
conn, err := grpc.NewClient(
```

## Pitfalls (must-read)

| Pitfall | Symptom | Solution |
| :--- | :--- | :--- |
| Deadline not set | Calls hang, resources exhausted | `withDeadlineAfter` / `context.WithTimeout` |
| Retry without idempotency | Duplicate transactions | Idempotency key in the DB + `idempotency_key` in the request |
| Long streaming behind a proxy | Streams drop at 60 seconds | Raise `grpc_http2_max_duration`, use keepalive |
| `INTERNAL` + raw error details | DB structure leaked to the client | Generic description, details in the log |
| Enum starts at 1 without `UNSPECIFIED` | Old clients get nonsense values | Always define `*_UNSPECIFIED = 0` |
| Changing a field number | Old data misread | The field number is a permanent contract |
| `float64` for money | Rounding differences | `int64` cents / `BigDecimal` |
| Marshal/Unmarshal in a loop | CPU blows up | Batch messages, or use streaming |
| gRPC without mTLS | Traffic can be sniffed | TLS + per-RPC token (metadata) |
| Auth header without expiration | Token leaks | Validate `exp` + `aud` + `iss` in the interceptor |
| `waitForReady` without a deadline | Requests pile up | Still set a deadline |
